# Selected RAL appearance swatches

The shared native appearance palette includes a separate RAL category with 23
selected codes, sorted numerically. The user's 14 distinct requested codes are
included once. Additional industrial choices are 1023, 2004, 3001, 5005, 7016,
7032, 7040, 9003 and 9010. These complement the requested yellows, reds, blues,
greens, light grey, black and traffic white with further enclosure and frame
choices. This selection is not a mandatory automotive customer specification.

The hexadecimal swatches use the consistent public sRGB crosswalk published by
[paint manufacturer Fire Scale Modeler](https://www.firescalemodeler.com/ral-classic-to-rgb).
Comparison with [RAL.no](https://www.ral.no/) and
[TGT's display chart](https://www.tgt-srl.com/wp-content/uploads/2018/07/Colori-RAL.pdf)
showed differences between conversions; these sources are not mixed per code.
They are not licensed RAL Digital colorimetric data or paint-matching standards.
Official names and codes can be checked in the
[RAL catalogue](https://www.ral-farben.de/en/all-ral-colours). Physical samples
remain the reference for paint matching. RAL 3024 is fluorescent; the ordinary
surface shader does not simulate fluorescence, and its tooltip says so.

All swatches use the established nonmetallic surface style with roughness 0.35.
Existing gloss and transparency controls remain available. Selecting a code
previews an appearance through the existing transaction; OK commits and Cancel
restores the prior appearance. It does not assign an engineering material,
density, manufacturing process or safety classification to the Part.

RAL codes remain language-independent. The category and screen-approximation
tooltips are covered in all five UI catalogs. Factory palette definitions are
shared by Windows, Linux and the native console; user-created palettes retain
their separate storage and editing behavior.
