# Reference standards acquisition and review list

Status: **OPEN**, reviewed on 2026-10-15. The user intends to obtain suitable
standards later. No automatic purchases are authorized or required. Obtain full,
lawfully accessible editions, including applicable corrections; a catalogue or
sample alone cannot verify every table and exception. Check publication status
again at acquisition, since revisions are in progress for several items.

These are verification sources for our own reference tables, not files to bundle
with the GPL distribution. Do not redistribute their text, scans or artwork.
Language selection does not select a different country's standard. A national
adoption is useful only when its exact ISO edition and corrections are confirmed.

The public catalogue identifies **ISO/R 775:1969 as withdrawn**:
[shaft-end reference](https://www.iso.org/standard/5059.html). No direct current
ISO replacement was established in this review. Original ČSN shaft-end data
therefore remain explicitly historical. Do not purchase withdrawn material
merely to describe it as current. A separate national-standard review is needed
if a current shaft-end selection is required.

## Fasteners: bolts, screws, nuts and washers

The user confirmed that product grades are to remain where specified by ISO.
Keep **product grades A/B/C** (dimensional and geometrical tolerances) separate
from **property classes**, for example 8.8. The old ISO 4762 factory labels
incorrectly said grade C; the refreshed names omit that false classification.

Prioritize complete product dimensions and their common tolerance rules before
buying every specialist document. The following are review sources, not a claim
that old factory dimensions have already been reconciled with these editions.

| --- | --- |
| [ISO 4759-1:2000](https://www.iso.org/standard/10745.html) | Product grades, dimensional and geometrical tolerances, applicability of A/B/C; still current despite its date |
| [ISO 4014:2022](https://www.iso.org/standard/72579.html), [4017:2022](https://www.iso.org/standard/72585.html) | Hexagon partial/full coarse threads, A/B; reconcile actual dimensions, bearing areas, lengths and material scope |

Specialist product selections already have current catalogue contexts in the
dataset: ISO 1207, 1580, 2009, 2010, 7045, 7046-1/-2, 7047, 7049 and 7050 (2011
editions); ISO 7380-1:2022; slotted set screws ISO 4766 and 7434/7435/7436 (2024);
hexagon socket set screws ISO 4026/4027/4028/4029 (2026); and countersunk socket
screws ISO 10642:2026. Acquire only those required by the actual product scope.
Reduced-loadability head styles need their complete mechanical specification.

The publisher's [nuts catalogue](https://www.iso.org/ics/21.060.20/x/) identifies
ISO 4034:2012 and ISO 4036:2012 as withdrawn. A related modern nut standard is
not an automatic interchangeable replacement for either. It also identifies
[ISO 8839:1986](https://www.iso.org/standard/16316.html) as withdrawn; do not
present its old non-ferrous material prescriptions as current ISO requirements.

The separate numeric dataset records independent recalculations for nominal

do not resolve manufacturing allowances, material selection, fatigue, profile
modifications or standard-specific inspection exceptions.

## Additional preserved source defects

- ISO fit source `02-ISO-FITS/09-HOLES/01-A-D` includes the contradictory
  `+850 / +540` pair. Do not infer which bound or unit was wrong from fit-width
  arithmetic alone. Full ISO 286-2 comparison is still required.
- Original split-pin mass headings alternate between mass per **1,000 pins**
  and mass per **one pin** within the same matrix. Each original column heading
  is retained explicitly; confirm the scale and numbers before using this data.
- Original clevis-pin length tolerances contain `±0,5 0`; the ambiguous spacing
  is retained, not silently interpreted as a different precision or bound.
- The taper-pin printed equation is fragmented across three rows containing
  a fraction bar and `(0.02·l)²`. Its intended grouping and applicability are
  unresolved; the original cells remain in the source ledger, outside the
  authored numeric table.
- Some historical key mass entries are non-monotonic; for example the original
  parallel-key table lists 0.314 g/mm for 2×2 and 0.071 g/mm for 3×3. Retained
  values are unverified, not analytically justified by the new mass formulae.
- Several obsolete material names map to multiple different modern entries;
  the old cross-reference table is deliberately labelled historical rather than
  used to certify a substitution.
