# Post-release cleanup, 2026-10-07

The user requested cleanup after Windows 2026100702 publication and public asset
acceptance. The cleanup used an audited list of resolved absolute targets and
native PowerShell LiteralPath operations. Recursive targets were checked against
the repository or the dedicated `C:/zcb` staging root. Reparse points, current
build/runtime paths and working Projects were excluded.

Removed:

- 152 obsolete diagnostic directories under `build/`.
- 76 obsolete package, source, GUI and validation staging directories.
- Two clean temporary release worktrees, removed through Git.
- 59 generated verification files from the repository root.
- 219 old numbered settings/library backups; three latest untracked local backups per
  file remain, including backup groups whose former base file no longer exists.
- 3 numbered native test-fixture backups; their tracked fixtures remain.

Fifteen historical Git checkout copies were included in the staging count only
after confirming zero modified/untracked/ignored files and proving all 93 unique
references remain reachable from references in the main repository. This includes
the pending curve-reference work branch; its history was preserved.

Audited removed payload was approximately 30.33 GB, plus the two temporary worktrees.
Measured C: free-space increase was approximately 31.38 GB (allocated space differs
from logical file sizes). Detailed local path lists and checks remain under
`build/form-diagnostic/cleanup-0702-*.json` and are excluded from product source.

Preserved: the current local native build and Qt/OCCT SDK, current release staging
and signed packages, the previous known-good package, existing immutable release
archives, Projects and their backups, current settings, tracked configuration,
factory libraries, the development launcher, private signing-key storage and
current verification evidence. Exact SHA-256 checks passed for all 9,858 protected
files after cleanup. Two tracked settings backup files inadvertently included in
a second backup pass were restored to their exact pre-cleanup hashes before this
final verification.

The Git ignore list now covers numbered local configuration backups and known
native verification scratch documents. This does not untrack factory assets or
hide changes to tracked settings. No modeling algorithm, persistent document
format, or user-visible UI string changes are part of the cleanup. The existing
five-language localization acceptance applies to the unchanged product text.

acceptance records, manifests/signature and packaged GUI logs were retained under
`build/form-diagnostic/distribution-evidence-0702`. The staging preservation list
above describes the first cleanup pass and is superseded by this authorization.

passed for Windows 2026100702 after removal.
