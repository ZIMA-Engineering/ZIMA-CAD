# Extrusion, Rotation und Dünn

## Bevor Sie beginnen

Aktivieren Sie einen bearbeitbaren Körper in einem Bauteil. Neue
Material-Features gehören zu Bauteilen; dies gilt auch für ein innerhalb einer
Baugruppe aktiviertes Bauteil.

## Schritte

1. Wählen Sie **Extrudieren** oder **Rotation**. Legen Sie in den Eigenschaften
   die Platzierungsreferenzen, die Basisebene und einen etwaigen Ebenenversatz fest.
2. Öffnen Sie **Skizze** und zeichnen Sie das Profil. Definieren Sie für die Rotation eine grüne Konstruktionsmittellinie als Achse. Die gewählte Achse bleibt erhalten; andernfalls wird die erste geeignete Mittellinie verwendet.
3. Stellen Sie die Skizze fertig. Legen Sie die Extrusionslänge oder den
   Rotationswinkel fest und prüfen Sie die in der Vorschau angezeigte Richtung.
4. Wählen Sie **Hinzufügen** oder **Abziehen**. Für Wände wählen Sie **Dünnwandiges Formelement**,
   geben die Dicke ein und wählen deren Seite oder eine symmetrische Verteilung.
5. Bestätigen Sie mit **OK**, um zu berechnen und zu übernehmen. Verwenden Sie
   **Abbrechen**, um die ausstehende Definition zu verwerfen.

## Was Sie prüfen sollten

Ein geschlossenes Profil kann einen Volumenkörper erzeugen; ein offenes Profil
verwendet ein unterstütztes Dünn- oder Flächenergebnis. **Bis zu…** benötigt ein
gültiges Ziel, das die Operation erreicht. **Durch alles** ist für die
Subtraktion verfügbar. Prüfen Sie die ausgewählte Materialseite.

Öffnen Sie zum Bearbeiten erneut die **Eigenschaften**. Die Ansicht zeigt
vorübergehend die Eingangsgeometrie vor dem Feature. Ein einfacher Klick wählt
aus; ein Doppelklick zeigt die Parametermaße an.
