# Zeichnungen

## Bevor Sie beginnen

Bereiten Sie ein Quellbauteil oder eine Quellbaugruppe vor. Eine Zeichnung
(`.drwz`) speichert ihre Quellenverknüpfung, Blätter, Ansichten und Anmerkungen.

## Schritte

1. Wählen Sie **Datei > Neu**, im Dialog **Zeichnung**, und geben Sie einen Namen ein. Bestätigen Sie mit **OK** und wählen Sie das Quellmodell, oder verwenden Sie **Zeichnung** im Baumkopf der geöffneten Quelle.
2. Prüfen Sie Blattformat, Rahmen und Schriftfeld. **Format** ändert das aktive
   Blatt; das **+** am unteren Rand fügt ein weiteres Blatt hinzu.
3. Wählen Sie **Ansicht einfügen** und platzieren Sie die Ansicht. Prüfen Sie im geöffneten Dialog Ausrichtung, Maßstab und Darstellungseinstellungen und bestätigen Sie mit **OK**.
4. Fügen Sie benötigte Maße und Texte hinzu. **Bemaßungen ein-/ausblenden…** macht
   unterstützte Quellmaße, Achsen und Hilfsgeometrie in einer ausgewählten
   Ansicht sichtbar.
5. Speichern Sie die Zeichnung und verwenden Sie dann den passenden Export für
   PDF, DXF des aktuellen Blatts oder ein Bild des Blatts/eines Bereichs.

## Was Sie prüfen sollten

Prüfen Sie vor dem Export Maßstab, Anmerkungsreferenzen und die Lesbarkeit der
Texte. Die X-Koordinate des Blatts nimmt vom Ursprung unten rechts nach links
zu; dies ist beabsichtigt. Eine Formatänderung erhält diese
Verankerungskonvention.

Die Ansichtseigenschaften bearbeiten auch vorhandene Ansichten. Abbrechen
verwirft ausstehende Änderungen. Verwenden Sie **Regenerieren**, um anhand
der aktuellen Quelldaten zu aktualisieren. Eine fehlende Referenz wird als
ungelöst gekennzeichnet, statt unbemerkt an eine andere Kante gebunden zu werden.
