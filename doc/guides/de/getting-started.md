# Erste Schritte

## Bevor Sie beginnen

Wählen Sie einen Arbeitsordner für Ihre nativen Dokumente. ZIMA-CAD verwendet
`.prtz` für Bauteile, `.asmz` für Baugruppen und `.drwz` für Zeichnungen.

## Schritte

1. Öffnen Sie **Werkzeuge > Systemeinrichtung**. Wählen Sie die metrische oder
   zöllige Voreinstellung und passende Bauteil- und Baugruppenvorlagen. Prüfen Sie
   den Arbeitsordner und bestätigen Sie mit **OK**.
2. Wählen Sie **Datei > Neu**, im Dialog **Bauteil**, und geben Sie einen Namen ein. Wählen Sie **Modellierung** oder **Blech**. Beide Modi erstellen ein gewöhnliches Bauteil und wählen seine anfänglichen Werkzeuge; bestätigen Sie mit **OK**.
3. Arbeiten Sie im aktiven bearbeitbaren Körper. Starten Sie einen
   Modellierungsbefehl, legen Sie seine Platzierungsreferenzen fest und verwenden
   Sie **Skizze**, wenn der Befehl ein Profil benötigt.
4. Stellen Sie die Skizze fertig, prüfen Sie das noch nicht übernommene Feature
   und bestätigen Sie mit **OK**. **Abbrechen** verwirft die ausstehende Definition.
5. Speichern Sie das Bauteil mit **Datei > Speichern**. Erstellen Sie eine
   Baugruppe oder Zeichnung, wenn Sie Komponenten oder ein technisches
   Zeichnungsblatt benötigen.

## Was Sie prüfen sollten

Der Baum sollte das neue Feature innerhalb seines Körpers anzeigen. Drehen Sie
die Ansicht mit der mittleren Maustaste; verschieben Sie sie mit der mittleren
und rechten Maustaste gleichzeitig. **Regenerieren** ist ein ausdrücklicher
Berechnungsbefehl. Das Wechseln zwischen Dokumentregisterkarten regeneriert keine
Modelle.

Siehe [Systemeinstellungen](../../SYSTEM_SETUP.md) und das
[Benutzerhandbuch](../../USER_MANUAL.md#new-documents).
