# Скругление и фаска

## Перед началом

Подготовьте рассчитанное твёрдое тело в активном редактируемом теле детали.
Эти команды выбирают рёбра фактического входного тела в своей позиции истории.

## Порядок действий

1. Выберите **Скругление** или **Фаска**. Для создания и последующего редактирования
   используется одно и то же окно свойств соответствующей команды.
2. Щёлкайте по нужным входным рёбрам, чтобы добавлять или удалять их, и проверяйте список выбранных рёбер.
3. Для скругления выберите постоянный радиус R или переменные R1 → R2 и проверьте направление. Для фаски выберите A × A, A × B или A + угол; при несимметричных значениях проверьте опорную сторону.
4. Выберите **ZIMA** или **OCCT** и проверьте автоматически добавленные касательные участки. Удаление строки исключает только данный участок ребра; при ошибке расчёта ZIMA не переключается на OCCT.
5. Нажмите **OK**, чтобы выполнить расчёт. **Отмена** отбрасывает неподтверждённое изменение.

## Что проверить

Результат должен соответствовать нужным рёбрам и стороне. При повторном открытии
свойств отображается предшествующее исходное тело с острыми рёбрами, чтобы ссылки
на рёбра можно было исправить или заменить. Двойной щелчок по скруглению показывает размеры его параметров.

При неудачном первом нажатии OK выводится ошибка, а черновик остаётся открытым.
Повторное нажатие OK без изменений может сохранить структурно корректное определение
как неразрешённое; это не делает его геометрию допустимой. Исправьте его через свойства.
