# Začínáme

## Než začnete

Zvolte pracovní složku pro nativní dokumenty. ZIMA-CAD používá `.prtz` pro díly,
`.asmz` pro sestavy a `.drwz` pro výkresy.

## Postup

1. Otevřete **Nástroje > Nastavení systému**. Vyberte metrickou nebo palcovou
   předvolbu a odpovídající šablony dílu a sestavy. Zkontrolujte pracovní složku
   a potvrďte **OK**.
2. Zvolte **Soubor > Nový**, v dialogu vyberte **Díl** a zadejte název. Vyberte **Modelování** nebo **Plech**. Oba režimy vytvoří běžný díl a zvolí jeho výchozí nástroje; potvrďte **OK**.
3. Pracujte uvnitř aktivního upravitelného tělesa. Spusťte modelovací příkaz,
   určete jeho umístění pomocí referencí a použijte tlačítko **Skica**, pokud příkaz
   potřebuje profil.
4. Dokončete skicu, zkontrolujte připravovaný prvek a potvrďte **OK**. Tlačítko
   **Zrušit** zahodí nepotvrzenou definici.
5. Uložte díl pomocí **Soubor > Uložit**. Pro práci s komponentami vytvořte sestavu;
   pro technický list vytvořte výkres.

## Co zkontrolovat

Strom má zobrazovat nový prvek uvnitř jeho tělesa. Pohled otáčejte prostředním
tlačítkem myši; posouvejte jej současným stisknutím prostředního a pravého
tlačítka. **Regenerovat** je výslovný příkaz k výpočtu. Přepínání záložek dokumentů
modely neregeneruje.

Viz [nastavení systému](../../SYSTEM_SETUP.md) a
[uživatelská příručka](../../USER_MANUAL.md#new-documents).
