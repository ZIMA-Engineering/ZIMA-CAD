# Extrusion, révolution et paroi mince

## Avant de commencer

Activez un corps modifiable dans une pièce. Les nouvelles fonctions de matière
appartiennent aux pièces, y compris à une pièce activée dans un assemblage.

## Étapes

1. Choisissez **Extruder** ou **Révolution**. Définissez les références de
   placement, le plan de base et son éventuel décalage dans les propriétés.
2. Ouvrez **Esquisse** et dessinez le profil. Pour la révolution, définissez une ligne d’axe de construction verte. L’axe choisi est conservé ; sinon, la première ligne d’axe admissible est utilisée.
3. Terminez l’esquisse. Définissez la longueur d’extrusion ou l’angle de révolution
   et inspectez le sens indiqué par l’aperçu.
4. Choisissez **Ajouter** ou **Soustraire**. Pour des parois, choisissez **Fonction à paroi mince**, saisissez l’épaisseur et sélectionnez son côté ou une répartition symétrique.
5. Confirmez avec **OK** pour calculer et valider. Utilisez **Annuler** pour
   abandonner la définition en cours.

## Points à vérifier

Un profil fermé peut créer un solide ; un profil ouvert utilise un résultat de
type paroi mince ou surface pris en charge. **Jusqu’à…** nécessite une cible valide
atteinte par l’opération. **À travers tout** est disponible pour la soustraction.
Vérifiez le côté de matière sélectionné.

Rouvrez les **Propriétés** pour modifier la fonction. La vue montre temporairement
la géométrie d’entrée précédant la fonction. Un clic sélectionne ; un double-clic
affiche les cotes des paramètres.
