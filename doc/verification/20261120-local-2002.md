are recorded in [Cursor orbit](20261120-cursor-orbit.md) and
[Profile direction and Loft output](20261120-profile-direction-and-loft-output.md).

limitations remain explicitly documented in those reports. Model-26 candidates

history conversion has not been certified. Originals were not overwritten.

inside an Assembly. Linux execution remains unverified.

Those documentation edits introduce no user-visible application strings.
Portable packaging must use committed source and the exact verified factory
assets through the repository release pipeline after user testing.
