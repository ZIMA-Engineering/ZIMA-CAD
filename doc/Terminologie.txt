Main Window       = The main application window.
Menu Bar          = The top-level File/Edit/... menu.
Document Tab      = A tab representing one open file.
Tree              = The container hierarchy on the left.
Viewport / View   = The 3D display area on the right.
Properties Dialog = A container's Properties window.
Document          = An open .prtz/.asmz/.drwz file held in memory.
Part              = The document type representing a mechanical part.
Container         = A container within a document.

Use these terms consistently: Main Window, Menu Bar, Document Tab, Tree,
Viewport/View, Properties Dialog, Document, Part, and Container.
