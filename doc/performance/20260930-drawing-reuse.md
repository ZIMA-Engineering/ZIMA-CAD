# A10/A11 — scoped Drawing reuse

## Part projection after unrelated edits

A completed Part projection can be reused when its own live document, Family
owner and source-path matches are unchanged, even if an unrelated open document
was edited. Runtime identity, data generation and path remain part of the check.
The existing native-byte capture still checks every observed file, including
missing files and changes with an unchanged timestamp. Assemblies retain the
conservative full-Workspace gate: the Part-specific rule is not generalized to
nested component dependencies without a complete observed-read dependency set.

A calculated Part owns its geometry and annotations; no external geometry is
regenerated by this reuse. Family changes, edited source geometry and source
replacement must invalidate reuse. Source/occurrence and measurement identities
remain exact. No lower-detail mesh or image substitutes for geometry.

The current box fixture measured twenty preparations after an unrelated edit:
10.89 ms fresh versus 0.8536 ms using the completed Part projection. Reuse
performs zero source loads and zero camera calculations; measurement geometry
is identical and the existing immutable display packet is retained.

## Multi-sheet PDF source metadata

A synchronous PDF export now reads each unique source identity/path context once
for the whole export. Each sheet still receives its own index/count and chosen
source/variant. Every independent view source is checked; failures still abort
atomic output publication. The map is local to one export, so changed live or
saved metadata is read again on the next export. Image/DXF exports retain their
single-sheet behavior. Exact output stroke calculation is unchanged.

The 32-sheet fixture with a saved Part containing 128 authored text parameters
measured 22.2559 ms without reuse and 2.0377 ms with it (including context checks).
Only one source context was prepared. All source fields and page numbering
match, and a subsequent export sees changed source data. PDF contract checks
also cover Unicode, unsaved authoritative values, independent missing sources,
unchanged model/history and preservation of an existing output on failure.

Annotation preparation additionally reuses the Assembly scene already calculated
in the same scope when collecting Assembly-owned dimensions, eliminating one
discarded duplicate scene calculation. No cross-operation geometry cache is
introduced. Localization review: no user-visible strings changed.
