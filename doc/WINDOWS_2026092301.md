# Windows build 2026092301

## Changes

- Sheet Profile supports independent corner closure at both ends, with a small
  welding gap, unfolding, bending back and sheet cutting.
- Closing Sheet Profile removes transient editable dimension overlays.
- Sheet from Body reconstructs an independent native sheet in an empty active
  Body after the source Body. Planar faces and cylindrical bends become native
  Flats and Bends; local joining tolerance is 0.05 mm. Complex corners may need
  manual finishing. See [Sheet exchange](SHEET_EXCHANGE.md).
- Part sheet DXF exports the active Body's unfolded finished contour to the
  configured relative DXF folder without changing its history.
- This build also includes the drawing responsiveness, title-block, export and
  cylindrical-reference changes committed since Windows build 2026092203.

## Development verification

Native sheet exchange tests passed, including rotated source/target Bodies,
source removal, save/reopen, slots and holes, Unbend/Bend Back, through Sheet Cut
and DXF contour/volume checks. Existing closed-spline extrusion, sheet-cut wire
preview, Profile, Flat, sheet-state and Bend command regressions passed.

The synthetic GUI contract and a private copy of the supplied STEP Part passed
native picking, five-language dialog checks, Cancel, middle-button OK, Undo/Redo,
reopening generated feature properties and DXF export. Localization catalog
validation passed. Original user documents were not overwritten.

Packaging unit tests passed (9 tests, 2 platform-dependent skips); all 16
release-publisher input tests passed.
