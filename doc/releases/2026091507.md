# ZIMA-CAD 2026091507

## Development changes

- Family Table uses a wider internal properties window, shared reference input
  and inspection controls, a generic row and typed variant rows.
- Original solids, Bodies and Assembly components provide Yes/No presence.
  A Part feature double-click exposes dimensions; selecting one creates its
  stable `dN` column with numeric overrides.
- Opening a row explicitly calculates an independent native instance in a new
  tab. Invalid geometry leaves existing models unchanged. Regeneration preserves
  user edits in an already opened variant.
- Saved open instances can replace the generic source through the Drawing
  Variant selector. Related views update in one undoable transaction.
- GUI and CLI share the same reference catalog, validation and generation.
  Part INI 24 (payload 48), Assembly payload 32 and the tracked start templates
  carry the typed Family Table schema.

See [Family Table](../FAMILY_TABLE.md) for the workflow, supported parameters and
verification results.

This is a development revision, not a published Windows package. Stable remains
`2026091505`. The root `zima-cad.bat` continues to launch the local development build.
