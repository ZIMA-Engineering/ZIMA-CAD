# ZIMA-CAD 2026093004 — Windows

Extrusion now shows each active side's draft-angle dimension after double-click
in the View, including zero degrees. The annotation lies in a section normal to
an outer profile edge. The Relations picker inserts its existing driving
identifier, preserving signed angles and symmetric-side ownership.

H-Sweep exposes pitch as a one-turn axial dimension with the complete dimension
line offset beside the winding axis. It supports the ordinary inline dimension
editor and insertion into Relations.

Entering a Sketch frames its existing geometry instead of the entire scene.
Empty Sketches fit available background geometry; empty scenes use the monitor's
physical scale. This uses the common entry path for ordinary and embedded Sketches.
The other pending Sketches, available winding preview and preceding visible
body geometry remain passive context during drawing. Finish Sketch returns to
the same pending Properties transaction; Cancel retains the committed model.

See [Relations](../RELATIONS.md) and [H-Sweep](../HELICAL_SWEEP.md). These changes
reuse existing dimension identifiers and native data; no file-format change is
required. Shared container-placement behavior is unchanged. No new translated
UI strings were introduced; labels use existing dimension values and units.
