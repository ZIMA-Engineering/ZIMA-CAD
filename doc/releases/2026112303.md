# ZIMA-CAD 2026112303

## Modeling and Sketcher

- Closed spatial spline Sweeps retain the complete circular tool and subtract
  along every authored segment. The finite regression also verifies open and
  closed rectangular and elliptical sections.
- Regeneration preserves analytic Cylinder supports for owned path Points
  instead of replacing them with incomplete saved display data. Successful
  Sweeps no longer acquire a false unresolved-reference Tree state in the
  reported case.
- New 3D Curve/Sweep Points capture the clicked Cylinder position in the View,
  including translated and rotated Body/path frames. Planar reference entry
  retains ordinary Origin projection. Trimmed spline support recognition no
  longer crashes the tested three-point Sweep.
- Sketch Trim recognizes contact boundaries on coincident circular supports,
  preserving real contact points and independent constraints.
- Holes Properties uses the shared two-row Plane/Sketch layout and full-height
  Sketch action.

## Render

- Camera, Sun, Point Light and Spotlight markers use dimension yellow. Active
  Properties previews are cyan and remain visible through model occlusion.
- New Camera/light placement immediately offers the existing reference entry.
  The Camera Properties checkbox follows changes live and displays its output
  frame. The context-menu camera-view action retains its one-shot behavior.
- Spotlight adds a directional cone and configurable soft edge, with native
  storage, rendering, Undo/Redo and reopening. Sun remains parallel lighting;
  Point Light emits in all directions.
