# Windows 2026112804 - Grooves, source edits and Assembly modes

Status: published and verified. The [signed Windows release](https://github.com/ZIMA-Engineering/ZIMA-CAD/releases/tag/ZIMA-CAD-2026112804)
was built from commit `aa24aa112af7ae19b306bed514d4eca2d21d5e66`.
All three public assets were downloaded anonymously and matched the signed
local outputs. See the [release acceptance record](../verification/20261128-release-2804.json).

Sheet from Body prepares changed solid source history before refreshing the
exact attachment boundary. Valid Fillet-radius, size and placement edits retain
generated identities, corrections and independent sheet branches. A RIP lost
outside its trimmed sector leaves an unresolved association with its last valid
frames; it does not silently choose another face. See the
[measured source-edit matrix](../performance/20261128-sheet-source-edit-preparation.md)
for exact geometry checks, finite timings and unfolding/Explode coverage.

Part > Mechanics gains [Groove](../MECH_GROOVE.md): select a cylindrical material
face as Axis and a positioning plane as Face, in either order. The cylinder
determines the internal/external side. Rectangular and circular sections have no
angular placement parameter. Four reviewed DIN catalogue families provide 477
sizes; rectangular widths offer the documented H13 interval. Custom dimensions
remain available. The approved native extension stores the new typed feature in
the Part; existing feature definitions and the protected placement solver remain
unchanged. Older executables cannot read a Part containing the new feature.

Assembly navigation is organized into Sections, Mechanisms and Assembly. The
[Mechanisms application](../ASSEMBLY_MECHANISMS.md) is an empty preparation for
future motion definitions. It keeps construction geometry visible and does not
calculate motion, regenerate material or extend the Assembly file format.

Changed UI and the new Groove guide are available in Czech, English, German,
French and Russian, including authentic native screenshots in each language.
The website and packaged offline guides use identical generated files.

## Verification and limits

The local native Groove matrix passes 20 combinations and checks exact material,
source edits, persistence, last valid frames, Undo/Redo and failed confirmation.
Actual GUI creation/editing, mouse reference entry, whole-Origin replacement,
inspection, no-op/Cancel, catalogue width selection and both failed OK paths pass.
All thirteen mandatory sheet-branch gates pass locally. The Assembly-mode,
history-cursor, presentation, application-tools and translation gates pass.

All six start templates were rewritten and reopened with unchanged hashes.
The inch and millimetre New Document GUI suites passed in 43.75/42.90 seconds,
including initial editable context, ordinary commands and Skeleton insertion.
The committed-source candidate passed all thirteen mandatory sheet gates;
all 23 packaged GUI cases and the additional Groove, Keyway, confirmation
and translation contracts passed. Packaged native factory loads and the
signed archive smoke, including packaged FEM MP4 export/playback, passed.
The updater recognizes this public build as
trusted and current. The additional old selected-Point pixel failure is reproduced
on the unchanged 2803 executable and recorded in the Assembly-mode notes.
Protected user models and backups remain unchanged. The old TOYOTA project has
pre-existing unsupported versions and a missing dependency; this change does not
claim to convert or validate that project.

Windows and Linux share the implementation. Native Linux execution remains
unverified because no Linux host is available. The normal development launcher
remains the repository-root `zima-cad.bat`. These finite checks do not establish
exhaustive geometry or manufacturing certification.
