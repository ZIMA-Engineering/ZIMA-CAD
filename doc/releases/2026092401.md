# Windows build 2026092401

## Changes

- Modeling reference tables follow the shared reference-entry presentation,
  including numbered rows, independent input and inspection states, predictable
  resizing and command-specific removal behavior.
- The 3D Curve editor supports single-click point editing, explicit row selection
  for reordering, direction controls and correctly sized numeric fields on Windows.
  Curve points remain visible for attachment; editing highlights only the target.
- Whole-Origin reference entry publishes the scene once per completed operation.
  The measured imported-Part case improved from 3335 ms to 964 ms on the development
  machine; this is not a cross-machine performance guarantee.
- Sweeps expose persistent attachment endpoints and highlight their own axes.
- GUI text uses the system font by default, with the bundled font as fallback.
  Sketcher, View and Drawing technical text retain the ISO font.
- Hover is green and confirmed selection, inspection and previews are azure.
  Sketch buttons are white, confirmation checkmarks turn black on hover, and
  menus share consistent icons. Tree ordering remains available by drag/drop;
  redundant Move Up/Down context actions were removed.
- Sketch midpoint acquisition, selected-entity colouring, vertical dimension
  clearance and passive Assembly sketch display were corrected.
- The Applications menu has mode icons. The Window menu remains available for
  selecting documents when their tabs do not all fit.

The source also includes the already committed editable Sheet Transition and
Sheet from Body/DXF corrections since build 2026092301. See the feature documents
for their manufacturing limits and supported geometry.

## Verification scope

All five UI languages remain supported. This release does not add document-format
fields or change native filename extensions. The development launcher remains
`zima-cad.bat`; portable installations keep their own launcher and user data.

Release acceptance results and any remaining test limitations are recorded after
the committed-source package has been validated. Linux is not part of this build.

Known limitations from the development verification: the broader Section GUI
scenario expects a Drawing sheet/view Rename action that is not implemented in
that menu branch. The older nested-Body GUI scenario fails its active/passive
later-history assertion before the Sketch return operation. The focused return
scenario passes independently; these broader checks are not claimed as passing.
