# Windows 2026102803 — deferred aggregate physical analysis

This Windows release follows `2026102802` with a focused reduction of work on
the geometry-critical modeling path. Exact output-only aggregate properties are
calculated from a private snapshot after the model geometry is available.

## Changes

- Parts without a persisted Body Properties row no longer calculate aggregate
  mass, area, centroid and inertia while constructing ordinary history geometry.
- Existing Body Properties histories retain their established adaptive behavior,
  and a centroid used by later geometry still forces exact synchronous analysis.
- Explicit occurrence measurement uses its own exact analyzed snapshot instead
  of reading pending mass from the live occurrence.
- Closed nested Assemblies hydrate their native Part sources before Save-time
  physical analysis, preventing zero nested mass after reopen.
- Open nested Assembly source stamps include the calculated data generation, so
  changed child geometry invalidates stale parent physical values without
  creating history or evaluating Assembly Relations.

## Performance and rejected experiment

Five 24-operation synthetic Release samples retained identical geometry,
reference packets and native archive size while reducing foreground calculation
time by 5.2--11.2%. Exact completion on the private final snapshot then took
0.607--0.636 ms.

The representative protected Skeleton operations 1--22 measured
10.081--10.134 seconds versus 10.049--10.224 seconds on the unchanged release
baseline. That history already used adaptive deferral, so no Skeleton speedup is
claimed.

An experimental production route for batching independent Add operations was
removed. It took 14.626 seconds versus 11.329 seconds sequentially and produced
non-zero Boolean differences in the following Fillet. The linear evaluator
therefore remains the production authority.

## Compatibility and verification boundary

The implementation is shared by Windows and Linux C++. Native document format,
geometry precision, stable references, side identity, oldest-face ancestry,
Undo/Redo and container placement are unchanged. Qt remains pinned at 6.11.0
and OCCT at 8.0.1 on both platforms.

Focused Release checks pass for Body Properties, measurement demand, STEP
parallel properties, cache storage, measurement commands, history recovery,
solid-state history, Boolean split edges, Save/Save As, nested mass,
Regenerate, concurrency, Undo/Redo and all five localization catalogs. The
Assembly profile test reaches a pre-existing shared Axis Feature rendering
failure after the affected source-refresh checks pass; the same failure occurs
with the unchanged release executable. Native Linux compilation and execution
require their separate host acceptance.
