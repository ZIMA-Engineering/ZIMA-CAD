# Windows build 2026100903

## Scope

This build includes the compact 16 mm wide, 12 mm deep native corner gusset
definition from the unpublished 2026100902 candidate. The symbolic wall is
`t/2`, cavity transition radius is `t`, and opposite projecting transition is
`t/4`. Stock and Bend thickness remain unchanged. Ordinary planar Form and
shared Shell/Fillet parameters are unchanged.

It repairs actual workspace Pattern/Mirror creation on the user's `12.prtz`.
Preparing a rounded copy uses the exact added and removed material delta,
avoiding two redundant Boolean operations and invalid transition trims.
Rejected copies preserve the document and report the existing localized kernel
error. Rigid direct copies reuse immutable source geometry and non-destructive
Booleans; reflected copies still own their transformed geometry.
The settling pass reuses a complete unchanged Form-copy result when no external
operand is required, retaining all existing fingerprint and reference guards.
Previously saved corner packets receive the new axis on explicit regeneration;
their authored-input fingerprints remain stable and opening does not calculate.

Corner Form publishes an axis through the source Sketch centroid along the
actual extrusion path, including its planar Up To endpoints. Collinear
two-sided paths form one whole-profile axis with 1 mm physical end overhangs;
original cap/face side references remain separate. The old arbitrary placement
axis is removed. The new axis has no picking points and follows Pattern/Mirror.
Unbend shows no corner geometry, spatial forming axis or manufacturing symbol,
in either View or Drawing: this gusset is formed during bending. Bend Back
restores the shape and axis, including copies created while unfolded. Planar
Form retains its flat manufacturing symbols. Pattern/Mirror previews now hide
the same parameter seams and smooth joints as the ordinary View. A forming-tool
preview also excludes split fragments whose persisted parent is an edge of the
supporting stock, while retaining fragments of the tool itself. These filters
change only transient display, not model geometry or persisted references.
Source-shape dimension editing remains deferred.

Ordinary disjoint in-Body Pattern operands now enter the Body Boolean together,
preserving all original topology references. Overlapping or touching bounds
retain sequential processing. A 50-occurrence synthetic additive Pattern
measured 2.872 / 1.434 seconds (sequential / batch); its subtractive counterpart
measured 2.412 / 1.122 seconds. These are individual host measurements. A separate
corner Form batching experiment passed exact geometry/identity checks but did
not improve total calculation time and was removed. See the
[performance record](../performance/20261009-form-copy-batching.md).

The proposed solid-based pocket is recorded as a next investigation using
`Projects/20-FORM.prtz`; it does not replace the working Ventilation Window in
this build.

## Verification

The final focused Windows matrix passed all 18 checks in 471.69 seconds:
native contracts, transactions, workspace creation/editing and queries, planar
and corner Form, six corner copy distributions, eight ordinary batching cases,
catalog validation and the corner GUI lifecycle. The broader ordinary copy GUI
and editable Pattern-dimension checks also passed. The final stock-fragment
preview correction passed command/query checks and the 183.63-second corner GUI
lifecycle. Its preview and Unbend captures were visually inspected: long copied
stock fragments are absent, and the unfolded sheet has no corner symbol or axis.
Two earlier GUI probes failed during support entry, before the copy preview;
the test now parks the native cursor, finishes camera transitions and checks
the common ordered picker with RMB cycling before LMB confirmation.

Independent checks cover strict BRep validity, volume, area, centroid, inertia,
two-way geometric differences, complete topology/side identities, original
reference immutability, source-axis geometry, save/reopen, regeneration and
Undo/Redo. Rejected disconnected/overlapping configurations leave the document
unchanged. Changed copy counts invalidate reuse; unchanged OK creates no revision.

Both embedded definitions in the original `Projects/12.prtz` passed Pattern
and Mirror creation. The compact definition also passed its default X Pattern
of four occurrences at 20 mm spacing. Cold timings on this more complex file
were 9.1–11.2 seconds for two-occurrence Pattern/Mirror, including recalculation
of both independently stored definitions. The larger definition's third forward
occurrence intersects the other Form and was correctly rejected atomically;
the reverse distribution succeeded. The original file remained unchanged.

Complete corner GUI confirmation measured 1.700 seconds. Its two-occurrence
Pattern/Mirror measured 6.450 / 6.423 seconds. Unbend exposed zero centroid axes;
Bend Back restored one. These observations are not universal timing guarantees.
The final repeated large ordinary batching measurements were 2.937 / 1.443
seconds additive and 2.489 / 1.118 seconds subtractive (sequential / batch).

Localization review found no new user-visible strings or catalog keys; existing
errors continue through the shared translation path. All five catalogs were
validated. No native schema, dependency pin or protected shared placement change
is introduced. One shared C++ implementation uses OCCT 8.0.0. Linux native and
GUI execution remain unverified.

The final picker test, including the common candidate list and RMB cycling,
passed in 80.00 seconds. Complete corner confirmation measured 1.737 seconds;
Pattern/Mirror measured 6.483 / 6.503 seconds. Evidence is retained in
`build/form-diagnostic/corner-preview-candidate-*.log`.
