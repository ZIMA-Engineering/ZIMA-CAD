# Windows 2026112602 — Vector profiles and modeling interactions

Status: signed Windows release published and independently verified. See the
[publication evidence](../verification/20261126-windows-2602-publication.json).

- Insert DXF into the Sketcher as an embedded block and explode it through the
  ordinary native symbol operation. Insertion commands are named Symbol.
- Extrude supported filled SVG geometry while keeping the original editable
  image. Image Properties explicitly controls participation in solid profiles.
- Load and embed a TTF/OTF font, retain editable text and calculate exact private
  profiles for extrusion. Repeated height changes reuse bounded preparation caches.
- Trim technical hole-thread surfaces against the actual drilled/chamfered solid,
  including cylindrical entrances. A plain hole uses its authored hole diameter.
- Drag the purple container origin within its existing placement constraints.
  The separate rotation grip remains available. Plane selection accepts the
  container's XY/XZ/YZ through the shared View field and arrow; overlapping datums
  remain available through the ordinary right-button candidate cycle.
- Keep single-row plane fields readable without scrollbars. Helical Sweep has
  sufficient field width and a compact Sketch button label.
- Add sphere-center coincidence mates, white Default Origin in component
  Properties, and Create Component followed by placement and activation.
- Author Project curve and Wrap curve in Assemblies using exact read-only
  component faces. Definitions and exact calculated curve results live in `.asmz`.
- Calibrate the K factor from a signed correction for one measured bend, including
  inch input. The correction modifies the pending K factor, then the ordinary
  Properties OK commits it.
- Start the Part Surface tools with General Surface, show dimension lock/unlock
  icons and use a taller Windows application mark.

All affected UI strings have Czech, English, German, French and Russian
translations. The implementation is shared C++; native Linux execution is not
verified in this Windows work session.

The supported SVG subset and finite font, geometry, persistence, manipulation
and GUI coverage are documented in the
[verification record](../verification/20261126-vector-profiles-assembly-calibration.md).
This is not a complete SVG painting engine. Unsupported painting is reported
explicitly. Existing multi-face external Wrap limits remain.

The 407 affected factory opening-thread definitions were regenerated and checked
with the native implementation; the
[factory evidence](../verification/20261126-opening-thread-factory.json) records
per-file hashes, volume and mass. Start-template GUI creation was verified.
User production documents were investigated only through isolated copies.

Take geometry in the Sketcher is explicitly deferred and is not part of this
release. The five further development ideas are recorded in the
[post-release discussion](../POST_RELEASE_IDEAS_20261126.md).

The normal Windows development entry remains `zima-cad.bat`. The portable build
carries its own native runtime and installation-root launcher.
