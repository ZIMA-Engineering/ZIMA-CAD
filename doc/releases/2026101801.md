surface/Sketch-plane intersections. Moving a Sketch along its normal retains
available source references. The ordinary reference UI offers individual curves,
vertices and axes; complete side-on cylindrical/conical bands offer both outline
generators independently. Whole Face picking is removed from this UI. Exact
shaft-thread outline supports are persisted during calculation without exposing
cosmetic thread surfaces as container placement supports.

Coupled symmetric diameter and chamfer-angle edits retain their directed branch
and source contacts. Impossible intermediate edits reject atomically. Junction
and axis-contact work preserves native point ownership; coincident contact does
not require a redundant dimension. The Sketch verification notes record the
finite interaction matrix and remaining unrelated GUI limitations.

Shaft threads without an explicitly selected entrance chamfer begin at the
authored cylinder end. Explicit chamfer references retain their existing meaning.
Both physical rim identities and exact root/runout outlines survive native
save/reopen. Existing factory thread Parts have been cold-recalculated and
verified with this implementation.

Construction/helper curves are green in the active Sketch and the edited
feature's profile annotations. Finished and passive profiles retain their normal
centerline/helper colors. Hover and selection remain azure, as do ordinary
feature-preview wires. Actual picking of the short construction axis in the
user's final fitted-bolt Revolution passes overlap cycling and zoomed selection.

Engineering Tables now include 24 editable fitted bolts: all twelve existing
sizes for each of ČSN 02 1111 and ČSN 02 1112. They use the approved native
pattern, separate actual fitted and thread diameters, n6 metadata, appropriate
default lengths, thread lengths and runouts. Two native representative Drawings,
five-language main images and horizontal white thumbnails accompany them.
Historical-source review warnings remain; this is not complete numeric
certification against the current standard editions.

## Verification and limits

- Native Sketcher, dimension, external-reference and shaft-thread suites pass.
  Coverage includes 96 coupled diameter/angle configurations, atomic rejection,
  240 projected-outline configurations, 288 trim variants, the 128-case FORM
  sweep matrix and 64 external point/circle contact variants.
- Actual GUI reference selection passes for both thread outline sides and the
  end rim in a Sketch displaced 100 mm from the source. Short-axis picking and
  active/passive/editing-preview construction colors pass targeted GUI checks.
- All 24 new Parts pass independent BRep, dimensions, mass, Sketch constraint
  and thread-limit checks. Their 72 successive length edits pass independent
  geometry checks, Undo/Redo and save/reopen. Both native representative Drawings
  have resolved dimensions; localized Czech, French and Russian layouts were
  visually inspected, including white horizontal thumbnails.
- A cold calculation of 212 existing affected factory Parts preserves authored
  history, role Bodies, BRep volume/area and reference identities through native
  save/reopen. All 211 existing and 26 new/reference thread Parts pass saved and
  regenerated extent/analytic-outline checks. Eleven dependent Drawings retain
  their 101 dimension identities and values. Native FORM definition, command and
  spatial/flat geometry suites pass against the installed library.
- Five-language catalogs and actual language-switching GUI checks pass.
  No native schema, extension, OCCT version or protected placement-solving
  contract changes are introduced. Windows and Linux share the C++ implementation.

The broader UI suite still encounters its unrelated native Qt hover-style
assertion; it is not reported as passing. Comprehensive oblique/trimmed general
surface outlines, every related tangency interaction, the unrelated Coincident
circle preselection GUI case and Linux runtime execution remain unverified.
