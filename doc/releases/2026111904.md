# ZIMA-CAD 2026111904

## Changes

- Keep independent sheet-metal branches separate at point, edge and face contact,
  during overlap and containment, and after cuts. Preserve concurrent calculation.
- Retain current branch edges, endpoints, material sides and attachment ownership
  for Flat, Bend and Profile, including the midpoint reference.
- Preserve separate material through Unbend and Bend Back. Publish current
  topology after batch Cut and complete compound sheet-group boundary ancestry.
- Calculate Line Bend separately on each material branch and retain that
  ownership through following cuts, Unbend and Bend Back.
- Enforce eleven native/GUI sheet regression gates in both platform package builders.

The [verification record](../verification/20261119-independent-sheet-branches.md)
defines the executed Windows matrix and limits. Older references created by
cross-branch unions may require new models; no legacy retargeting path is added.
View-only Flat end correction remains a future design, not a delivered feature.

release acceptance are pending. Native Linux execution remains a separate host
gate. Versions 2026111902 and 2026111903 remain unpublished.
