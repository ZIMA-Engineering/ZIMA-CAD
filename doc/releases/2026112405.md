# ZIMA-CAD 2026112405 — Windows

This update fixes Wrap sketch placement and interaction, constrained polygon
relief calculation, and the material direction of relief on native cylinders.
It adds Project relief and Wrap Split, repairs the saved cylindrical Projection
case, and makes the FEM player and helical profile controls consistent.
Windows publication is pending the
committed-source package, signature and public-download acceptance gates.

- Project sketch, Project relief, Wrap sketch and Wrap relief have separate
  commands in that order below Twist. Existing Extrusion operations remain.
- Committed cylindrical curves agree with the cyan preview, including anchors
  away from the native seam. Curves use ordinary Sketch width, support hover and
  feature selection, and do not show permanent black endpoint markers.
- Relief accepts a signed Correction: positive adds material and negative cuts
  into the selected face. Direction checkboxes and separate Add/Subtract buttons
  are removed. Both outer and bore surfaces retain their actual material side.
- Constrained polygons retain their construction and equality supports during
  profile extraction, fixing the reported invalid Sketch constraint failure.
- A cylinder, cone or sphere normal driver prevents automatic Orientation on
  later position references. Explicit manual Orientation remains available.
- All changed UI text is localized into Czech, English, German, French and Russian.
- H Curve and H Sweep place their initial circle/point button beside the shared
  plane selector. Plane selection and offset update the cyan plane preview.
- The FEM player displays every setting immediately and retains its size during
  playback, setting changes and video export.
- Section creation uses the consistent Create section label and section icon.

Wrap uses the same Sketch / Split / Surface labels as Projection. Cold-open hover
uses the authored wire; double-click additionally displays the original planar
Sketch, the wrapped result and dimensions. The reported cylindrical Projection
failure is repaired by joining artificial section pieces before endpoint naming.
Regenerate an existing model to replace
previously cached geometry with the corrected result. User originals and personal
settings are preserved.

The approved native extension adds the Wrap Split output and Project relief's
height. Start templates are rewritten with the current serializer and verified
through actual new-document creation. All 1,190 factory native assets load.

See the [finite verification matrix](../verification/20261124-wrap-fixes.md) and
[Project relief contract](../design/PROJECTION_RELIEF.md).
Native Linux execution and a dedicated interactive external-Skeleton/nested-
Assembly Wrap matrix remain unverified.
