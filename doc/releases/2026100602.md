# Linux 2026100602 — shared OCCT 8 kernel

Status: signed Linux release published and verified on 2026-10-06.

Linux now uses **OCCT 8.0.0**, matching the Windows dependency pin.
Both platforms use the same surface-intersection implementation; the temporary
OCCT 7.x sequence/output-parameter branch is removed. The Linux SDK builder
pins the V8_0_0 archive and verifies its SHA-256. Its SHA-512 was independently
compared with the pinned Windows vcpkg port. CMake requires OCCT 8.0 or newer,
and presets/candidate builds explicitly select the intended SDK config directory
so a cached old package cannot override it. The shared-code/dependency alignment
requirement is recorded in AGENTS.md. No UI strings, document formats or
protected shared container-placement contracts changed.
