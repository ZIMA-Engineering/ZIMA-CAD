# ZIMA-CAD 2026091903

Global Settings now offers a complete interface restart after changing the
language. Menus and panels remain consistently in the original language until
restart; saved native documents reopen in the newly translated workspace.
Declining or cancelling restart preserves the open documents and retains the
language preference for the next startup.

Closing the main application now checks all open documents and offers Save All,
Discard and Cancel. This includes Parts, Assemblies, Drawings and drawing
templates. A failed or cancelled save keeps the application open. Pending
editing dialogs must first be completed or cancelled.

See [application lifecycle](../APPLICATION_LIFECYCLE.md) for the interaction
contract. No native document format or model regeneration behavior changes.
Linux was not rebuilt. Known title-sketch and first-open file-list
issues from 2026091901 are not claimed as resolved.
