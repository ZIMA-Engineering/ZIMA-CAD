# Windows 2026102401 — OCCT 8.0.1

This signed Windows release upgrades the shared native
kernel from OCCT 8.0.0 to 8.0.1 with the existing Gauss integration repair.
Windows and Linux recipes pin the same source; native Linux acceptance requires
the Linux host.

The complete Windows application/test build and Debug/Release SDK build pass.
All seven analytical integration cases pass on the old and new kernels.
The broad Windows matrix reports 275 passing and 42 failing tests; all 42
failures reproduce on the current implementation with 8.0.0. They remain open;
this release does not claim an entirely passing suite or universal geometry
coverage. Native/GUI, persistence, factory and timing evidence is in the
[upgrade record](../verification/20261024-occt-801-upgrade.md).

The change repairs the large CLI test's Windows build option and aligns two
verification scenarios with existing GUI controls. No ordinary property dialog,
modeling algorithm, protected placement contract or native document schema is
changed. Existing factory assets and start templates are retained; private
configuration, projects and library edits are excluded from packaging.
The repository-root development launcher remains `zima-cad.bat`.

Loft (Czech UI name `Přechod / Loft`) is subsequent work and is not included in
this kernel release.
