## Format and verification boundaries

Keyway payload version 2 and Sheet from Body payload version 2 require current
native definitions; there is no legacy loader. No factory or protected Toyota
document contains Sheet from Body. The converted user box was reconstructed on
an isolated copy, and production originals were not overwritten. Start templates
were regenerated and checked through normal New Document creation.

This is a Windows release. Native Linux execution remains unverified. These tests
provide finite regression evidence, not exhaustive geometry certification.
An incorrectly routed controller run entered the broad startup suite and failed
its old assertion that the first failed Fillet OK closes and commits. The agreed
contract keeps that first failure private until a second unchanged OK. Only the
local runner's controller entry flags were corrected; the broad startup suite is
not claimed as passing and its assertion remains outside this change.
