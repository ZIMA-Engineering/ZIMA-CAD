# ZIMA-CAD 2026111906 — Windows

## Changes

- Preserve separate sheet-metal branches when they touch, overlap or contain
  each other. Keep their parallel calculation and independent attachment sides.
- Repair Fillet routes on symmetric and two-sided extrusions, including the
  line–arc–line case, and allow the resulting faces in Extrusion and Sheet from Body.
- Recalculate sheet conversions after upstream history edits; retain editable
  independent sheets when their source is removed. Bound output corrections
  display a user-relative zero; attachment corrections remain hidden.
- Keep invalid modeling definitions after a second unchanged OK, including
  Assembly cuts, with one Undo transaction and a visible unresolved state.
- Preserve angled Parallel together with C through Sketch trimming.
- Extend virtual corner rounding and add Curve fillet for two finite native
  curves, exact trimming and point-based tangency, without an automatic radius
  dimension. Lines, arcs, elliptical arcs and open splines are supported.
- Edit Sheet Profile Flat-end corrections through ordinary dimensions in the
  View. Preserve replacement constraints and propagate the corrected edge to
  the next Bend; planar Up-to limits account for material thickness.
- Retain the previous embedded Sketch, intersection, Corner Closure and
  adaptive Properties repairs. New labels and diagnostics cover all five UI languages.

See the [verification matrix and limits](../verification/20261119-modeling-completion.md).
The product retains shared Windows/Linux C++ and the existing native format.
Linux build and runtime acceptance remain a separate host task.

## Distribution status

Committed-source packaging, signing and anonymous public download checks are
required before publication. Both platform packagers now build and require the
Bend end-constraint test alongside the other sheet-branch gates. The modeling
implementation is unchanged from 2026111905. Builds 2026111902–2026111905 remain
unpublished.
