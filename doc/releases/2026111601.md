# Windows 2026111601 — Safe ZIMA route ends and Sketcher repairs

Status: Windows release candidate. Publication acceptance and immutable asset
digests will be added only after committed-source packaging, signing, smoke and
public-download verification pass. Native Linux acceptance remains a separate
host gate.

This release makes every open ZIMA Fillet and Chamfer route end explicit. Both
physical end vertices and independent `Cut` / `No cut` decisions are persisted.
A new or changed end defaults to `No cut`, which stops the treatment at the
authored route boundary and prevents a generated tool from continuing through
material to an unrelated surface. Double-clicking a purple open-end node label
offers the two localized choices. Closed routes do not expose endpoint choices.

Automatic `Cut` resolves the complete local planar and curved boundary and
classifies the retained material side independently at both ends. The result
therefore supports opposite end directions, asymmetric pockets and bounded
contact with an existing Fillet or Chamfer without tunnelling through the Body.
Equal-distance, A x B and A + angle Chamfer use the same endpoint and containment
rules. Complete circular A x B Chamfer remains supported. The analytical azure
preview and final calculation use the same endpoint decision.

The release also repairs the reported adjacent interactions. Shaft Thread
double-click inspection shows the thread length as well as its diameter. Opening
A x B Chamfer Properties retains shaded display. A valid Shell following three
Fillets reaches the existing inner-offset fallback when OCCT throws in its direct
open-face thickening attempt. Invalid dependent treatments keep their last-valid
Body, prune only unresolved references and remain editable or deletable with
Undo/Redo and save/reopen.

Sketcher no longer adds a redundant duplicate contact when a circle endpoint is
already incident. Repeated point dragging can change both the angular position
and radius when degrees of freedom permit it; fully constrained or impossible
edits remain rejected without modifying the document. Parallel inference from
native and external references, Trim, dimensions, Undo/Redo and save/reopen are
covered, and the ordinary Image command is enabled.

Part native format 53 / JSON 77 stores the route-end vertices and choices
explicitly. The format is current-only. All 1,058 repository-owned Part-based
templates, FORM definitions, symbols, title blocks and native fixtures were
calculated, saved and reopened with the changed implementation before their
verified outputs replaced the repository copies. No legacy loader, sidecar or
duplicate platform path was added. The implementation remains shared C++ with
Qt 6.11.0 and OCCT 8.0.1.
