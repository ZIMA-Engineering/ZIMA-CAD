# Windows 2026100603

This release uses the shared native C++ implementation and OCCT 8.0.0.

## Behavior

- Connected direction constraints and tangent-chain dimension edits preserve
  their dependent geometry. Supported failed line/arc drags receive a bounded
  simultaneous equation seed, verified by the ordinary solver.
- Planar angular labels remain on their dimension circle, with an arc extension
  outside the measured sector. Radius/diameter text grips also position arrows.
- Slot creates two equal semicircular arcs and tangent connecting lines from
  two centre clicks and a perpendicular radius. Both axes and oblique
  construction lines can provide centre symmetry.
- Tools > System Setup provides initial configuration, matching mm/inch native
  templates and optional desktop integration through the existing service.
  Completion/skipping lives in shared settings outside version directories.

See [Sketcher](../SKETCHER.md), [System Setup](../SYSTEM_SETUP.md) and
[Desktop integration](../DESKTOP_INTEGRATION.md). Documentation is English;
new UI strings are translated into cs/en/de/fr/ru. Native formats and the
development `zima-cad.bat` entry point are unchanged.

## Source verification

Eleven focused contracts passed in the 106.79-second run, with the new setup
test initially exposing an incorrect test-path assumption. After correcting
the test, System Setup passed in 3.57 seconds. The checked suites cover portable
settings, translation coverage, Sketch solving, Sketch grips, drawing measurement
UI, dimension layout, measurement calculations, Sketch dimension entry, arc
directions, Slot GUI and desktop integration.

The setup GUI checks both native template presets through New Document and
save/reopen, active editable Part Body, mismatch rejection, menu Cancel,
first-launch skipping, isolated registration and all five languages.
Slot GUI covers horizontal, vertical and oblique symmetry, preview, radius,
Escape and native save/reopen. Problematic user sketches are retained as native
regression data; the user's original document is not overwritten.

Packaging must independently pass the repository-owned committed-source,
dependency, archive, signed smoke and public-discovery gates. Windows checks do
not establish Linux GUI or desktop acceptance.
