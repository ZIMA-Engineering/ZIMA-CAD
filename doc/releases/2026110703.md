# Windows 2026110703 — ZIMA Fillet and Chamfer nodes

Status: signed Windows release published and publicly verified at
`2026-11-07T22:42:45Z`.

[Download the signed Windows release](https://github.com/ZIMA-Engineering/ZIMA-CAD/releases/tag/ZIMA-CAD-2026110703).

Fillet and Chamfer Properties now expose the two supported engines, **ZIMA**
and **OCCT**. Selected segments are direct removable items rather than route
branches. The former manual end-face column and route-level controls are not
shown. Clicking an already selected segment in the View removes that logical
item, while the analytical preview retains the complete selected curves and
shows their terminal and continuation nodes in azure.

The exact ZIMA builders now complete constant-radius Fillet and symmetric
`A x A` Chamfer at inner and outer two- and three-branch nodes. They also cover
the staggered two-box shoulder. Segment bands are calculated first, node
connectors second and the signed CUT/FUSE result last, independent of selection
order. Unsupported node geometry remains on the established OCCT fallback.
Asymmetric `A x B` and `A + angle` Chamfer is restricted to one connected open
line so multiple independent chains cannot silently choose conflicting sides.

Stable authored edge identities survive source resizing, native save/reopen,
cold recalculation and Undo/Redo. Current Boolean descendants remain resolved
from the authored item. Fixtures cover two staggered boxes, a blind pocket, a
through notch and a side-reaching box-minus-box pocket.

The focused native/GUI contracts and five-language catalogs passed. The clean
committed-source candidate and finalized signed package each passed native
Windows smoke; candidate smoke loaded all 1,185 committed factory native assets
without a failure. The native file format, start templates, factory library,
shared placement contract, geometry-side contract and Qt/OCCT 8.0.1 pins are
unchanged. Native Linux compilation and execution remain a separate host gate.
