# ZIMA-CAD 2026092101 — Windows

## Changes

- Complete Czech, English, German, French and Russian interface dictionaries,
  localized object naming, compact Part property dialogs, localized drawing
  title blocks and the embedded ZIMA-Engineering logo.
- File commands follow the toolbar order: F1 New, F2 Open, F3 Save, F4 Save As;
  F6 closes the current document. Existing Ctrl shortcuts remain available.
- About includes the company logo, author Ing. Vladimír Zima, contact email and
  website, with localized introductory text.
- New Part offers Modeling and Sheet Metal modes. New Drawing lists installed
  formats and loads the corresponding frame and localized title block. Drawings
  created from Parts or Assemblies start with the configured A4 format.
- Mirror and Pattern keep their origin visible during reference entry and move
  it with the numeric preview, including nested Assembly occurrences.
- Colors and Appearance opens on the right with tighter palette spacing. Every
  appearance supports 0–100% transparency, including custom palette persistence.
  Transparent surfaces render after opaque surfaces and in depth order. The
  basic Skeleton color is muted purple with 70% transparency.
- Hidden Assembly components remain gray instead of receiving false missing
  reference warnings. Actual unresolved references still report errors.
- Component origins are hidden during ordinary Assembly viewing. Insertion and
  component Properties show the edited occurrence's own origin. Other origins
  are explicitly revealed through Origin selection or the Tree's Show/Hide
  origin menu, which no longer exposes unrelated component operations.

The Skeleton color is preparation for the agreed Skeleton workflow; this release
does not implement filename-based Skeleton insertion, history or mass exclusion.
There is no appearance format migration: transparency uses existing ARGB values.
Linux is not rebuilt by this Windows release.

## Verification

Seventeen focused native and GUI contracts passed across the initial suite and
its final rerun: appearance persistence/rendering/commands, shared UI and hidden
reference validation, translations, viewer, native documents, closed spline
extrusion, component Properties and origin menus, Mirror/Pattern kernel and GUI,
application lifecycle, sections, new-document options, Drawing view controls,
view breaks and thread drawing. The stale Drawing harness was rebuilt before
its final successful checks. Transparency is checked with actual OpenGL frames,
including mesh-order independence and fully transparent foreground geometry.

All five dictionaries contain the same 1,501 non-empty keys. Seven Windows
packaging checks and all 16 publisher checks passed; two Linux-only packaging
checks were skipped. Evidence: `build/release-2101-*.log`.
