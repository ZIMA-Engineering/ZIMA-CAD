Status: candidate preparation; publication and packaged acceptance are pending.

## Behavior

Sheet from Body creates independent native Flats and Bends in the active editable
Body. An empty Body receives geometry from a preceding source Body. In the same
Body, the first generated Flat replaces the solid result while preserving its
preceding history. Later source changes do not drive the generated sheet.
Part sheet settings are retained; unsupported connected transitions reject the
pending batch rather than committing a partial reconstruction.

System Setup uses the natural height of its applicable pages and the Czech name
`Nastavení systému`. Documentation is English; changed UI messages are translated
into Czech, English, German, French and Russian.

See [Sheet from Body and DXF](../SHEET_EXCHANGE.md) and
[System Setup](../SYSTEM_SETUP.md).

## Source verification

Fourteen affected native/GUI suites passed on Windows with Qt 6.11 and OCCT 8.0.0.
They cover independent native/STEP conversion, actual three-edge corner-blend
rejection, material states, Flat/Bend commands, history recovery, multiple Bodies,
solid states, translations and factory templates. All native start templates were
regenerated through the current CLI, with identical empty definitions.

Private copies of `01.prtz` passed both new-Body and same-Body GUI scenarios,
including picking, all five languages, Cancel, generated-feature Properties,
middle-button OK, Undo/Redo and DXF. Its side-face branch produced two Flats and
one Bend at the Part's 1 mm thickness. Cold regeneration and a source-length edit
preserved the generated sheet. The original user document was not overwritten.

The development entry point remains `zima-cad.bat`. Windows verification does
not establish Linux build, GUI or desktop acceptance.
