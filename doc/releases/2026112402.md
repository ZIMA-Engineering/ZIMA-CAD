# ZIMA-CAD 2026112402

## Mirror and Family Table

- Mirror Properties highlights its selected plane, including Body Origin planes.
  Tree icons match the command in light and dark themes. Ordinary selection uses
  the shared preview wire without topology-point markers.
- Mirrors inherit source Body and face appearance. Explicit copy appearance takes
  precedence; View, Render and exchange output share the same resolution.
- Original and mirrored Bodies can form opposite-presence Family variants for
  Assembly insertion. Extended checks cover both variants, regeneration and
  native persistence. Sparse reference packets retain their exact geometry across
  repeated saves without relying on ephemeral calculation evidence.

See the [Mirror/Family verification](../verification/20261124-mirror-family-presentation.md).

## FEM

- Failed condition submission now displays its error beside OK/Cancel. A second
  unchanged OK retains the failed definition for later repair. The red condition
  and its diagnostic survive save/reopen and Undo/Redo; meshing and calculation
  reject unresolved inputs. Successful repair clears the error.
- Locked placement rows accept the existing Origin planes correctly. Committed
  projected conditions display the projected region; their source Sketch remains
  available while editing. Repeated FRONT/BACK changes retain the intended plane.
- Projected condition curves use conformal mesh partitions at surface boundaries
  and intersections. The reported `50.prtz` edge-recovery failure now meshes at its
  original settings, without reducing geometric accuracy or changing the CAD Body.

The approved native extension adds optional FEM error metadata. Current valid
definitions and format identifiers are unchanged. See the
[FEM verification](../verification/20261124-fem-condition-and-mesh-repairs.md).

## Modeling and Drawings

- Exact ZIMA oversized fillet corners support a main radius larger than the
  existing corner radius. The verified planar line/arc/line family includes
  nonperpendicular main edges, native reference ancestry and a matching lightweight
  preview. This release also includes the preceding cylindrical/toroidal runout
  and Fillet regeneration repairs.
- Drawing diameter and linear dimensions accept the supported cylindrical
  silhouettes, including independent rounded ends and axis-to-outline dimensions.
  Section references survive Part regeneration; linear dimensions on supported
  planar Section boundaries remain associative.
- Feature relief between target surfaces and signed correction is included.
- The Part Body-list command panel exposes Create render and Create section.
  Multiple Part Render definitions appear in the Renders group below Sections.

See [oversized fillets](../verification/20261124-fillet-route-retention.md),
[Drawing silhouettes](../verification/20261124-drawing-cylinder-diameter.md),
[target-surface relief](../verification/20261123-feature-surface-relief.md), and
[Render/Section commands](../verification/20261124-render-group-and-section-command.md).

## CAM checkpoint

The native calculation core, setup window, translucent stock, machine editor,
CAM library paths and editable generic tool/machine/vise examples are included.
Tool Parts use `.toolz` and ordinary Body ownership; the sample cutting geometry
is yellow with a red shank. Vise contacts are named native Sketches.

This is the verified [setup](../verification/20261124-cam-setup-ui.md) and
[library](../verification/20261124-cam-library-definitions.md) checkpoint.
Complete tool/operation editors, the generic NC pane, stepping UI and oriented
clamping exclusion/grip verification remain pending. Unchecked Sketch clamping
is still rejected. Assembly Render scenes remain future work.

## Verification and protected data

Focused native and GUI checks cover the changed operations, persistence,
Undo/Redo, shared confirmation, five languages and both themes. Detailed matrices
and pre-existing broad-suite failures are recorded in the linked verification
notes; no exhaustive geometry coverage is claimed.

All 172 Toyota project originals retain their hashes and have a verified backup.
Both Drawing copies reopen successfully. Seven Part copies and one Assembly copy
remain unsupported, identically to published Windows 2026112303; their modeling
behavior is unverified. No original or legacy file was converted.

Native Linux execution is unverified. Windows publication is pending the
committed-source package, signature and public-download acceptance gates.
