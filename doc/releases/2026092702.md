# ZIMA-CAD 2026092702

Status: Windows release preparation; acceptance and publication pending.

## Boundary Surface

- Adds the Modeling **Boundary Surface** command, its vector icon and one shared
  creation/editing properties dialog with four boundary references.
- Accepts individual Sketch curves, complete open Sketch chains and 3D Curves
  in perimeter order. The installed OCCT kernel generates the interior surface.
- Validates source order and ownership, perimeter closure, intersections,
  geometric tolerance and resulting shape validity. Invalid edits do not commit.
- Preserves semantic topology ancestry, native source references, explicit
  regeneration, rollback editing and Undo/Redo. Unchanged OK creates no new
  calculation or transaction.
- Includes Czech, English, German, French and Russian UI text.

The result has no material thickness. Sheet conversion, unfolding, extrusion
up to the surface, editable interior grids and tangency control are deferred.
The command consumes source geometry and does not change shared container
placement. See [the command contract](../NETWORK_SURFACE.md).
