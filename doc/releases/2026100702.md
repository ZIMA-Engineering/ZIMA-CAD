# Windows 2026100702

Status: source preparation; signed publication acceptance is recorded after the final gates.
Tag: `ZIMA-CAD-2026100702`.

This build makes the actual FORM 2D Sweep radius and supplementary-angle
dimensions editable with immutable external supports. Unlocked driving values
follow permitted grip movement. Native circle endpoint tangency has independent
contact equations, allowing a segment anchored to an external point to retain
C+T during subsequent radius, length and angle changes.

Changing a placed Extrusion/Revolution container frame reprojects its owned
Sketch references before returning to Sketcher. Unusable changed projections
are removed with their dependent relations in the pending edit. Valid sources
remain immutable. Cancel, OK, native persistence and Undo/Redo retain their
existing transaction ownership. The protected placement solver is unchanged.

Surfaces from solid retire the preceding solid's automatic axes/path helpers
from ordinary Part display. Original reference packets, authored construction
axes, independent Bodies and rollback input datums remain available.

The native equation matrix covers 128 FORM variants with 1,920 successive
actions and 64 external-point/native-circle tangent variants. All 15 targeted native, GUI and localization suites passed. Windows GUI checks
exercise actual FORM dimensions, grip movement, endpoint capture, embedded
Sketch return and transaction/persistence behavior. Detailed applicable variants
and limits are in [FORM Sketch editability](../FORM_SKETCH_EDITABILITY.md).

Documentation and the user manual are English. No new user-visible text is
introduced; Czech, English, German, French and Russian catalogs passed source
coverage, key/placeholder validation and actual translated dialog checks. No native file-format or Windows/Linux modeling split is added.
User settings, working FORM documents and backups are excluded from Git source.

Linux execution is not established by Windows checks. The broader suite retains
unrelated baseline failures documented in the preceding release: Extrusion Limit
expected 20 but produced 20.635083; Surface Profile hidden-sheet geometry/picking;
and Boolean Assembly access violation. This targeted acceptance does not claim
that the entire repository-wide test suite passes.

The final conservative draft-ownership check also passed both existing owned-profile
reference and new placed-reference GUI suites (19.36 s and 7.62 s).

Signed committed-source packaging, dependency/archive/native smoke, production
trust, packaged GUI checks and remote asset/update discovery are pending.
