# Windows release 2026093007

## Changes

Saved Body-measurement centroids can drive later feature placement through their
point, axes, planes and whole Origin. Eligibility follows the measured history
boundary; upstream and self-references cannot use their own future centroid.
The shared View/Tree picker, inspection, placement preview and Cancel behavior
are reused. Explicit calculation refreshes the measured boundary before solving
its downstream placements. Hidden frames retain their persisted references.

The welding all-around circle is 30% smaller. Its two adjoining strokes remain
continuous and visible inside the unfilled circle, in model and Drawing layouts.
Authored Symbol geometry is unchanged.

No native format or template change is required. Localization review found no
new product strings; all controls reuse shared translations in Czech, English,
German, French and Russian. User configuration and the development BAT remain
outside the change.

## Verification

Seventeen focused tests passed: measurement inspector GUI, translation coverage,
native documents, document transactions, reference refresh, Body/feature/datum
placement, reference assignment/removal, Body properties, measurement commands
and four Symbol suites. They cover common View picking, whole-Origin Tree entry,
inspection, OK/Cancel, reopening, native persistence, Undo/Redo, hidden centroids,
rotated Body coordinates, FRONT/TOP, signed offsets and missing/upstream anchors.
Additional independent-Body and aggregate-centroid checks exercise dependency
ownership and source movement.

This is targeted regression verification, not a claim that the entire repository
suite passed. Linux verification remains assigned to the Linux host.
