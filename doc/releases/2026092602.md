# ZIMA-CAD 2026092602 — Windows

This release fits the main workspace on smaller laptop displays, improves
light-theme contrast and adds editable ISO welding symbols with bilateral leaders.
It also includes the native Qt interaction appearance from the preceding changes.

## Visible changes

- The Drawing sheet-control row scrolls horizontally instead of imposing its
  full width on Part, Assembly and Drawing windows. The command panel remains
  inside 1024 x 680 and 800 x 600 logical-pixel test windows.
- The 3D view uses a light gray gradient with dark neutral strokes in light mode.
  Dark mode retains the original gradient. Saved colours and Drawing output
  are unchanged. The Windows icon gives its white C a dark outline.
- Four native welding definitions cover fillet, square-butt, V-butt and bevel-butt
  indications with ISO 2553 system A arrow-side/other-side variants, editable
  size and length/count/pitch, and reference lines that grow with the text.
- The fourteen existing ISO 1101 frame definitions now connect leaders at the
  centre of the nearest side. Welding leaders connect to either reference-line
  end. Changing the approached end never mirrors text or changes weld-side
  meaning. New tolerance/weld insertions enable a leader automatically.
- The common symbol editor scrolls long forms while keeping OK/Cancel accessible.
  New labels and validation text are translated in cs/en/de/fr/ru.

See [the symbol guide](../SYMBOLS_USER_GUIDE.md) for exact catalog scope. Combined
weld indications, supplementary weld flags/process tails and a complete ISO
conformance validator are outside this catalog. The optional reference-line
layout is stored inside the existing embedded native symbol definition. No new
Part/Assembly file fields or required external files are introduced; empty start
templates remain byte-identical.

## Verification

Eleven focused CTest contracts passed: shared UI, translations, compact windows,
symbol GUI, symbol Drawing, placement, integration, document persistence,
application lifecycle, new-document options and Drawing UI. These cover creation,
editing, Cancel, Undo/Redo, save/reopen, bilateral geometry and PDF/DXF export.
Packaging/signature tests passed (23 tests; two platform-specific skips).
The light View and icon on light/dark backgrounds were visually inspected.

The signed Windows acceptance receipt is recorded after the committed-source
package is verified. This is a Windows-only release; no Linux acceptance or
test on a fresh Windows installation is claimed.
