# ZIMA-CAD 2026102001

This Windows release combines native Sketcher editing repairs, complete Drawing
glyph rendering and 37 additional reviewed native fastener models. Shared C++,
Qt 6.11.0, OCCT 8.0.0, the native document schema and the root development
`zima-cad.bat` remain unchanged.

## Changes

- Ordinary Sketch text has its real solver anchor, with the documented alignment,
  dimension, manipulation and dependent-extrusion behavior. See
  [text anchor verification](../verification/20261019-sketch-text-anchor.md).
- Coordinate changes retain native finite-line incidence. Rounded tangent
  outlines and angular profiles accept repeated dimension changes and drags.
  Invalid final geometry and impossible finite contacts are rejected without
  publishing a failed edit. See [coordinate incidence](../verification/20261019-sketch-coordinate-incidence.md)
  and [rounded/angular profiles](../verification/20261020-rounded-tangent-wing.md).
- Part and Assembly Relations evaluate target values together and retry
  temporarily blocked Sketch dimension edits after other targets make progress.
  The final geometry, native support domains, side choices and tolerances remain
  authoritative; the model is not forced through an invalid final state.
- Calibrated Drawing text weight is applied to individual shaped glyph paths.
  Long notes retain letters that could disappear when the complete text path
  was eroded. Existing physical pen calibration and native-text export paths
  are retained. See [Drawing text coverage](../verification/20261020-drawing-text-coverage.md).
- Eleven CSN 02 1431 closed nuts follow the original 1970 cone/flat drawing:
  45-degree closed end, flat diameter k, 120-degree thread mouth and flat blind
  bore end. The contradictory former visible table is retired; DIN 1587 remains
  a separate family. See [nut and washer authoring](../NUT_AND_WASHER_LIBRARY.md).
- Fourteen coupling nuts M6–M36 use nominal height 3d and an editable native
  through opening. DIN 6334 is identified as the customary trade designation,
  following Fabory's qualification. See [verification](../verification/20261020-coupling-nuts.md).
- Eight nominal DIN approximately 6923 flange nuts M5–M20 omit seating
  serrations as requested. The spherical DIN 74361 A M20x1.5 SW27 nut, separate
  DIN 74361 F M12x1.5 60/90-degree seat variants and compressed M20 spherical
  spring washer retain their actual distinct shapes. See
  [shaped-fastener verification](../verification/20261020-shaped-fasteners.md).

Every new catalog model has an ordinary Body, authored native history,
current calculated mass, five translated names and a thumbnail. Forty-two
neutral/localized reference Drawings use actual geometry, dimensions and axes.
The spherical drawings show their real model R18 annotation. The washer has
a native Axis feature whose length follows its height. Custom libraries and
the user's unrelated working files are preserved.

## Finite verification and remaining limits

Windows native checks include 1,792 rounded tangent variants, 512 finite-line
controls, 512 angular-triangle variants, sixteen Part/Assembly Relations cases,
the ordinary Sketcher/metadata/physical-property contracts and 100 Drawing
glyph/weight cases. The four wing studies now pass all forty driver cases and
120 successive edits. All 451 repeated edits of the new factory families pass
independent geometry/property, reference, Undo/Redo and native reopen checks.
The linked notes record the actual GUI editing/dragging scope and exceptions.
Five-language table/catalog checks cover the new metadata and reference art.

The four cast wing nuts remain private unfinished studies. Their perimeter R2,
one M16 source-radius discrepancy and contour review still block factory
publication; six smaller pressed variants are not authored. Only the reviewed
M20 spherical spring washer is offered. Do not infer other sizes from the
retained source facts. Selected CAD rounding, gap, bevel and roof details are
identified in all five languages; these nominal models do not certify complete
manufacturing conformity, coating, preload or spring response.

Linux uses the same C++ implementation and committed factory documents, but
native Linux compilation, interaction and packaging were not performed on this
Windows host. See [Linux handoff](../LINUX_RELEASE_HANDOFF.md).

## Rejected Windows candidate

Candidate 2026102001 was not published. Native loading and 24 finite command/GUI
scenarios passed, but final visual review found missing technical-font glyphs
when the portable CLI ran from an ordinary project directory. Source-directory
execution hid that defect. The corrected release is 2026102002; see
[portable font and Unicode verification](../verification/20261020-portable-font-and-unicode-probes.md).
The signed trial archive and failed visual evidence are retained for diagnosis;
its native smoke receipt is not publication acceptance.
