# Windows build 2026100901

## Scope

Sheet Metal Form can insert the closed-solid 90-degree corner gusset from
`config/lib/01-SHEETMETAL/01-FORM/CornerGusset90.prtz`. Select the two outer flat
faces adjoining the same Bend and a longitudinal position reference. The
independent embedded definition can be replaced. The complete solid supplies
the automatic cut and native Shell; no authored cutting Sketch is required.
Inner transitions use destination thickness `t`, outer transitions `2t`.

The feature supports native Pattern/Mirror, Unbend manufacturing symbols and
Bend Back. Copy/state operands are prepared only when consumed downstream.
Private p-curve repair preserves exact 3D curves/surfaces, ancestry and the
existing tolerance budget. Body names select roles independently of Body order.
The supplied independent exact-outline symbol has no retired projection
dependency. Changed source geometry rejects reuse of a stale calculation.

The accompanying FORM-EDGE fixes cover connected equal-length dimension edits
and drags, stale committed-curve hover during Sketch editing, transient profile
Undo/Redo and exact external spline display/native shared endpoints. Invalid
Fillet definitions retain their parameters under the failed-feature contract.
Ordinary planar Form, Shell, Fillet and Thicken Surface retain their established
paths and have focused regression coverage.

No native format, dependency version or protected general placement changes.
Windows and Linux share one C++ implementation using OCCT 8.0.0.

## Verification and limits

The final native corner roundtrip/copy suite passed in 119.78 seconds; its actual
GUI sequence passed in 128.86 seconds. GUI creation includes exact hover/click
planes, reference inspection, rollback, Cancel, unchanged OK, station editing,
definition replacement, Undo/Redo and native reopening. Actual confirmation,
calculation, commit and scene publication measured **1.583 seconds**.

Supported test pairs `(t, Ri)` in mm are `(0.5, 2), (1, 2), (2, 4), (3, 6)`.
For each, both admissible orientations pass and 14 incompatible choices reject.
The fixture uses genuine Bend-attached 120 mm-wide Flats with 50 mm extensions.
Strict BRep curve-on-surface validity, connected-solid count, independent GK
volume, centroid/tensor equations and retained manufacturing records are checked.
Native file and independent copy role lookup cover all 24 Body orders for both
the ordinary Form and the new closed corner definition.

**Tight bends are a finite limitation:** tested `Ri = t` combinations at
`t = 0.5, 1, 3` mm fail the fixed-radius inner transition construction. They report
a localized error and keep the feature definition for correction. No smaller
radius is silently substituted. Adaptive-radius experiments were rejected for
asymmetric failures and excessive cost; their production code was removed.
These tests do not establish arbitrary-definition or arbitrary-radius support.

The equal-length matrix checks 576 successive dimension edits and 2,016 drags;
the final FORM-EDGE edit/hover/draft history GUI sequence passed in 19.13 seconds.
Details and finite variants are in [FORM Sketch editing](../FORM_SKETCH_EDITABILITY.md)
and [Sheet Form design](../SHEET_FORM_DESIGN.md).

New placement instructions and transition-fit errors are localized in all five
languages. Source/catalog coverage and actual translated controls are checked.
The final definition/localization/external-reference/equal-length group passed
all four suites in 69.09 s; it supersedes two diagnostic-fixture failures caused
by an inconsistent Arc mutation and an incorrect assumption about the source's
generic profile feature type. Both ordinary and corner source-order matrices,
valid stale-geometry rejection and oriented-plane equations now pass. The five
catalogs contain the same 2,246 non-empty keys.
Documentation is English. Linux compilation, native and GUI acceptance remain
unverified for this change and must run on the Linux host.
