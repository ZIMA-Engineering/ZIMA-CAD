# Windows 2026111202 — Complete tangent Fillet termination

Status: Windows source and focused verification accepted; signed publication
acceptance is recorded below only after immutable release assets are published.
Native Linux acceptance remains a separate host gate.

This release contains the Planar Surface, robust large-assembly STEP import and
single-direction Line Bend work completed for 2026111201. Planar Surface creates
a zero-thickness result from closed Sketch profiles in the selected plane, with
optional signed offset, nested holes, disjoint regions and native circle axes.
Line Bend uses the drawn line as the developed bend centre, derives one physical
direction from the Sketch plane, accepts 0–180 degrees and preserves usable
downstream edges and unfolding. Large STEP assemblies keep valid components and
report and skip invalid components instead of rejecting the entire import.

The Fillet terminal correction is completed in this build. A route may still
use its auxiliary extension when it must reach an oblique, remote or curved
terminal. When a planar terminal lies at the authored endpoint and is tangent
to the route, the base sweep already ends at the correct location and the
entire auxiliary tail is discarded. This removes the residual planar wedge or
chamfer beyond Fillet 03 in the reported `RADIUS.prtz` case without weakening
the extension behavior required by other terminal configurations.

Focused Windows verification recalculates an isolated copy of the reported
document with five calculated boundaries, no calculation errors, unchanged
authored definition and exact native readback. The Fillet regression compares
both additions and removals beyond the tangent endpoint and runs together with
the existing planar, oblique, curved, returning-route and exact-half-turn
coverage. The wider edge-treatment, document-state, model-calculation, command,
query and GUI contracts also pass before packaging. Candidate and signed archive
acceptance add committed-source, dependency, archive, factory-library, GUI/CLI
identity, save/reopen and rendered-output smoke checks.

No user-visible text changes in this follow-up, so the Czech, English, German,
French and Russian catalogs require no new entries. The protected shared
placement contract, native document format, calculation tolerances, Qt 6.11.0
and OCCT 8.0.1 remain unchanged. A complete repository-wide regression run and
native Linux execution are not claimed.
