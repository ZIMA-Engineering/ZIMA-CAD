# ZIMA-CAD 2026112502 — Windows

This update removes repeated history calculations when confirming Project sketch
and Project relief, clarifies missing-region input and finishes the compact FEM
deformation player. The signed Windows build passed the publication gates recorded below.

- Unchanged Projection/relief OK performs no geometry calculation and creates no
  Undo step. On the reported saved model, actual GUI confirmation took 0.22–0.47 s.
- Changed Projection confirmation reuses valid earlier results and Family Body
  calculations. The measured CLI case fell from 29.69 s to 3.26 s after opening,
  and from 20.07 s to 2.97 s on the next edit, with equivalent output.
- Missing retained-region input is reported immediately and activates region
  selection. Both positive and negative relief passed independent volume checks
  on a copy of the reported model.
- Project/Wrap relief previews show the source Sketch in white and the material
  tool in azure. The Feature list places Project relief directly below Project
  sketch, followed by Wrap sketch and Wrap relief. Selected icons retain the
  theme foreground.
- The compact, stable FEM player has separate Start, Pause and Stop controls.
  The sidebar has one player entry with the play icon; redundant Play deformation
  is removed. All settings remain visible and video export remains available.
- New UI text is translated into Czech, English, German, French and Russian.

See the [measurements and finite regression matrix](../verification/20261125-projection-performance-player.md).
Changed material operations still require calculation; measured times are not
universal limits. This update does not change the native document format.
Native Linux verification and unfinished CAM authoring/simulation UI remain
separate work. CAM follows this CAD release and requires its own acceptance.
