# Windows 2026111102 — Line Bend and associative sheet detachment

Status: signed Windows release published and accepted. Native Linux acceptance
remains a separate host gate.

The new **Line Bend** command bends sheet material about one finite straight
Sketch segment. One side remains fixed; the other follows the requested inside
radius, angle and direction. The command supports reverse direction, either
fixed side, sheet-thickness and K-factor overrides, native value locks, inline
dimension editing, Undo/Redo and save/reopen.

**Sheet from Body** now accepts additional planar or cylindrical faces and up to
an automatically growing set of RIP Sketch inputs. RIP may contain open or
closed ordinary geometry and separates sheet connectivity without representing
a manufacturable cut. Generated Flats and Bends remain associated with source
faces and radii. The Tree can detach one generated child with **Explode part**
or remove the conversion owner with **Explode all**, preserving the current
native sheet features and their calculated result.

The approved native Part format is INI 52 / internal packet 76. All 1,058
repository-owned Part-based native assets were migrated with the current shared
C++ writer, recalculated across 5,477 boundaries, saved and reopened with zero
errors. Independent comparison preserved calculated reference/side identities
and available physical values in 1,042 cached assets. The Part and Skeleton
start templates are current; private projects, custom libraries and user
configuration were excluded.

Fourteen focused Windows native and GUI contracts pass, including Line Bend,
Sheet from Body, RIP, same-Body conversion, partial/full detachment, ordinary
Bend continuation, history/cache behavior, native metadata, Unicode I/O, units
and all five localization catalogs. Millimetre and inch Part, sheet Part,
Skeleton and Assembly creation also confirm the active editable context and
normal command availability from the refreshed start templates. See the
[finite verification record](../verification/20261111-line-bend-rip-explode.md).

No calculation tolerance, protected shared placement behavior, geometry-side
meaning, Qt 6.11.0 or OCCT 8.0.1 pin changed. A complete repository-wide test
run and native Linux execution are not claimed by this Windows release.
