# Windows 2026101206 — source-root projects and engineering tables

## Changes

The File Manager source-row context menu now offers Open, Open in New Tab,
Directory Properties and Create/Edit Project Overview. Directory Properties
edits five localized labels, Files visibility, automatic Overview behavior,
SVG/PNG branding and ordered parameter definitions. Read-only sources expose
the values without allowing changes.

Directory labels stored in metadata version 3 are displayed in the source tree
and Files view. The Tree caches those labels and clears the cache after the
project editor writes metadata, avoiding repeated INI reads during painting.

The factory `03-ENGINEERING-TABLES` source now contains a filtered copy of the
ZIMA-Engineering mechanical-table hierarchy. It includes 1,448 HTML pages,
styles, scripts, documents, data files and preview images (155,953,349 bytes)
plus 312 converted metadata files. Legacy Pro/ENGINEER CAD files, editor
backups and desktop metadata are excluded. Short English physical directory
names keep packaged paths below the 180-code-unit archive limit. Metadata
preserves human labels and parameters; the root and main groups include all
five application languages. The source hierarchy was not modified.

Overview now prefers `index_<language>.html`, falls back to `index.html` or
`index.htm`, and uses automatic image tiles when no page exists. Shared web
assets are localized beside imported pages and navigation links are rewritten
to the new directory names.

No native document schema, geometry algorithm, container-placement contract or
OCCT version changed. New File Manager text is translated in Czech, English,
German, French and Russian.
