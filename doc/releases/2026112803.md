# Windows 2026112803 - Sheet boundary preparation and Drawing dimensions

Status: signed Windows release [published on GitHub](https://github.com/ZIMA-Engineering/ZIMA-CAD/releases/tag/ZIMA-CAD-2026112803)
at `2026-11-28T14:10:18Z` from immutable source `de735241c1553f636c561187c2648cfa4ce86803`.

Sheet from Body now prepares exact authored attachment boundaries before material
for supported native polygonal Flat/Bend chains. It removes intermediate solid
calculations while retaining independent branches and ordinary attachments after
Explode. Unsupported lightweight preparation uses the established materialized
path. Complete history publication retains exact source reference demands.
On the measured complex RIP box, median conversion preparation decreased from
30.86 s to 9.88 s across three paired runs. These timings exclude file I/O and GUI
rendering. See the [geometry and performance record](../performance/20261128-skeleton-first-conversion.md).

The ordinary Drawing Dimension command starts in Automatic mode. Right-clicking
during final placement cycles arrow direction and radius leader presentation.
Explicit kinds, Cancel, Undo/Redo and saved references retain their contracts.
The projected-view action has its own icon in the context menu. Changed text is
translated in Czech, English, German, French and Russian. See the
[Drawing verification record](../verification/20261128-drawing-dimension-placement.md).

Manual testing found that changing Part sheet thickness updated only the root
Flat of a converted solid. The material-input invalidation now rebuilds its
exact attachment boundary and retains generated identities and user corrections.
Source Fillet radii remain authored in the original solid. The reported model
passes repeated thickness and source-radius edits, native geometry, Undo/Redo,
save/reopen, Unbend/Bend Back, Explode and actual Sheet Properties interaction;
see the [material-default verification](../verification/20261128-sheet-material-defaults.md).
