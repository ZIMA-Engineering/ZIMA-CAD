# Windows build 2026100902

## Scope

The corner Form library profile is reduced from 24 to 16 mm width and from
18 to 12 mm depth. Its independent exact-outline manufacturing symbol is rebuilt.
Already inserted definitions remain independent copies; use Replace definition
to receive the compact profile. Placement uses two outer flat faces adjoining
the same 90-degree Bend and a longitudinal station reference.

At the user's explicit request, symbolic forming permits local thickness
variation. The corner wall uses half the destination stock thickness `t`, the
cavity transition radius is `t`, and the opposite projecting transition is
`t/4`. Stock and Bend thickness remain unchanged. These are fixed rules, with
no adaptive radius retries or increased approximation tolerance. Ordinary Form,
Shell and Fillet parameters remain unchanged.

The build also includes the preceding first-support clear control and disabled
zero offset, signed View placement-offset editing inside Properties, and sheet
default thickness recovery while a downstream feature is already failed.
Editing source-shape dimensions in an inserted Form remains deferred.

## Local verification

Nine native `(t, Ri)` cases pass both admissible orientations and reject the
other fourteen: `(0.5, 0.5)`, `(1, 1)`, `(2, 2)`, `(3, 3)`, `(4, 4)`,
`(0.5, 2)`, `(1, 2)`, `(2, 4)`, `(3, 6)` mm. Checks include strict BRep
consistency/connectivity, independent volume and centroid/inertia, and actual
transition-surface principal curvature. Native save/reopen, regeneration,
Pattern/Mirror, flat symbols, Unbend and Bend Back pass. Independent replacement
also passes on a separate copy of the user's corrected `12.prtz`.

Eight focused Windows native/GUI suites pass in 358.29 seconds, including
ordinary/corner Form GUI, all five languages, 24 Body orders for both native
definitions, Form geometry, Shell, solid-state Fillet and Thicken Surface.
Complete corner GUI confirmation measured 1.205 seconds; individual native
insertions measured 0.986–1.335 seconds. These are finite fixture observations.
The broader standalone dialog JSON failure remains outside this acceptance.

No new UI text, native schema, dependency pin or protected shared placement
change is introduced. One shared C++ implementation uses OCCT 8.0.0.
Linux native and GUI execution remain unverified.

## Package status

This candidate was not signed or published. The subsequent user verification
exposed a failure in the ordinary workspace Pattern/Mirror path that the direct
kernel copy fixtures had not covered. Build 2026100903 supersedes this candidate
with that correction and the source-profile centroid axis. The 2026100902 tag
and its committed source remain unchanged.
