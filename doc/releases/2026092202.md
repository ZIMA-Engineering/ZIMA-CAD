# ZIMA-CAD 2026092202 — Windows

## Changes

- Assembly Drawing projection uses a spatial triangle index while preserving
  exact visibility clipping and curve refinement. The reported five-component
  assembly now projects isometric edges in about 0.6 seconds, compared with an
  original run stopped after more than a minute. Complete source projection,
  including annotations, measured about 4.7 seconds locally.
- Skeleton occurrences are excluded from Assembly drawings, including nested
  occurrences and their reference geometry. Assembly display is unchanged.
- New Skeleton Parts use `start_skeleton.prtz`: an empty active Body and black
  surfaces with approximately 70% transparency. Classification remains based
  exclusively on the `*_skeleton.prtz` filename.
- Running dimensions are independent entities with their own tolerances. They
  can continue from an existing dimension, move through their common datum,
  and convert to linear dimensions. Reference entry follows shared progressive
  rows, and the dimension properties dialog has a compact height.
- Free parallel dimensions support alignment; witness lines support editable
  jogs and breaks with draggable grips. Commands have localized labels/icons.
- Drawing point/curve hover, curved edge visibility, saved thread projection,
  model dimension units, stacked tolerance size and Tree icons are corrected.
- Title-block text supports Today's date and configurable lists. Projection
  symbols use shared center geometry and centerlines. All five title blocks
  include central mass/quantity unit labels. The values dialog is narrower.

This release also includes the Drawing features documented in
[2026092201](2026092201.md), whose signed archive was prepared locally but not
published. Existing drawings embed their title blocks; reinsert a library title
block to adopt changed labels and projection geometry.

## Verification

Focused projection, source filtering, Drawing UI, thread, native document and
translation tests passed. Skeleton creation and enabled modeling commands were
verified in all five UI languages. Regression tests cover open/saved sources,
nested Skeletons, unchanged Assembly display and exact partial occlusion.
No modeling precision or document format changed in this follow-up.

Portable acceptance and publication are recorded after the committed-source
candidate and signed archive pass their validation gates. This document does
not claim a complete repository-wide test pass or Linux verification.
