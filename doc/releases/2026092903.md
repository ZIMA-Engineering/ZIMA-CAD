# ZIMA-CAD 2026092903

Status: Windows release signed, published and verified.

## Changes

- Standalone unified Sketch Features now offer Extrusion and Revolution in
  their Tree and confirmed View context menus. Shortcuts open the ordinary
  Feature Properties transaction, preserve container/Sketch identity and
  authored names, commit on OK and leave the original intact on Cancel.
- The common placement candidate policy accepts the persisted end-plane datum
  of both sheet-transition variants. Pick the visible plane border. The
  explicitly approved change preserves solver behavior and reference identity;
  display-only end planes remain excluded from placement references.
- The factory drawing library contains the combined frame and title-block
  Families only. Original single-format/language assets remain as regression
  fixtures outside the selectable library.

See [Feature types](../UNIFIED_FEATURE_TYPES.md),
[transition planes](../SHEET_TRANSITION_PREVIEW.md) and
[drawing Families](../NATIVE_TITLE_BLOCK_FAMILY.md).

## Source verification

The Windows application, CLI and affected test targets built successfully.
Six focused contracts passed: Sketch context conversion, actual tilted
half-round/rectangular transition plane picking, sheet-transition backend and
GUI, Feature type editing, and five-language catalog/source coverage. Conversion
checks include Cancel, OK, stable identities, authored names, native persistence
and Undo/Redo. Plane checks compare offered, hovered and confirmed identities,
include ordinary/Origin planes and reject a display-only end plane.

An initial concurrent GUI test attempt encountered the working-directory lock;
its isolated rerun passed. This is not a full-suite pass. The unrelated broader
UI/console failures recorded for 2026092902 have not been addressed here.
No native file-format change or new UI string was introduced. Existing labels
are reused in Czech, English, German, French and Russian. Linux runtime
verification remains work for the Linux host.
