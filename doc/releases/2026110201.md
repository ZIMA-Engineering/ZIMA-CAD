# Windows 2026110201 — dependency-aware history and durable references

This Windows release follows `2026103101` with dependency-aware native history
evaluation, durable edge and profile references, and current-format factory
assets. The implementation remains shared C++ for Windows and Linux; this
release establishes Windows execution only.

## Changes

- Model regeneration plans exact history dependencies and avoids rebuilding
  independent completed work. Final Body publication, rollback boundaries,
  persisted references and authored operation order retain their established
  contracts.
- Exact edge-treatment continuation uses persisted endpoint incidence and native
  curve derivatives. The former authored angular tolerance is removed; corners,
  T-junctions and missing exact curve data stop automatic traversal.
- Boundary composition and edge-treatment ancestry retain stable references
  through representative repeated Fillet, Chamfer, Shell and Boolean edits.
  Experimental direct Boolean and custom planar-Fillet paths remain disabled by
  default and are not represented as production replacements.
- Extrusion, Revolution and unified Feature properties can publish an individual
  centroid axis for each disconnected closed profile region. Holes contribute to
  their owning region and never become separate axes. Identities remain stable
  across supported dimension and extent edits.
- Sketch constraint handling, external circular-profile references, exact
  intersection presentation and point/axis interaction receive focused
  corrections. Native document replacement now uses an atomic sibling-file
  publication path with bounded Windows sharing-violation retries.

## Native format and factory assets

Part documents use current native INI format `47` and JSON format `71`. The new
format explicitly persists the individual-centroid-axis option and contains no
legacy fallback. Assembly format `37`/JSON `49` and Drawing format `21`/JSON `13`
are unchanged. Repository-owned Part assets, FORM definitions, symbols, formats
and start Part, Skeleton and Assembly templates were recalculated, saved and
reopened with the current implementation before publication.

This format boundary intentionally follows the project's current-format-only
policy. Documents saved by this build are not promised to open in older builds.
No external sidecar or required cache is introduced; complete authored and
calculated state remains in the native document.

## Verification boundary

Focused Windows Release checks cover dependency planning, exact boundary union,
edge-treatment support, repeated dimension edits, native save/reopen, Undo/Redo,
profile centerlines, Sketcher contracts and the complete document/OCCT contract
executable. The complete-skeleton matrices include successive thin-profile and
batched-cut edits with persisted identity comparisons. Candidate and signed
package acceptance additionally load every committed native factory asset and
verify the exact tagged source, Qt 6.11.0 and OCCT 8.0.1 dependency closure,
archive integrity, GUI/CLI startup and deterministic native save/reopen.

The obsolete edge-treatment tolerance text was removed from Czech, English,
German, French and Russian catalogs; no new user-visible string was introduced.
The five-language source/catalog coverage check passes. Portable packaging clears
development-machine Codex executable paths while leaving the source checkout and
installation-root user overrides unchanged.

The aggregate framebuffer UI executable retains an unrelated construction-point
base-colour mismatch before it reaches the changed tangent-route fixture; the
specialized affected UI contracts pass. Native Linux compilation, execution and
timing require their separate host acceptance. Finite geometry and persistence
matrices do not prove every possible topology.
