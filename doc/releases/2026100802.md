# Windows build 2026100802

## Changes

- New free Sketch/profile Origins agree with Default and use XY. Complete
  Origin entry uses the same frame; manual work planes and authored XZ quarter
  turns retain their geometric meaning. Sketch-to-Sweep conversion preserves
  the selected frame. The shared placement change was explicitly authorized
  by the user on 2026-10-08.
- FORM definition roles are selected by Body name independently of Body order.
  The factory Ventilation Window and the user's FORM Part were rotated into
  XY through native calculation, retaining reference IDs, the surface shape
  and the two R15 cutting corners. The original personal Part has a backup.
- Fusion properties layout was reviewed in all five languages. Internal
  properties stay inside their owner after resizing. Drawing View Properties
  requests its natural height and keeps every input reachable on smaller
  screens. Drawing Break Editor correctly confirms its validated draft.
- Ordinary Sketch Properties retains its real input-history boundary during
  Sketcher entry. Active-occurrence rollback, passive occurrences, exact frames,
  point dragging and Trim retain their ownership; Assembly entry preserves zoom
  and pan while aligning the sketch plane.
- Drawing sheets show fixed-screen-size X/Y arrows at their actual lower-right
  Origin, with positive X left and positive Y up. These display arrows do not
  enter printing, export, selection or history.
- The empty application background shows subdued ZC, including after the last
  tab closes. The proposed zima-cad.com internal startup page is a separate
  follow-up; an embedded browser is not included in this build.

## Verification

The detailed scope and limits are recorded in
[XY Origin and Fusion review](../XY_ORIGIN_AND_FUSION_REVIEW.md).

Native frames cover XY/XZ/YZ, automatic/manual choice, both contact sides at
zero offset, numeric corrections, plane offsets, all quarter turns and native
roundtrip. Default GUI checks Tree Origin equivalence, canonical initial and
confirmed preview axes, successive reference entry, manual-plane retention,
all five tooltips, OK/reopening, Cancel, Undo/Redo and save. The native
Sketch-to-Sweep matrix covers 72 plane/reference/side/quarter-turn combinations,
transformed owning Bodies, constraints, source identities, geometry and edits.

FORM tests cover all 24 Body permutations and real reordered insertion, valid
BRep, volume and reference identity. The XY conversion independently compares
every old/new tessellation vertex with the opposite native shell after a rigid
90-degree rotation, checks equal area and stable IDs, and reopens the native
Part. This does not reduce calculation or display precision.

The Fusion matrix covers 38 modeling-dialog configurations in five languages
at two application sizes: **380 combinations**. Drawing View Properties covers
all five languages at 1366×768 and 1920×1080, resized owners, input reachability,
horizontal containment and visible OK/Cancel. Origin rendering covers two zooms,
two pan positions and screen/print; direction, actual zero, fixed screen extent
and absence from print are checked independently. Actual screenshots were
inspected. This is not exhaustive DPI/theme or populated-table coverage.

The native Sketcher, dimension-command, work-plane and five-language translation
suites passed. Actual profile GUI covers existing/new Extrusion/Revolution,
three first-Origin entry orders and eight orientations. The 48 Sketch/Holes/
Flat/Bend return-frame cases and external-constraint GUI matrix passed. Nested
Part/Assembly dragging, exact occurrence identity, independent placed-coordinate
checks, active-only rollback, passive context, save/reopen and Trim Cancel passed.
Packaging/signing input tests passed: 26 cases, with two Unix/Linux-only cases
skipped on Windows. Distribution acceptance is completed before publication.

No persistent fields, native extensions, OCCT dependency pins or development
launcher path change. C++ remains shared with Linux; this release does not claim
Linux build or GUI acceptance, nor exhaustive Sketch solver permutation testing.
