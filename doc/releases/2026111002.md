# Windows 2026111002 — Imported sheet reconstruction

Status: Signed Windows release candidate pending publication acceptance.

Body-to-Sheet conversion now reconstructs finished imported STEP sheets from the
selected planar face as an ordered native Flat/Bend history. It preserves exact
attachment endpoints, save/reopen and Undo/Redo, and it can recover the reported
rounded end ears as one Bend each even when the source exporter represented each
ear by a compound pair of coaxial fillets.

Complementary STEP semicircles are now authored as one true Sketch circle. This
both exposes the ordinary circle axes and fixes the reported case where a Bend
failed until another Bend had first been created on the initial Flat. The cause
was invalid split-arc Boolean topology, not uninitialized Bend state or a warm
cache. The first following Bend now passes from a cold reopened converted sheet.

Consecutive same-side Sheet Profile turns no longer reapply an already carried
sheet-thickness offset at their shared edge. Single active Plane Up To targets
are covered on both logical branches and both reversed-side states. Whole
Assembly occurrence hover and selection show the complete persisted wire through
occlusion without filling faces or highlighting a sibling occurrence.

The focused Windows matrix passed nine native and GUI contracts for STEP exchange,
Sheet Profile, Feature side reversal, source-wire rendering, Bend, Sketcher
tangency and all five localization catalogs. The reported `17.prtz` model also
passed exact selected-face conversion and cold regeneration with eleven native
features, including two recovered ears and 74 native circles. No user-authored
project file was modified.

No user-visible text, native file format, factory asset, start template, protected
shared container-placement implementation, geometry-side meaning, calculation
precision or dependency pin changed. Windows and Linux retain one shared C++
implementation with Qt 6.11.0 packaging and OCCT 8.0.1. Native Linux compilation
and execution remain a separate host gate.
