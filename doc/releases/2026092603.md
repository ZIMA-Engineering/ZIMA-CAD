# ZIMA-CAD 2026092603 — Windows

This release unifies interactive geometry and checked controls around azure,
and ships the approved graphite/azure ZC monogram.

## Visible changes

- Confirmed and inspected geometry uses azure, with a stronger 2.5 logical-pixel
  wire in the existing rendering passes. Hover stays thinner. Pending wires stay
  solid; only the existing through-all terminal outlines use dashed previews.
  Construction and centreline patterns retain their meaning.
- Checked toolbar controls and active commands use azure backgrounds with dark
  text and contrasting icons. Confirmation checkmarks remain green. The container
  Origin icon is green, while Body/document Origin identities remain unchanged.
- The logo has a graphite Z with a light outline and an unoutlined, angular azure
  C with rounded transitions. Its longer upper arm is bevelled inward; its lower
  terminal is square. Both Windows executables embed the same multi-size ICO.
- Development shortcuts explicitly reference the ICO, avoiding a stale implicit
  executable icon in an existing taskbar pin. The user confirmed the refreshed
  Windows taskbar appearance. Existing portable pins may require a shortcut/icon
  refresh if Windows retains their previous icon.

Ordinary native controls, Tree selection, stored drawing pen colours and model
data are unchanged. No UI text was added; all five existing languages remain
covered. See [visual conventions](../UI_VISUAL_CONVENTIONS.md) for details.

## Verification

Shared UI, Drawing UI, Sketch Offset, whole-Origin, compact-window and translation
contracts passed during implementation. The focused interaction fixture also
passed with Windows 11 styling. It covers checked-button contrast, green
confirmation and Origin icons, wire thickness and through-all dash preservation.
The approved icon was inspected on light/dark backgrounds at 16–48 pixels.

Three alternating runs of the same 400-edge selected-wire scene at 800 x 600
gave median framebuffer times of 3.78/3.68/3.75 ms before and 3.63/3.66/3.67 ms
after the change. No slowdown was observed in this fixture; this is not a
universal GPU guarantee. No geometry traversal or rendering pass was added.

The committed-source package, signatures and public assets are verified before
recording the release acceptance below. This is a Windows-only release. Linux
uses the same SVG/desktop identity but its updated panel appearance remains to
be checked on the Linux host. No fresh Windows OS acceptance is claimed.
