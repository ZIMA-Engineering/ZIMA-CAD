# ZIMA-CAD 2026091607

## Changes

- Sketcher preserves signed absolute coordinates from its origin and main axes.
  Its solver now solves coupled rectilinear equations together, so moving a
  dimensioned rectangle with a negative coordinate preserves its dimensions and
  orientation. Editing either coordinate works through the View and commands.
- Entering Sketcher from Extrusion or Revolution on a sheet-metal Flat keeps
  the pending profile in its Properties transaction. This fixes the crash in
  documents with evaluated Family Table variants and prevents premature history
  changes on Sketcher return or Cancel.
- Bend dimensions use their actual Sketch planes. Prepared start coordinates
  follow the selected edge direction. The View's selectable **Bend / Unbend**
  label can populate a Family Table state column and open Bend properties.
  Variant state overrides are distinct from shared model edits.
- Family Table's localized Yes/No editor covers the underlying cell text.

The development entry point remains repository-root `zima-cad.bat`.
Portable installations start through their root `ZIMA-CAD.exe`.

## Validation

After the additional solver repair, eleven related contracts passed, including
actual GUI dimension edits and save/reopen. The solver matrix covers 112
coordinate changes and eight rejected fixed-corner changes. Seven command-driven
edits were also checked on a disposable copy of the user's rectangle; the source
file remained unchanged. See [Sketch commands](../SKETCH_COMMANDS.md) and
[Sheet Metal](../SHEET_METAL.md) for evidence and scope.

## Compatibility and known limitations

- Native file formats are unchanged. This release adds no legacy migration.
  Previously saved inconsistent Bend coordinates are not silently rewritten.
- The documented conflict between an authored Bend trajectory endpoint and its
  moved end profile during Unbend remains unresolved. Use the end-profile
  endpoint for downstream attachment; see [Sheet Metal](../SHEET_METAL.md).
- These are focused tests, not a new full repository-suite acceptance.
- Linux packaging and acceptance remain assigned to the Linux host.
