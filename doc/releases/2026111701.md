# ZIMA-CAD 2026111701

Status: geometry, interaction and localization checks passed on Windows;
committed-source portable packaging and publication acceptance are pending.

This build corrects the reported Fillet transitions on changing plane/cylinder
and cylinder/cylinder supports, including the local oblique mixed-material
corner. Main Fillet contacts preserve tangency through a rolling support-driven
construction. Local terminal and junction transitions need not be tangent at
every point.

Complex closed Chamfer routes now support A x A, A x B and A plus angle,
including Flip. Distances follow the developed support surfaces and the angle
is checked against the A support. Open line/arc/line routes retain independent
end choices, including NoCut, reversed edge orientations and oblique/curved
material limits. The preceding direct node editing and material-terminal fixes
are included.

The shared lightweight preview uses the current calculated support geometry;
opening Properties does not calculate a preview solid. The empty-selection
prompt in Fillet and Chamfer Properties is green. Actual errors remain red.
All changed messages have Czech, English, German, French and Russian translations.

Verification includes five saved Fillet cases, five saved closed-Chamfer
variants, an independent 12-case closed-Chamfer matrix, independent Fillet
curvature/tangency checks, native save/reopen and face ancestry, zero-calculation
previews, and native/GUI contracts covering selection, editing, creation,
unchanged OK, Cancel and Undo/Redo. Actual Windows GUI runs regenerate the
saved 04 and 05 models and inspect both asymmetric Chamfer variants.

This is bounded support for the verified geometry families. Arbitrary freeform
blends, all varying-angle open Chamfer routes and every radius value are not
claimed. Unsupported candidates fail validation. Some exploratory R3 edits of
the supplied 04/13 and 05/04 cases are rejected; their authored radii pass.

No native format or shared placement contract changed. Qt 6.11.0 and OCCT 8.0.1
remain pinned, and Windows/Linux use the same C++ implementation. Linux native
compilation and runtime verification require the Linux host. The repository
launcher remains `zima-cad.bat`.
