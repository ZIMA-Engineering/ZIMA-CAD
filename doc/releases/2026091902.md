# ZIMA-CAD 2026091902

Windows follow-up release with corrected Twisted Sheet material-side attachment
and creation previews, plus explicit exclusive All/individual choices in Unbend
and Bend Back. Profile-chain unfold/fold-back and Sheet Cut with rotated Origins
have additional regression coverage.

Part format is INI 41 / JSON 65. The updated start Part is included. Backward
compatibility with earlier native Part formats is not supported; preserve
original documents before opening them with another release.

Fifteen focused native/GUI contracts passed during implementation. Signed
Windows package acceptance is recorded after candidate and publication checks.
This release contains Windows only; Linux was not rebuilt.
