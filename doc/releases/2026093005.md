# ZIMA-CAD 2026093005 — Windows

## Changes

- Qt controls use Fusion with an explicit Light/Dark choice in Global Settings.
  `Application/Theme` is stored in shared global configuration and never follows
  the operating-system theme automatically. View, Sketch and Drawing retain
  their ISO technical font. Labels and tooltips cover Czech, English, German,
  French and Russian. See [UI conventions](../UI_VISUAL_CONVENTIONS.md).
- 2D/3D Sweep support Surface results; H-Sweep supports Solid, Thin and Surface.
  Helical native feature data requires the new result/thickness/side fields;
  legacy H-Sweep documents are not supported. Factory start templates were
  regenerated and verified through GUI creation.
  Thin uses the established thickness/side controls. Surface is uncapped and
  Add-only. See [result-mode verification](../performance/20260930-sweep-result-modes.md).
- 2D Sweep offers its own XY/XZ/YZ path planes in a dropdown. H-Sweep places
  result type below the Sketch buttons and offers its own base-plane dropdown
  above the signed offset. Existing shared container placement is unchanged.
- STEP/IGES imports place their new Bodies before existing Part Bodies, retaining
  source order, existing geometry, native persistence and Undo/Redo.
- Saved centroid planes resolve for measurement; Assembly placement-reference
  measurement uses the owning Assembly frame. H-Sweep previews and sibling
  Sketch editing retain the initial point alongside the base circle.
- Zero extrusion draft-angle annotations are hidden. Directory chooser
  acceptance text remains localized while navigating.
- Measured performance work reduces independent Sketch equation work, Assembly
  scene copies/picking, repeated source refresh, unnecessary presentation rebuilds,
  object-bounds lookup, fingerprint copies, SVG reads, read-only Drawing history
  copies and discarded Symbol-leader geometry. Each comparison and its exact
  scope is recorded in the [performance audit follow-ups](../PERFORMANCE_AUDIT_20260930.md).
  These are operation-specific results, not a promised whole-application speedup.

## Verification and limits

Focused geometry, native persistence, transaction, command, localization and GUI
checks are recorded in the linked feature/performance documents. Fusion checks
cover both themes in all five languages, OK/Cancel, missing/invalid theme values
and independent technical fonts. The settings captures were visually inspected. All 300 Part dialog/language/window-size
layout combinations passed after fitting the existing Sweep Sketch button and
avoiding compressed initial Pattern spacing.

The remaining broader cache/transaction/renderer proposals remain explicitly
open in the audit. This release does not claim that every optimization candidate
has been implemented or that the complete repository test suite passes. Linux
build and desktop verification belong on the Linux host; this release is Windows.

Broader checks are not a release-wide green result: the combined UI fixture
has intermittent real-cursor hover failures; its last broad run stopped at the
styled Sketch hover check. The old Assembly-import test still references the
removed automatic physical-relations function, and unrelated DXF fixtures retain
old construction-entity counts. Targeted current Part import and geometry tests
pass; these wider test-maintenance gaps are not silently treated as passes.

The final targeted Windows gate passed **8/8** in 86.21 seconds: portable
settings, 2D Sweep, H-Sweep, Relations editor, translations, Pattern dimensions,
Fusion/fonts and Drawing UI. The layout gate passed separately (**300** cases).
Archive tests passed eight cases with two environment/platform skips; all sixteen
publisher-input checks passed. Logs: `build/fusion-release-checks.log`,
`build/fusion-pattern-tests.log`, `build/fusion-package-tests.log` and
`build/fusion-publisher-tests.log`.

## Release acceptance

The fresh committed-source Windows build passed dependency closure, archive
path/collision, CRC/SHA-256 and native smoke checks: deterministic Part
calculation/save/reopen, PDF/JPEG export and GUI startup without developer SDK
paths. The signed archive passed smoke again and the production updater accepted
its bootstrap trust.

All six packaged GUI checks passed: Fusion/fonts in five languages (including an
initial Windows-style override), 2D Sweep, H-Sweep, Pattern dimensions, native
Relations/View insertion and Sketch return frames. Authenticated draft downloads
and anonymous public downloads of all three assets matched the accepted local
SHA-256 values. Production discovery from signed 2026093004 offered 2026093005
as installable; no update was installed by this check.
