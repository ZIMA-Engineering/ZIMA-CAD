# ZIMA-CAD 2026092001 — Linux

This Linux release updates Drawing dimensions, view properties and view breaks.
The supported runtime target is Debian 13 x86_64 with KDE/Wayland. Windows is
not included. Extract into a new directory and run `ZIMA-CAD/ZIMA-CAD.sh`.
User settings and projects remain outside immutable version directories.

## Changes

- Drawing dimensions measure projected distances and snap to axis-aligned 2D
  guides. Model dimensions retain their original values and Part/Assembly frames.
- New point dimensions choose horizontal, vertical or direct distance during
  placement using the same classifier as Sketcher.
- Millimetres are implicit in Drawing length labels, including transferred
  model dimensions and exports. Angular units and tolerances remain visible.
- A linear dimension converts to a running chain with its two existing points.
  Chains show a zero datum, cumulative values, one shared line and perpendicular
  labels outside the witness geometry. Additional points are separate actions.
- Compact View Properties adds in-plane rotation. New views receive numbered
  names. Moving a view preserves dimensions; confirming orientation changes
  removes its local dimensions, with Cancel and Undo protection.
- View breaks have an internal graphical editor, numeric intervals and gaps,
  result preview, native persistence and shared screen/PDF/DXF rendering.
  Zigzag corners use 20-degree included angles; measured values remain unchanged.
- Dimension Properties preserves cyan selection after double-click, OK and
  Cancel. Title-block master dimensions again drive equal-length rows.

## Validation scope

Local development checks passed: 13 targeted Drawing/Sketcher contracts, followed
by nine core/export/GUI checks for the final dimension conventions. The root
launcher's main-workspace Drawing verification passed. These cover selection,
conversion and Undo, projected values, chain direction/label sides, moving
already dimensioned views, breaks, save/reopen and PDF/DXF output.

This is not a claim that the complete repository suite passes. The separate
3D dimension-layout test has a known text-clearance assertion, left unchanged
at the user's request. The broader conical Sheet Cut Boolean-probe limitation
recorded in Linux 2026091904 is not claimed as fixed. No Windows build or fresh
operating-system installation is verified by this release.

Native document backward compatibility is not guaranteed. Preserve original
files when returning to an older binary. Part and Assembly formats are unchanged
by this Drawing follow-up; Drawing uses the current INI 19 / JSON 11 format.
