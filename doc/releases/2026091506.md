# ZIMA-CAD 2026091506

## Development changes

- Mirror and both Pattern modes accept individual original solids. An active
  Body offers its own preceding solid features; Part scope offers Bodies and
  solid features; Assembly scope offers immediate components.
- A selected subtractive feature repeats its cuts in the owning Body. Changing
  the source between Add and Subtract updates the copies during calculation.
- Tree selection and the common View picker retain the exact source. At Part
  level, RMB cycles between the solid and its whole Body before confirmation.
- Native Part version 23 and Assembly payload version 31 persist the inherited
  source operation. Factory templates and current test fixtures are updated.

GUI/CLI builds and eight related contracts passed. See
[Mirror and Pattern](../MIRROR_AND_PATTERN.md#acceptance-on-2026-09-15).

This is a development revision, not a published Windows package. The signed
stable release remains `2026091505`. The root `zima-cad.bat` continues to launch
the local development build.
