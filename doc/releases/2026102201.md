# ZIMA-CAD 2026102201

Windows release preparation; publication and packaged acceptance are pending.
The user tested the normal Windows build positively, accepted automated
verification of the subsequent arithmetic-input correction and authorized
publication before further feature work. Final committed-source package
acceptance remains required.

Ordinary Feature hover, selection and inspection use the original analytical
creation/Properties preview wire, visible through the model at normal line
width. Whole-solid selection does not fill faces. View and Tree selection share
the owning Feature; double-click exposes its parameter dimensions through the
existing inspection path. Exact current Face boundaries remain available for
placement/reference entry, retaining the offered fragment while storing its
original ancestry.

Swap sides reverses physical directions while each original panel retains its
own operation, dimensions, draft, locks and end references. Logical Start/End
identities survive reversal, native readback and Undo/Redo. Extrusion, Revolution,
Twist and datum Axis consume the same direction mapping. See the
[finite direction matrix](../verification/20261022-feature-side-reversal.md).
The additional numeric Direction parameter supports deterministic +1/-1
Relations. Negative manual lengths/rotation angles and grip crossing reverse
physical directions without exchanging panels. Two numeric Revolution grips
stop at their shared angular end. Native and actual mouse/View dimension checks
pass; see [numeric direction](../FEATURE_DIRECTION_PARAMETER_PLAN.md).
The side fields also accept arithmetic: `70-100` reverses the direction and
stores positive magnitude 30 in the entered unit. Invalid expressions remain
editable and cannot commit; unit conversion, locks and unchanged confirmation
retain their existing contracts.

The correction batch also fixes Symmetric second-point hover, Slot first-centre
markers and inference priority, unchanged dimension inspection, default unchecked
Point/Text display, axis-based Opening entry direction, and Drill Point creation
on partial planar bore bottoms. Feature/Sweep axis Reference is verified without
an unnecessary alternate implementation. [The correction record](../PRE_RELEASE_CORRECTIONS_20261022.md)
documents finite equations, mouse tests and remaining platform/package gates.

A first planar support for a newly authored profile uses a real local XY/TOP
frame. Existing explicit FRONT/TOP roles retain their authored meaning. Sketch
entry orients the camera consistently with the real frame, including rotated
Bodies; the Drawing sheet/title-block convention is preserved. The
[factory origin and preview audit](../verification/20261022-factory-origin-preview-audit.md)
records existing-frame and library GUI coverage.

Default Origin and whole-Origin Tree entry inherit the owning Origin's aligned
axes. The individual first-face XY authoring rule is scoped away from complete
frame entry. Sketch placement resolves the parent of its owning container,
including the existing Flat behavior. [The focused correction](../PROFILE_WHOLE_ORIGIN_CORRECTION.md)
records actual GUI axes, persistence, Undo/Redo, five-language and factory checks.
Existing stored placements are not rewritten.

Sketcher corrections retain equality inference during second-endpoint axis and
H/V offers, preserve source constraint annotations around rounded corners, and
reject the reported invalid rolled-L dimension edit safely. Exact external trim
boundaries retain their geometric support. Detailed scope and remaining limits:
[endpoint equality and corners](../verification/20261021-sketch-equal-endpoint-corner-markers.md),
[rolled L](../verification/20261021-rolled-l-dimensions.md), and
[external references/trim](../verification/20261021-external-reference-trim.md).

The approved native extension stores independent Feature direction reversal in
Part/Assembly definitions. Factory conversion recalculates and saves 1,046
Part-based definitions, reopens exact calculated data and compares authored
history, Sketch data, volume/area and reference identities. Six start templates
are regenerated. Custom user libraries and projects are not bulk-converted.

This release does not complete the planned Face × Sketch-plane intersection
commands. Their [native foundation](../verification/20261021-sketch-face-plane-foundation.md)
and [remaining integration plan](../SKETCH_INTERSECTION_REFERENCE_PLAN.md) are
separate. Windows and Linux share C++ sources and the OCCT 8.0.0 pin; Linux-host
execution and Linux packaging remain unverified in this change.

The final committed-source, signed archive, native runtime, factory-file and
anonymous-download results must be added after acceptance. Portable user data
remain outside version directories. The ordinary development entry point stays
at the repository-root `zima-cad.bat`.
