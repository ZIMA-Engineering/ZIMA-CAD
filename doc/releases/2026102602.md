# Windows 2026102602 — sheet attachment, selection and copied axes

This signed Windows release contains the focused corrections developed after
`2026102601`.

- A new Flat can attach directly to any straight outer perimeter edge of an
  existing Flat. The prepared rectangle stays coplanar, follows the selected
  edge and grows away from the source panel with either endpoint as Origin.
- Default Flat, Bend and Pattern names use localized three-digit numbering in
  both GUI and CLI (`Tabule 001`, `Ohyb 001`, `Pole 001` in Czech), without
  colliding with names already present in the document.
- Hiding axis endpoint points hides only their markers. It no longer removes
  overlapping sheet faces, ordinary features or cylindrical subtraction faces
  from hover and click selection.
- Sheet picking uses the actual displayed authored panel region while resolving
  to the existing persistent face ancestry. Later coplanar Flats remain
  selectable without changing the oldest-face identity or making consumed
  regions selectable.
- Mirror and Pattern copy profile, Origin and centroid construction axes,
  centerlines and endpoints as visible derived construction. These objects keep
  their source parent, update after a source change and survive save/reopen.
  Their idle endpoint markers inherit the same brown construction presentation
  as the copied axis, including a Pattern made from mirrored geometry.

The shared Windows/Linux C++ implementation and OCCT 8.0.1 pin remain aligned.
There is no native format version, required sidecar/cache, calculation precision,
geometry-side, oldest-face or protected container-placement change. No new
user-visible text was introduced; the existing translations supply the localized
base names in Czech, English, German, French and Russian.
