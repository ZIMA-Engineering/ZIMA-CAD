# Windows 2026111101 — Sheet and Sketch workflow corrections

Status: Windows release source prepared; signed publication acceptance is
recorded after the immutable assets are published.

Pattern and Mirror occurrences now inherit the current source Part and Body
appearance, including after native save/reopen, without regenerating or changing
the Assembly. Sheet Cut resolves its Up-to target from the selected Sketch and
accepts a valid target on the side opposite its initial direction.

Editing a normal subtractive Feature on an imported sheet now resumes from the
exact persisted Body immediately before the cut. On the reported `02.prtz`
diagnostic copy, the ordinary Feature edit completed in 988.122 ms and the final
Sheet Cut edit in 484.286 ms, with unchanged history-prefix identity, boundary
count, save/reopen and Undo behavior.

Ordinary Sketches can now contain embedded reference images through the existing
image command used by drawing templates. Images support placement, size, aspect
locking, rotation, opacity, visibility and selection locking, remain editable
from the Tree and are stored inside the native Part. They are presentation-only:
they do not participate in constraints, profiles or model operations. Ordinary
Sketch coordinates remain left-to-right while the established right-anchored
drawing/title-block convention is preserved.

Sketch tangency at an already shared native point no longer creates a redundant
Coincident relation. Dimension value text receives click priority when an
overlapping relation marker is present, and small-circle Mirror interaction uses
the intended curve rather than the point hit radius. The empty-workspace
watermark now shows the complete `ZIMA-CAD` product name.

The retained STEP-to-sheet algorithm was also exercised on the reported
`17.prtz`: conversion from the selected side face creates six Flats and five
Bends, reconstructs both rounded ears as one Bend each and preserves all 74
openings as native circles. Cold regeneration and reopen passed.

Nineteen focused native and GUI contracts passed, including the applicable
Sketch equation, repeated edit/drag, persistence, Undo/Redo, image, derived-copy,
sheet exchange, Sheet Cut and five-language catalog paths. The known unrelated
`zima_cpp_model_calculation_tests` endpoint-face assertion remains reproduced and
is not presented as fixed. No calculation precision, protected shared placement,
geometry-side meaning, Qt 6.11.0 or OCCT 8.0.1 pin changed. Optional Sketch image
persistence does not require a native format version increment or factory asset
regeneration. Native Linux build and execution remain a separate host gate.
