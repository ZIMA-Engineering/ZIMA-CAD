# ZIMA-CAD 2026091505

## Windows portable release

This version follows the signed Windows release `2026091504`. Existing signed
installations can use Settings > Updates > Install and restart. For a new
installation, extract the complete ZIP into a new directory and start
`ZIMA-CAD.exe`. The package includes the native Windows runtime, matching source,
documentation, factory configuration and dependency notices. Development continues
through the existing root `zima-cad.bat`.

## AI console

- Settings > AI contains native Codex connection, ChatGPT sign-in, model choice
  and connection status. Use your own account; Codex is installed separately.
- Type `codex` in the desktop console. Each request follows the active Part,
  Assembly or Drawing and its active occurrence and confirmed selection.
- Model and file changes require review in the console and use the existing
  shared CAD command host. Switching the tab or changing its revision invalidates
  a pending command. Completed changes keep ordinary CAD history behavior.
- `/new`, `/exit` and Stop manage the conversation. A draft typed during a request
  remains editable and is never sent automatically.
- Settings and console controls are translated into all five application languages.

See [AI console setup and verification](../AI_CONSOLE.md). Local protocol, real CAD
command and GUI tests passed. A live authenticated ChatGPT response remains a user
acceptance step after signing in.

## View interaction

- The Part/Assembly ↔ Drawing navigation button uses the main toolbar's hover
  and pressed feedback.
- With both Perspective and Fly enabled, the wheel follows the same zoom
  direction as the other navigation modes. Both directions were checked in all
  four projection/navigation combinations.

## Platform and account scope

This package is for Windows x64. Linux runtime acceptance remains assigned to
Linux. Codex is optional, installed separately, and uses your own ChatGPT account
and its usage limits. No account credentials or Codex runtime are included in the
CAD archive. Open Settings > AI to connect and sign in, then type `codex` in the
CAD console.

See [Application updates](../UPDATES.md) and [AI console](../AI_CONSOLE.md).
