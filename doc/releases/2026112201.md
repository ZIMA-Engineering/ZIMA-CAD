# ZIMA-CAD 2026112201

FEM Curve and Surface conditions now own an editable Sketch with the same plane,
offset and automatic reference entry as an ordinary Feature. An explicit option
projects that Sketch onto selected Body faces. Pressure supports both direct
faces and Sketch regions for authoring and meshing; pressure-load solving is
still unavailable.

Sketch OK and Cancel are prominent at the top right. English is the default on
first launch, while existing language preferences are preserved.

Drawing details start without copied visible dimensions and have their own
dimension frame and layout. Dimensions can extend outside the detail boundary.
Projected views can inherit breaks at the parent's matching model positions;
the break editor has a larger landscape preview. Detail insertion instructions
use the existing assistant. Show/Erase includes solid extrusion length, and an
edge-on model diameter supports witness lines and dragging in the view plane.

Straighten/Restore preserves attached openings through a Twist. Exactly planar
spline supports inherited from a Twist can define both bore and thread Up to
limits. Drawing nominal lengths remain unsigned.

The [finite verification report](../verification/20261122-fem-sketch-and-drawing.md)
records Windows geometry, Sketch interaction, drawing, persistence, localization
and native asset checks, together with their limits. Linux execution remains
unverified in this Windows release cycle.
