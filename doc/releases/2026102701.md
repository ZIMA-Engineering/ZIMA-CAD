# Windows 2026102701 — exact cache packets and responsive close

This Windows release candidate follows `2026102603` with a conservative native
I/O and interaction correction batch. It contains no experimental local-Boolean
or semantic-kernel redesign.

## User-visible changes

- Closing a large already saved document detaches its document family and View
  geometry immediately; immutable history and picking storage can be destroyed
  away from the UI thread.
- An oriented Rectangle can enter axis selection with RMB even while the pointer
  remains over its first corner or another overlapping candidate.
- Deleting a segment that owns a rounded mirrored corner also removes obsolete
  corner-radius constraints. Unselected source/copy geometry remains editable.

## Native workflow performance

- Viewer cache v2 stores repeated triangle identities as run lengths and edge/
  point coordinates as validated binary arrays while retaining exact topology,
  sheet-side, display-owner and treatment metadata.
- Exact measurement-source prefixes are stored once only when every source
  archive, property and topology binding matches; unsupported layouts retain the
  complete representation.
- Existing v1 calculated caches remain readable. Save writes v2 without changing
  the authored Part format, requiring a project conversion or adding a sidecar.

On the protected representative Skeleton copy, observed save changed from about
17.0 s to 12.394 s and reopen from 13.7--13.8 s to 9.716 s. Complete current-cache
load was approximately 9.45 s. The authored-definition digest and every expanded
calculated packet digest match. These observations are a 27--30% I/O improvement,
not the tenfold gate required for the proposed broader internal redesign. See the
[performance record](../performance/20261027-native-cache-close-and-redesign-gate.md).

No geometry precision, authored content, topology/reference identity, geometry
side, Undo/Redo or protected placement contract was weakened. The shared
Windows/Linux implementation and OCCT 8.0.1 pin remain aligned.

## Verification boundary

Focused Windows native and GUI contracts cover exact viewer-cache round trips,
malformed input rejection, multi-Body/suppression/Boolean restoration, complete
document-family release, rounded mirrored-Sketch deletion and oriented Rectangle
entry on X/Y/oblique axes from both sides. The Sketcher matrix includes repeated
drags and edits, driving/reference and fully constrained states, Undo/Redo and
save/reopen. Czech, English, German, French and Russian catalogs validate; no new
user-visible source text was added.

Native Linux compilation, execution and timing are not established by the
Windows checks. Windows publication acceptance, signed asset digests and updater
discovery will be recorded here only after the release is published and verified.
