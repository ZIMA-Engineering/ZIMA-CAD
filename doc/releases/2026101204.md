# Windows 2026101204 — File Manager navigation and table workflow

## Changes

The File Manager left pane now follows the established ZIMA-Parts navigation
layout more closely. A compact settings toolbar sits above a persistent list of
all data sources, and the active source's directory tree fills the remaining
space. Clicking a source row opens its root even when that source is already
selected. Internal `0000-index` support directories are hidden from the tree as
well as the Overview and Files views.

The Files view replaces the shared name and native-extension filters with a
separate contains filter for every textual table column. Filters combine across
columns and include dynamically discovered metadata and native document
parameters. The version-file toggle remains available below the table.

Writable parameter cells use the same selected-cell click editing behavior as
ZIMA-Parts. Double-clicking opens a file or directory only from the **File name**
column, so editing a parameter cannot also open its document. The former
**Name** header is now the clearer **File name** label. The new filter prompt and
header label are translated in Czech, English, German, French and Russian.
