# ZIMA-CAD 2026102301 — Windows

Status: release preparation. No Windows archive or publication is accepted by
this checkpoint. The immutable preceding release remains
[2026102201](2026102201.md). The root `VERSION` defines this new build identity.

## Changes

- Sketcher provides associative **Intersection → reference** and **Intersection
  → contour** for a face against the active Sketch plane. Multiple native
  branches remain separate choices. Ordinary Reference selects individual
  curves, points, axes and planes. Analytic circles/arcs remain native conics;
  exact splines retain their native basis. See the
  [editor matrix](../verification/20261022-sketch-intersection-editor.md).
- Feature **Up To** has an ordered target table on each side, retained-patch
  choices, independent inspection and reordering, and a signed correction
  below it. Extrusion uses length and Revolution uses angle; both quantities
  retain their own values and support the existing Relations/lock workflow.
- Consecutive intersections support convex and concave limiting chains.
  Corrections retain the original contact's turn, reject spans through zero or
  a complete turn, and preserve earlier material when the end exceeds half a
  turn. Original cap identities survive reordering and correction.
- Changed extended-limit drafts calculate the exact operation wire privately,
  combining rapid edits and discarding stale results. Target eyes inspect
  existing sources; unchanged Properties reuse stored wire. Unchanged OK adds
  neither a calculation nor an Undo step. Ordinary selection uses the stored
  original operand wire through the model.
- All new controls, guidance and row diagnostics are localized in Czech,
  English, German, French and Russian. The Feature dialog exposes at least
  three target rows, with stable eyes and correction controls when resized.
- Intersection commands also accept a native Sketch curve or authored 3D Curve
  against the Sketch plane, producing isolated associative points. Multiple
  roots remain separate; non-unique intervals reject point creation. Native
  bindings retain their exact source and branch, including after cold reopening.
  Explicit Assembly regeneration uses unsaved open source data. See the
  [curve-point and rounded-mirror record](../verification/20261023-curve-plane-points-and-rounded-mirror.md)
  for the finite matrix and separate package gates.
- Sketch Mirror retains rounded corner treatments with their native support
  legs and linked radii. Intrinsic radius annotations appear in the Dimensions
  Tree and can be selected/deleted without removing the rounded geometry.
  Dragging a mirrored point can drive its free source through the existing
  symmetry relation.
- Centered rectangles with connected native-axis symmetries propagate dragging
  from all four corners through the shared H/V equations. Curve/plane queries
  respect retained spline intervals and exact rounded-leg/arc boundaries.
- Assembly cuts retain their own calculated preview wire in the native document,
  separate from component reference topology. Ordinary selection and unchanged
  exact Properties use that wire after cold reopening. Assembly persistence is
  JSON 49 / INI 37 and requires the regenerated Assembly start templates; its
  [verification record](../verification/20261023-assembly-preview-wire.md)
  records the passing Windows native, GUI and template checks and finite limits.
- Includes the post-2201 [individual Reference picking](../verification/20261022-individual-sketch-reference-entry.md),
  [connected-curve Fillet](../verification/20261022-connected-fillet-curves.md)
  and [native circle picking](../verification/20261022-coincident-reference-circle-picking.md)
  corrections, with their linked finite regression records.
- Follow-up fixes for `2000.prtz` cover single-face correction wires, certified
  tangent limiting chains, distinct conic intersection endpoints and erroneous
  pending-Sketch Origin candidates. Part Feature OK can retain a failed geometric
  definition for repair. See the [review checkpoint](../verification/20261023-2000-reference-and-up-to-corrections.md).
  The user requested review of the normal developer build before publication.

The approved native contract covers 1,016 affected factory Parts, including all
four FORM definitions, and six start templates. Custom libraries, Projects,
private configuration and the user's edited M10 Part are preserved. The normal
development entry point remains `zima-cad.bat`.

## Verification boundary

The shared C++ implementation uses Qt 6.11.0 and OCCT 8.0.0. The
[ordered-limit verification](../verification/20261023-ordered-feature-up-to.md)
records 776 native geometry checks, 31 definition checks, 71 complete Workspace
checks, main-window entry/transactions, both themes and all five languages,
Relations/locks, existing Feature/Sketch regressions, all four FORM insertion
probes and actual new-document GUI creation from all six templates. Factory
conversion, dependency verification and portable acceptance have separate
recorded gates.

These are finite verified cases. Arbitrary mixed curved/draft chains, a complete
nested-Assembly GUI matrix and the generic physical-cursor hover suite retain
the explicit limitations in the linked report. Native Linux execution requires
its own host. Sketch Projection and view-relative H/V remain separate queued
work. Signed archive, clean packaged smoke, exact committed factory inventories,
trust, GitHub publication and public download verification remain pending here.
