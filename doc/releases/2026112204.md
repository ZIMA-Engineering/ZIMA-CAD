# ZIMA-CAD 2026112204

FEM thermal analysis can now calculate expansion and stress caused by heating.
Enable **Calculate thermal expansion** in **FEM Body properties**, define
mechanical restraints and run the calculation. The source Part material supplies
the expansion coefficient, stress-free reference temperature and elastic
properties. Mechanical force and pressure remain in the separate static analysis.

A **Measurement point** reports temperature together with ΔX, ΔY, ΔZ and total
displacement. Results offer temperature, displacement and von Mises stress color
maps, with deformation animation and an optional transparent original.

See the [workflow](../FEM_THERMAL_EXPANSION.md) and
[finite verification](../verification/20261122-fem-expansion.md). The scope is
one-way, steady-state, small-strain thermoelasticity with constant isotropic
properties. Linux execution remains unverified in this Windows cycle.
