# Windows 2026111003 — Associative Sheet from Body

Status: signed Windows release published and accepted. Native Linux acceptance
remains a separate host gate.

Native-solid Sheet from Body conversion is now associative. The owning history
row persists stable source face/edge roles and generated Flat/Bend child
bindings, shows still-bound children beneath it in the Tree and regenerates the
dependent target after planar source-dimension or cylindrical-radius edits.
Generated feature and Sketch identities remain stable. Unchanged regeneration
does not rewrite the document, while loss of a required source face retains the
last valid result and marks the dependency unresolved.

A separate source Body remains authored and editable but is excluded from the
destination material result. Same-Body conversion replaces the material at the
conversion boundary. Imported STEP reconstruction deliberately remains an
ordinary independent Flat/Bend sequence, so it is not locked inside the new
association owner.

The imported-sheet reconstruction from 2026111002 is retained: compound Pro/E
rounded ears become one Bend each, complementary semicircles become true native
circles, the first following Bend works from a cold reopen and consecutive Sheet
Profile bends retain the carried material side. Conversion from a source whose
skin is thicker than the requested sheet now extends the new bends to the
original adjoining edge instead of leaving a thickness-dependent gap.

Hover, click and inspection of an authored feature while an Unbend/Bend Back
state is displayed now reveal both its authored preview wire and the corresponding
developed result wire. The result wire reuses already uploaded display ranges,
does not fill faces and performs no geometry calculation or upload during
selection. Sketch segment creation also retains the direct horizontal/vertical
relation when its second endpoint contacts an external support, instead of an
unrelated inferred Parallel relation taking precedence.

Part native format advances from 50 to 51 and Part JSON from 74 to 75. All 1,058
repository-owned Part assets were migrated, recalculated and reopened with the
changed implementation: 5,477 calculated boundaries, zero calculation errors,
exact native readback and zero hash mismatches against the committed outputs.
Fresh creation from the regenerated millimetre Part template passed.

The focused Windows matrix passed Sheet exchange, Profile, Bend, sheet-state,
feature-side, source-wire GPU, Sketcher edit/drag, native persistence, metadata,
five-language catalog and GUI contracts. No user-visible text or translation key
changed. The protected shared placement implementation, geometry-side meaning,
calculation precision, Qt 6.11.0 and OCCT 8.0.1 remain unchanged. Windows and
Linux keep one shared C++ implementation; native Linux build and execution are a
separate host gate.

See the [finite verification record](../verification/20261110-imported-sheet-reconstruction.md).
