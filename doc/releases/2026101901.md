# ZIMA-CAD 2026101901

## Changes

- Opening settings support Ctrl+C from ordinary View/Tree selection and repeated
  Ctrl+V into the existing creation dialog. New copies have independent identity
  and placement. Text editors retain normal shortcuts. The settings snapshot is
  local to one application window. Whole-Origin attachment now supplies the
  correct Opening work plane for calculation, preview and Up-to length.
- Default Feature properties request their complete natural initial height.
  Shared properties layouts retain usable numeric row heights when space is
  limited. Bend endpoint offset dimensions retain their outside-arc display
  placements instead of being overridden by the general dimension envelope.
  A Flat attached to a Bend starts with a referenced, dimensioned 50 mm profile.
- Localized title blocks contain one ISO 13715 indication without the obsolete
  overlapping authored strokes. The English manual is named `USER_MANUAL.md`.
- RAL appearance choices and imported STEP/IGES Part parameters use the reviewed
  shared palette and configured start-Part parameter definitions. Assembly
  insertion feedback uses the same azure color as Part insertion.
- Native fastener authoring adds the verified socket-head, nut and washer
  families, localized tables, metadata, thumbnails and drawings described in
  [the library record](../NUT_AND_WASHER_LIBRARY.md). ISO definitions replace
  historical dimensions only where their correspondence is reviewed. DIN 1587
  is separate from the unresolved historical CSN closed-nut interpretation.
  ISO 7380-1 button heads reside under round-head screws.
- Socket entrances follow constrained revolved cuts. External circular-support
  junction checks preserve their reference geometry. Trimmed analytic physical
  property calculations and section thread-runout hatching retain their actual
  geometric boundaries. Collapsed zero-area display triangles no longer invent
  short boundary strokes.

Shared Windows/Linux C++, Qt 6.11.0, OCCT 8.0.0, the existing native formats and
the development `zima-cad.bat` entry point remain. The Opening correction consumes
the existing placement capability without changing the shared placement solver.
New application text is supplied in cs/en/de/fr/ru.

## Verification and limits

The Opening native matrix covers 32 whole-Origin variants plus the existing
single-plane, catalogue, invalid-input and lock regressions. Physical volumes,
preview axes, references, unchanged confirmation, Undo/Redo, native save/reopen
and cold calculation pass. Opening end-target and activated-component command
contracts also pass. Actual GUI shortcuts, Tree/View sources, repeated pastes,
numeric and whole-Origin placement, Cancel, text clipboard isolation and the
independent three-hole volume pass. See [Opening copy/paste](../OPENING_COPY_PASTE.md).

All five title-block variants pass native rendering/PDF export, Family switching,
A4-to-A3 changes, reinsertion and persistence. Existing drawings retain their
embedded definitions until explicitly replaced. Default properties pass the
400-case five-language/size matrix at normal and 1.5 scaling. Native Bend checks
and the finite GUI editing/isometric check pass; visual review and the four-zero
GUI case remain separate. Detailed scope is in [Bend dimensions](../BEND_OFFSET_DIMENSION_LAYOUT.md)
and [properties layouts](../PROPERTY_DIALOG_LAYOUT.md).

The linked library records retain per-family geometry equations, reference
identities, repeated edits, native persistence and finite GUI coverage. Unresolved
CSN closed nuts, two-part/nylon locking nuts, formed-nose and toothed washers are
not claimed complete. DIN 929/ISO 21670 weld-nut candidates have native matrices
and pilot GUI evidence, but their publication artwork/installation remains
pending; see [weld-nut authoring](../WELD_NUT_LIBRARY.md).

Linux execution, cross-process Opening clipboard transfer, exhaustive end-target
GUI combinations and the previously documented broad wire-thickness assertion
remain verification limits. No signed Windows publication is claimed by this
source record; package acceptance is recorded after the committed-source build,
native dependency, archive, smoke and packaged functional gates pass.
