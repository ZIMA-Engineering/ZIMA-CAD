# ZIMA-CAD 2026101702

Hex-head fasteners now use the approved two-view native reference Drawing layout,
with complete localized legends in Czech, English, German, French and Russian.
Radius leaders clear neighbouring extension lines and historical 15-degree
chamfers use outside arrows. Horizontal thumbnails retain white backgrounds.
Localized illustration HTML/PNGs have neutral fallbacks.

The library contains 200 editable representative products. Combined A/B chapters
use one length per diameter/pitch and omit the redundant product-grade parameter
and overview column. Zero-padded filenames provide ordinary text ordering while
native sizes, stock and standards retain their actual values. Grade C geometry,
partial thread limits and native model identities are retained.

Smooth 3D outlines follow the shaded native-face normal field instead of whole
internal triangulation edges, addressing short transverse strokes on radii and
Sweep surfaces. Real geometry, picking, reference identity and persistence remain
unchanged. Exact unchanged inputs permit outline reuse across pan/zoom helper
refreshes; changed source geometry invalidates it.
