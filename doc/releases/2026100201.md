# ZIMA-CAD 2026100201 — Windows

## Changes

- Reuse exact IGES topology locators within one import operation, retaining source
  identities, geometric precision, ambiguity handling and native persistence.
  The measured locator work fell from 21.2 s to 4.0 s; this is not complete import
  time. Full large IGES packet equality and seven focused tests passed.
- Fix saving STEP/IGES imports after explicit regeneration. Reference resolution
  can change the sign bit of a zero Euler angle; numeric equality previously
  accepted a calculation belonging to a different exact document state. Check
  the existing input fingerprint before convergence and before publishing a
  regenerated result. Preserve fingerprint encoding, native format and all
  authored side choices. Regression covers save, native reload, missing source,
  unchanged repeated regeneration and Undo/Redo.
- Correct the main manual's Relations, dimension driving, colour output, Pattern
  picking, Sweep planes/result modes, theme and centroid/deletion descriptions.
  Reconcile dedicated Sweep/import guides and README distribution instructions.
- Preserve the existing File shortcuts, ISO View/Drawing font and development BAT.

The STEP projector experiment showed no controlled speed benefit and is excluded.
The dominant large STEP/IGES edge-side calculation remains open. No native format,
start-template schema or product-visible string changes are introduced. Linux
verification belongs to the Linux host.

See [manual audit](../MANUAL_REVIEW_20261002.md) and
[import measurements](../performance/20261002-step-iges-projection.md).

## Release acceptance

The clean committed-source candidate and finalized signed archive passed native
dependency, archive path/collision, CRC, SHA-256 and Windows smoke gates. A fresh
signed extraction passed production bootstrap trust. Ten packaged GUI scenarios
passed: five-language Fusion/fonts, 2D/H-Sweep, Pattern dimensions, Relations,
Sketch return frames, history deletion, centroid measurement, whole-Origin and
edge treatments. The packaged CLI imported the 10 mm IGES cube, saved/reopened
it after removing its source file, regenerated it, saved again and retained
1000 mm3 volume. Seven additional fix-focused contracts cover fingerprint encoding, history recovery/deletion,
core behavior, Part/Assembly import and localization. An import saved by the
previous published 2026100102 build also reopened, regenerated and saved.

Seven final source contracts passed again, including import into Parts and
Assemblies and localization. Archive tooling passed eight tests with two
environment skips; sixteen publisher tests passed. All three draft and public
asset downloads matched the accepted digests. The signed 2026100102 updater
verified the public manifest and offered 2026100201 as installable; this check
did not install an update. Local GUI/CLI report 2026100201. The development BAT
remains unchanged. Pre-existing user settings and unrelated local files were
excluded from the clean source/package.
