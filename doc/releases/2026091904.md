# ZIMA-CAD 2026091904 — Linux

This build brings the current application, including the language restart and
multi-document shutdown changes from Windows 2026091903, to Debian 13 x86_64
with KDE/Wayland. It uses native Qt and OCCT and includes exact committed source,
version-local dependencies and factory resources. Windows is not included.

Extract the archive into a new directory and run `ZIMA-CAD/ZIMA-CAD.sh`.
Existing portable installations can discover the signed Linux update.
User settings and projects remain outside immutable version directories.

Native document backward compatibility is not guaranteed. Existing modeling
limitations and the title-sketch and first-open file-list issues recorded in
the preceding releases are not claimed as resolved.

Release validation results will be recorded after candidate and signed-package
acceptance. This is focused Linux acceptance, not a complete regression audit.
