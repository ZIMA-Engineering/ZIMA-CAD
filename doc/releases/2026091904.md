# ZIMA-CAD 2026091904 — Linux

This build brings the current application, including the language restart and
multi-document shutdown changes from Windows 2026091903, to Debian 13 x86_64
with KDE/Wayland. It uses native Qt and OCCT and includes exact committed source,
version-local dependencies and factory resources. Windows is not included.

Extract the archive into a new directory and run `ZIMA-CAD/ZIMA-CAD.sh`.
Existing portable installations can discover the signed Linux update.
User settings and projects remain outside immutable version directories.

Native document backward compatibility is not guaranteed. Existing modeling
limitations and the title-sketch and first-open file-list issues recorded in
the preceding releases are not claimed as resolved.

## Linux acceptance

Source/tag commit: `8d22b7a55fecde951a52954140bd5a0e66ba3043`.
Build identity was allocated on September 19; acceptance continued on September 20.
The Linux build required replacing newer OCCT interpolation array spellings with
the existing portable `TColgp_HArray1OfPnt2d` and `TColStd_HArray1OfReal` types.
The interpolation inputs and algorithms are unchanged.

Passed:

- Full native Release compilation with Qt 6.8.2, OCCT 7.9.3 and GCC 14.2.0.
- Eight packaging tests (one Windows-only case skipped), 16 publisher tests and
  all 23 isolated updater lifecycle tests.
- Eleven native suites: portable settings, STEP models, AI command contract,
  CLI processes, exports, profile commands, Sheet Cut wire preview, conical sheet
  states, sheet-state commands, sheet states and Twisted Sheet.
- The separate generic Sheet Cut regression mode, including rotated Origins,
  cylinder clearance, middle-depth clearance, persistence and regeneration.
- Actual Wayland GUI verification of five-language restart, saved-document
  reopening, Save All/Discard/Cancel, write failure, pending edit protection and
  Updates interaction/approval/cancellation behavior.
- Committed-source candidate dependency closure, safe archive paths, collisions,
  CRC/SHA-256, extraction with spaces and Unicode, launcher/CLI pipes, a 6000 mm3
  Box save/reopen, PDF/JPEG export, rendered GUI startup and preserved user settings.
  The exported GUI view was visually inspected.

Known test limitation: the broader Bend suite stops at an independent Boolean
subtraction probe for `expanding-profile-axis` conical Sheet Cut clearance with
OCCT 7.9.3 (`Assembly cut failed or produced an invalid solid`). The remaining
assertions in that suite did not run. This release does not claim that case is
verified or that the complete regression suite passes. No Windows rebuild or
fresh operating-system installation was tested.

Evidence: `build/linux-1904-*.log` and
`.dist-output/linux-1904-candidate/ZIMA-CAD-2026091904.validation.json`.
