# Windows 2026110402 — Sketch editing and current datum presentation

This build repairs stale pending Origin display, native history references and
editable coupled Sketch dimensions. It also persists each Sketch's view side
and orientation sector and completes independently removable external Segment
midpoints. The previous local `2026110401` tag remains unchanged.

## Resulting behavior

- Confirming an actual placement face and repeatedly changing numeric coordinates
  publishes one current pending Origin through the existing transient preview.
  The ineffective stored-Origin filter is removed.
- Exact history views include requested authored Feature points, Axes, Planes
  and whole Origins through the same native generators as ordinary resolution.
  They retain Body transforms and reference identities. A failed calculated
  face never becomes an older cached face. A valid authored work frame remains
  usable while its own Modeling profile is incomplete.
- Editing an earlier Sketch or radius retains the final visible Body when
  history ends with a reference-only or suppressed datum.
- Either center of a base-axis mirrored circle can follow the permitted cursor
  component. Fixed coordinates, locked dimensions and reference identities remain
  authoritative.
- Coupled dimension edits accept native Arc/Circle EqualRadius relations and
  start failed circular-profile fits from the last valid branch. The existing
  dense fallback extends to larger profiles with a bound on actual scalar unknowns, allowing the investigated
  38-point sheet profile without discarding its persisted equations.
- Sketch front/back and its four orientation sectors survive native save/reopen.
  Presentation metadata does not create modeling Undo or invalidate geometry.
- A new straight external Segment includes an independent midpoint cross. It
  follows the same original edge/occurrence, supports C and independent deletion,
  and does not appear merely because a distant endpoint is hovered.
- The agreed Feature Axis cleanup removes its redundant internal 3D visibility
  switch. The authored Axis has a direct local X/Y/Z direction control; its
  normal history visibility and endpoint reference identities remain authoritative.
