# Windows release 2026100102

## Changes

This build collects post-2026100101 improvements: fewer redundant scene
publications when opening Drill Point Properties; operation-local measurement
allocation, face metadata lookup and partition-centre preparation; and a single
edge traversal for View end-plane border preparation. See the
[optimization status](../performance/20261001-optimization-review-status.md) and
[remaining-area investigation](../performance/20261001-remaining-investigation.md).

The recorded performance changes preserve their original precision, references,
geometry and Undo/Redo contracts. No native format change or product text change
is introduced. The five-language catalog review applies. The development BAT
and user configuration are preserved.

Large STEP/IGES imports and broader persistent-cache redesigns remain open.
Rejected import experiments are not part of the product. Read-only profiling
modes and their limitations are documented. Linux verification is deferred to
the Linux host. This release does not claim the complete repository suite passed.

## Preparation

The focused scene/measurement/drawing/import/GUI gate passed nineteen tests in
79.56 seconds. Three final scene/import/catalog checks passed in 6.44 seconds.
Clean committed-source packaging, signing, packaged GUI checks and public asset
verification are required before publication; acceptance is recorded below only
when completed.

## Release acceptance

The clean committed-source candidate and finalized signed archive passed Windows
native dependency, archive path/collision, CRC, SHA-256 and smoke gates. A fresh
extraction passed production bootstrap trust. All nineteen packaged GUI scenarios
passed: five-language Fusion/fonts, 2D/H Sweep, Pattern dimensions, Relations,
Sketch return frames, history deletion, Family names, Assembly/scoped refresh,
centroid measurement, whole-Origin, edge treatments, Shell opening, Boundary
Surface, profile limits, surface profiles, selection filters and Drill opening.

The final source STEP/IGES/catalog checks passed again after withdrawing both
experimental kernel changes (three checks, 6.52 seconds). Archive-tool tests
passed eight checks with two environment skips; all sixteen publisher-input tests
passed. Authenticated draft and anonymous public downloads of all three assets
matched accepted SHA-256 digests. The signed 2026100101 updater verified the
manifest and offered 2026100102 as installable. No update was installed by that
check. Local GUI/CLI were rebuilt; the CLI reports this build and source commit.
The development BAT was not changed. Pre-existing user configuration changes
were excluded from the commit and clean package.
