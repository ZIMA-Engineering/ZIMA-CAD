# Windows 2026101205 — read-only File Manager sources

## Changes

The File Manager now applies a source's read-only state to automatic native
parameter mirroring as well as direct cell editing. Browsing a read-only factory,
library or network source displays its native parameters without creating or
updating `0000-index/metadata.ini`. Writable sources retain metadata version 3
mirroring and native parameter editing.

This is a narrow follow-up to 2026101204. Its persistent source list, hidden
`0000-index`, per-column filters, selected-cell parameter editing and
file-name-only opening behavior are unchanged. No user-visible text was added;
the Czech, English, German, French and Russian catalogs remain complete.

## Verification status

The synthetic File Manager contract now includes a dedicated read-only source
with a native Part. It verifies that the Part and its parameter remain visible,
the parameter cell is not editable and browsing creates no metadata directory.
The existing writable-source edit and mirror checks continue to pass.

No native document schema, geometry algorithm, metadata format,
container-placement contract or OCCT version changed. Native Linux build and
desktop verification remain assigned to the Linux host.
