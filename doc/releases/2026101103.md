# Windows build 2026101103

Confirmed View containers use their exact Tree context menu, including Delete,
confirmation, dependency handling, Cancel and Undo/Redo. Unrelated Tree selection
cannot join a deletion requested from the View. Origins and derived parameters
retain their existing ownership rules.

The Fusion Tree uses palette-aware continuous guides from above with right-angle
branches. Logical-pixel strokes overlap adjacent row boundaries to prevent gaps
at fractional display scaling. The focused test checks every physical pixel
through two successive rows and verifies live Light/Dark/Light, disclosure arrows
and selection. Screenshots of both themes were inspected.

Native point attachment to a circle, arc, ellipse or elliptical-arc characteristic
point now persists independent C+K relations. Removing K retains contact and
its identity. Existing C is reused, and insertion remains one atomic solve.
DOF analysis accounts for generated-coordinate dependencies without double-counting
the implied C. Trimming and Loft correspondence retain the independent contact.
Three-point angles support either input order with a K-anchored ray. Symmetric
drivers retain their structural equations after unlocked dragging.

The focused native matrix covers 860 cases with independent equations, repeated
value edits/drags and persistence. Eight GUI fixtures cover all four native
conics and both orders, actual mouse picking/cycling, Delete K, exact-ID
Undo/Redo, C-only movement and save/reopen. Applicable limitations and finite
coverage are explicitly recorded in [the contact matrix](../SKETCH_KEYPOINT_CONTACTS.md),
including existing K-only distance-driver rejections and nonanalytic open
external profiles. This is not exhaustive verification of every Sketcher variant.

Visible standalone Sketches and 3D Curves remain ordinary objects, but cannot
become body-operation references. Hover and confirmation use the same predicate;
Part refresh restores it. Lookup data is immutable and shared by copied callbacks.
Repeated triangles of the same face do not allocate repeated lookup keys.

Modeling and Sheet Metal use vertically stacked exclusive buttons with existing
Part/Bend icons, Modeling first. They share the existing Applications actions,
per-document mode, contextual Insert menu and editing restrictions. Mode changes
do not create document transactions. Both themes and live switching were checked.

label now uses the shared Delete key. Catalog/UI validation passes.
