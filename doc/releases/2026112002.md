# ZIMA-CAD 2026112002 — Windows

General Surface Sketches retain preceding owned Sketches and 3D curves as
read-only reference context. Reference and Reference-to-profile preserve source
identity, and converted curves no longer expose internal spline poles as loose
Sketch points. Side-plane intersections and owned Sketch frames are corrected.

Solid Twist exposes curved centroid axes with pickable endpoints. Straighten
and Restore carry end-attached plain extrusions using the complete end-frame
transformation. Twisted Sheet displays editable length, angle and L/R direction;
its preview axis uses the placed frame. Axes on a following Flat move with its
material through Unbend and Bend Back. Connected Flat attachment is verified
for both twist directions, both boundary endpoints and both material skins.
Misleading Add/Subtract controls are hidden for Twisted and Revolved Sheet.
Sheet Transition no longer adds loose Origin strokes to its authored preview.

Loft correspondence retains its first point and direction, with View point
ordering and Surface output. Three-station anchored guide cases now pass.
Sweep station/profile context, point ordering under transformed Bodies,
inspection-history ordering, text placement and reference handling are improved.
Cursor-centered orbit and named views preserve the selected camera center.

This build includes the previously approved Part native 56 / serialized 79
and Assembly native 38 / serialized 50 changes. All 1,060 affected current
native assets and six start templates were verified; factory data is committed
with its implementation. The twelve unchanged unsupported legacy test fixtures
are outside the factory library. Protected Toyota originals remain untouched;
their older unsupported Part formats still prevent complete project regeneration.

The thin rectangle/circle/slot Loft remains a known failure for positive
thickness. Arbitrary guide contacts away from numbered profile anchors remain
unverified. The intermittent model disappearance has not been reproduced.
Faster dimension entry remains a proposal. Linux execution is a separate host
gate; Windows and Linux retain shared C++ source and OCCT 8.0.1.
