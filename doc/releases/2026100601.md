# Linux 2026100601

Status: signed Linux release published and verified on 2026-10-06.

This build includes the current main branch through `c2b1c68a`, including the
surface modeling tools delivered in the recent Windows releases. It adds a
small SDK API adjustment for surface-intersection wire connection: OCCT 7.9
uses TopTools_HSequenceOfShape and an output parameter; OCCT 8 uses the generic
sequence and return-value API. Both use the same tolerance, shared-vertex policy
and downstream geometry/ancestry processing. No UI text, native format or
protected shared placement contract changed.
