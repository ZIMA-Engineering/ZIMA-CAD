# Windows release 2026100101

## Changes

This build collects measured modeling and viewer optimizations since 2026093007:
less repeated Assembly/source preparation, scoped copy/scale previews, local
Body-context transfers, exact shading adjacency and silhouette preparation,
reused camera-dependent silhouette buffers, and fewer scene publications when
opening Sweep, Extrusion/Revolution, Boundary Surface, Fillet/Chamfer and Shell
Properties. See the [command audit and measured follow-ups](../performance/20261001-command-properties-audit.md).

H-Sweep retains its rotation axis with brown endpoint markers and prior Sketch
context. Sweep action/Sketch button shapes are consistent, the measurement
inspector fits its contents, and Chamfer annotations use the dimension envelope.
The accepted H-Sweep calculation policy permits overlapping coils and omits
unused reference-packet work; this is not a claim that self-overlapping input
forms a valid manifold solid for every downstream operation. Profile-side and
Sheet regression fixtures were repaired, and resolved Sketch frames participate
in calculation convergence.

No native format change is introduced by this release. Localization review
uses the five-language catalog contracts. New-feature development now follows
[performance-by-design rules](../FEATURE_PERFORMANCE_GUIDE.md), including explicit
calculation boundaries, data ownership and equivalence verification.

The user-reported corner-drag issue in an older Sketch document was withdrawn
after a new document worked. No Sketcher production change is included for it.

## Verification status

The individual optimization records retain baseline commits, fixture scope,
measured timings, exact data/frame comparisons and targeted regression results.
Shell's final six selected contracts passed in 79.05 seconds. The existing first
Shell opening may change camera framing; its benchmark measures subsequent
openings from the same established frame. The broader repository suite and
Linux acceptance are not claimed.

## Release acceptance

The clean committed-source candidate and finalized signed archive passed native
Windows dependency, archive path/collision, CRC, SHA-256 and smoke gates. A fresh
extraction passed production bootstrap trust. All eighteen packaged GUI scenarios
passed: five-language Fusion/fonts, 2D/H Sweep, Pattern dimensions, Relations,
Sketch return frames, history deletion, Family names, Assembly/scoped refresh,
centroid measurement, whole-Origin, edge treatments, Shell opening, Boundary
Surface, profile limits, surface profiles and selection filters. Surface-profile
verification initially could not save its diagnostic image because the clean
source extraction had no build directory; creating that test-output directory
and rerunning the scenario passed without changing the archive or product code.

Archive-tool tests passed eight checks with two environment skips; all sixteen
publisher-input tests passed. Authenticated draft downloads and anonymous public
downloads of all three assets matched accepted SHA-256 digests. The signed
2026093007 updater verified the manifest and offered 2026100101 as installable;
no update was installed by this discovery check. The local GUI/CLI were rebuilt.
The development BAT and user configuration remain unchanged.
