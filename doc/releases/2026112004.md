# ZIMA-CAD 2026112004 — Projection

Projection is available in the shared Feature command. An ordinary planar input
Sketch projects onto selected bounded faces in its normal or a referenced
direction. Reverse changes the direction. The nearest nonnegative target is
used for each source interval; holes, uncovered spans and ambiguous targets are
not silently filled.

The three outputs are native spatial curves, face partitions preserving the
original material, and explicitly selected independent surface patches. Source
dimensions remain editable. Native ancestry, region selection, external source
ownership, save/reopen and Undo/Redo follow the shared document lifecycle.
Preview, inspection and unchanged OK do not calculate native geometry.

The required Projection definition extends only the new Feature type. Existing
format discriminators, file extensions and ordinary Feature definitions remain
unchanged. The shared placement solver is unchanged. All five UI languages are
included, and selected Plane wires remain visible over coincident passive planes.

This version also includes the General Surface, Twist, sheet attachment and
preview repairs from [2026112002](2026112002.md), and the mixed Loft Thin/Shell
repair from [2026112003](2026112003.md).

The [finite acceptance report](../verification/20261120-projection.md) records
26 directional geometry cases, native history and downstream surface operations,
48 source dimension/drag combinations, placed/nested external sources and actual
View/Tree interaction. Six start templates were rewritten and reopened with the
current implementation, then new documents were verified through the GUI. All
1,185 factory assets and eleven protected project originals remain unchanged.

Linux native execution and arbitrary Sketcher constraint combinations are not
claimed. A broad ordered Up To native control also fails on the accepted
pre-Projection baseline; the targeted cylindrical Up To GUI contract passes.

## Distribution status
