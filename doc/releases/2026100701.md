# Windows 2026100701

Status: prepared for committed-source Windows packaging on 2026-10-07.
Tag: `ZIMA-CAD-2026100701`.

This release retains the oldest contributing feature identity for coplanar
Boolean faces, shows the actual visible fragment consistently during face
reference entry and inspection, and removes coplanar joining lines. Fillet
and cutter highlighting follows persisted semantic ancestry. Fillet shading
uses consistent angle-weighted normals within each CAD face, preserving real
face boundaries and occurrence separation. These shared viewer rules also
apply to interactive Drawings.

Connected circular Equal constraints propagate radius/diameter edits through
all members, including four rounded rectangle corners. Straight-segment C+T
capture shows one endpoint and releases to C without a second cursor state.
Drawing scale ratios use M1:1 notation in Properties, captions and vector output.

Eleven targeted native and GUI suites passed before packaging, covering
translation catalogs, viewer contracts, Sketcher equations, Drawing DXF,
surface placement, actual FORM topology, Drawing view controls, four equal
corners, disconnected Boolean fragments, FORM Boolean geometry and endpoint
capture. The equal-radius mathematical matrix covers 192 corner variants plus
longer circular chains; detailed scope and remaining variants are recorded in
[Equal radius](../EQUAL_RADIUS_COMPONENT_FIX.md),
[FORM topology](../FORM_BOOLEAN_TOPOLOGY_FIX.md),
[display audit](../FORM_DISPLAY_AUDIT.md) and
[segment capture](../SKETCH_SEGMENT_CONTACT_CURSOR_FIX.md).

Localization review covers Czech, English, German, French and Russian. Existing
shared labels remain translated in all five catalogs; the M ratio is invariant
technical notation. No new user-visible prose or native format is introduced.
Documentation and the updated manual are English. Personal settings, working
Parts, Drawings and backups are excluded from the release source.

Windows checks do not establish Linux execution. Three unrelated baseline
failures remain: Extrusion Limit expected 20 but produced 20.635083; Surface
Profile hidden-sheet geometry/picking retention; Boolean Assembly access
violation 0xC0000005 reproduced at the preceding source commit. The targeted
passing tests do not constitute a completely passing full test suite.

Archive, signature, packaged GUI and public-download acceptance will be recorded
after the corresponding gates complete.
