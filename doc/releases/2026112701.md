# Windows 2026112701 — Keyways and sheet conversion

Status: source prepared for Windows distribution; publication acceptance is
recorded after candidate and signed-package verification.

- Create shaft keyways in a tangent local XY Sketch, and hub keyways in transverse
  Sketches aligned with the actual bore axis. Cylindrical hubs use Extrusion;
  generator-parallel conical hubs use two Sketches and Loft.
- Repair angular placement of hub cuts, including already saved unresolved
  examples. Preserve selected references, source edits, native reopening and
  Undo/Redo. Hide the unrelated auxiliary axis.
- Retain a failed keyway in the Tree after the second unchanged OK, with a
  visible error and an editable definition. Draft errors also appear in Properties.
- Offer the explicitly named historical CSN 02 2507 / 02 2562 table alongside DIN,
  with larger retained sizes and documented provenance in Engineering Tables.
  Add authored parallel, retaining and Woodruff key library models.
- Improve three-level Sheet-from-Body corners with independent fractional Bend
  coefficients and editable lower Flat corrections. Preserve parallel edges and
  exact source attachment. Remove the stale RIP plane after editing.
- Support offset open 2D Sweep paths and reversible station entry while retaining
  native profile identities, material side and explicit Sketch planes.
- Include the verified analytic Wrap/Projection target continuation and Windows
  taskbar icon repairs already completed in this development session.

All affected user-visible text is translated into Czech, English, German, French
and Russian. The normal local entry point remains `zima-cad.bat`; the portable
archive carries its own native runtime.
