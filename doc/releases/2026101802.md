# ZIMA-CAD 2026101802

## Changes

- Changing sheet format selects the matching Family variant from the frame
  definition embedded in the Drawing. Title-block geometry, selected variant,
  fields, authored data and right/bottom anchor remain unchanged. Missing or
  ambiguous variants reject atomically. A sheet without a frame can change
  format directly. No external template file is needed after embedding.
- Engineering Tables add 74 studs and 40 cylindrical-head screws, with native
  editable histories, localized metadata, horizontal white thumbnails and six
  independent representative Part/Drawing pairs. ISO 1207 head-height corrections
  have explicit source provenance. Cylindrical-head dimension tables are
  transposed and retain fixed headers and complete-row azure reading markers.
- Fitted and small-hex-head illustrations appear contiguously in one row.
  Fitted `ds n6` labels move above the cylinder; the redundant directory-index
  tolerance column is removed while the native n6 definition remains.

See [factory authoring and verification](../STUD_AND_CAP_SCREW_LIBRARY.md) and
[fitted bolts](../FITTED_BOLT_LIBRARY.md). All changed/new user-visible text is
available in cs/en/de/fr/ru. Native extensions, schema, kernel version and the
protected container-placement implementation are unchanged.

## Checks

- All 25 A4–A0 format pairs verify embedded Family selection, exact preservation
  of non-frame sheet data, one transaction for actual changes, no-op behavior,
  Undo/Redo and native persistence. GUI checks exercise the bottom selector and
  Sheet Properties OK/Cancel and verify the retained title block after reopen.
- 222 stud edits and 120 cylindrical-head edits include independent geometry,
  mass, thread identity, Undo/Redo and native reopening checks.
- Actual browser checks cover six topic pages, five languages and
  Light/Dark/Light without theme reload, including fixed headers, loaded
  illustrations and the complete-row reading marker.

The broader existing native-title-block authoring GUI scenario stops before
the format checks at its preceding-frame visibility assertion. The dedicated
format-control GUI check passes; the broader authoring scenario is not reported
as passing. Previously documented unrelated hover-style/general-surface gaps
remain; Linux runtime execution is unverified.

Windows package, signing and public-download acceptance are pending the clean
committed source build and release gates. The superseded 2026101801 candidate
remains unpublished; its frozen source tag and verified local archive are kept.
