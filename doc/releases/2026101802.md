  definition embedded in the Drawing. Title-block geometry, selected variant,
  fields, authored data and right/bottom anchor remain unchanged. Missing or
  ambiguous variants reject atomically. A sheet without a frame can change
  format directly. No external template file is needed after embedding.

  tolerance column is removed while the native n6 definition remains.
