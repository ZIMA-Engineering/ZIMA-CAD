# ZIMA-CAD 2026112101 — Projection presentation and FEM Body

Projection displays its source Sketch, projected preview and point markers in
the theme foreground. Selecting the feature highlights both source and result
with the ordinary azure wire. Endpoint references remain selectable. No dashed
connecting guides are added. Target and retained-region reference tables remain
visible together and expand their viewports with the Properties window.

Create FEM at Part Body-list level opens one shared internal Properties window
for creation and editing. The analysis references a preceding calculated Body,
consumed Body or Boolean result by stable identity and shares its geometry.
Activating FEM displays that source once and exposes analysis properties;
returning to Part restores ordinary modeling. Name/source edits use metadata-only
Undo transactions and do not calculate CAD or duplicate material volume.

This is the first FEM Body/source milestone. Conditions, volume mesh generation,
the mechanical solver, results, legend and animation are not working commands in
this release. The native foundation stores the new FEM definition inside `.prtz`;
ordinary native definitions and shared placement solving remain unchanged.

The [acceptance report](../verification/20261121-projection-and-fem-body.md)
records geometry/history checks, actual View/Tree and Properties interactions,
no-calculation counters, five-language/two-theme checks and template creation.
Linux execution and the explicitly listed untested FEM GUI variants are not
claimed. The existing Windows 2026112004 modeling fixes are included.
