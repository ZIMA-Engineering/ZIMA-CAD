# ZIMA-CAD 2026111703

Status: OCCT API modernization and regression verification passed; publication pending.

This build uses the current OCCT collection templates and native C++ scalar
types in place of deprecated collection headers and aliases. The replacements
are the same concrete types defined by OCCT 8.0.1; array indexing, shape hashing,
numeric precision and modeling algorithms retain their existing behavior.
No deprecation warnings are hidden with compiler suppression.

All 39 selected geometry, persistence and interaction contracts pass, including
two corrected test fixtures. Seven saved Fillets and five Chamfer variants
retain exactly matching recorded metrics. The Sketcher GUI matrix passes
16 cases and 576 dimension variants, and all five translation catalogs pass.

It includes the Fillet/Chamfer, circle inference and Mirror corrections from
[2026111702](2026111702.md). Native formats, factory assets and protected shared
placement contracts are unchanged. Windows and Linux continue to share one
C++ implementation with OCCT 8.0.1 and Qt 6.11.0. The normal local Windows entry
point remains `zima-cad.bat`.

See the [API modernization verification record](../verification/20261117-occt-current-api.md).
Native Linux verification remains a separate host gate.
