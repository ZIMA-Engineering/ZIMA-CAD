# ZIMA-CAD 2026112404 — Windows

This release adds Wrap sketch and Wrap relief on cylindrical, conical and
spherical faces, and completes the FEM result player with external MP4 export.
Windows publication is pending the
committed-source package, signature and public-download acceptance gates.

## Wrap

- Choose Wrap sketch or Wrap relief in the shared Feature Properties dialog.
  The type menu opens downward. The placed Feature Origin anchors the mapping;
  source coordinates extend to either side, with independent direction reversal.
- Wrap sketch creates curves or closed surface regions and can carry an
  embedded Sketch image. Wrap relief adds or removes material using the normal
  Correction. Image pixels remain artwork and are not converted into relief.
- Cylinder arc lengths and cone sector development preserve planar lengths.
  Spheres use geodesic mapping with transverse distortion. Singular domains,
  overlapping images and regions outside the selected bounded face are rejected.
- The planar source Sketch remains editable. Source edits, Family suppression,
  missing-reference repair, Undo/Redo and native save/reopen retain their normal
  history behavior. Preview, selection and unchanged OK avoid body calculation.
- New Wrap data and embedded artwork stay in the native document. All six start
  templates were regenerated; existing factory asset bytes remain unchanged.

## FEM results

- Result controls are direct buttons. A compact in-application player provides
  Play/Pause, timeline, duration and deformation magnification.
- Save video suggests the native document basename and writes an external MP4.
  It does not embed the video in the Part. Failed export preserves an existing
  destination file.
- Show mesh is restored when returning to the active FEM Body. Activating
  another Body displays that Body instead.

## Verification and limits

The finite Windows matrix covers all three supports and output types, polar
spherical anchors, holes, open curves, images, downstream cuts, explicit
regeneration, actual reference picking, whole-Origin placement, selection and
five languages in both themes. Native dependent suites, all 1,190 factory
loads, template-created documents and the complete FEM GUI suite pass.
The current `50.prtz` regenerates on a copy. Toyota originals remain unchanged;
eight older native files retain their previously unsupported-format status.

Native Linux execution and a dedicated interactive external-Skeleton/nested-
Assembly Wrap matrix are unverified. Assembly Render remains future work.
See [Wrap verification](../verification/20261124-wrap.md) and
[FEM player verification](../verification/20261124-fem-player-and-video.md).

## Distribution status

Committed-source portable acceptance, signing and publication are pending.
