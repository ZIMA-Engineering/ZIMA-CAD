# ZIMA-CAD 2026092701 — Windows

This unreleased development checkpoint adds explicit placement solution branches
and transition attachment and interaction updates. Verification is incomplete.

- Circle/ellipse and cylinder/plane placement remembers the selected branch,
  including passage through tangency. An unreachable branch becomes invalid
  without jumping to the other solution. The shared Solution branch field uses
  View picking and an independent inspection eye.
- Rectangular transition previews draw omitted profile sides and the omitted
  corner generator with dashed lines. Calculated material is unchanged.
- A Part can contain only one sheet transition, across all Bodies and both
  transition types. Editing that transition and attaching further sheet
  features remain available.
- Repeated solving of an already satisfied trimmed-edge attachment preserves
  the existing point. Changed source geometry is checked again with the same
  residual threshold; calculation precision is not reduced.
- Reference removal, internal-window close and tab close controls use a red
  background and white cross. Toolbar commands provide hover/pressed feedback
  from the system palette. Each control retains its existing action.

Part JSON/INI versions are 66/42; Assembly JSON/INI versions are 46/34.
Branch definitions are stored in the native documents. Start Part, Skeleton
and Assembly templates use the current serializer. Older document versions
are unsupported; no migration or sidecar storage is introduced.

Changed messages are localized in Czech, English, German, French and Russian.
The development entry point remains repository-root `zima-cad.bat`.
Linux and Solid Straighten/Restore remain outside this release.

## Verification status

The focused source suite passed all six tests, including translation coverage,
curve placement, Assembly contracts, transition attachments and transition
commands. The wider regression suite passed 20 of 21 tests. Packaging unit tests
passed (two platform-specific skips); publisher tests passed all 16 cases.

Two issues block release acceptance:

- `zima_cpp_bend_command_tests`: the continuation-side scenario fails during
  initial Bend creation with "Part placement references did not converge during
  regeneration". Investigation observed an external-reference `broken` flag
  changing during the final resolution pass; the cause is not yet established.
- The strengthened surface-placement GUI check detects overlap between the
  third reference row and the Solution branch field after inspection. The
  table's viewport fits its rows, but the following widget overlaps its bounds.

Start templates were regenerated and new-document/template GUI checks passed.
The two failures above remain reproducible; this checkpoint is not a verified
Windows release. No signed 2026092701 package has been accepted or published.
Builds and tests were run serially following reported Windows crashes. Their
cause has not been identified or claimed fixed by these source changes.
