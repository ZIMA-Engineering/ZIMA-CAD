# ZIMA-CAD 2026093006 — Windows

## Changes

- Existing styled toolbars immediately follow Fusion Light/Dark changes without
  restarting. ISO fonts in View, Sketch and Drawing remain unchanged.
- Complete session copies share inactive Undo/Redo states and detach before
  mutation. Current states remain independent, including deferred file relocation.
- Native Part Sketch packets avoid intermediate JSON text; all-prefix history
  fingerprints encode operation data once with exactly unchanged hash values.
  The encoder now compiles in one library source rather than every consumer.
- Completed Part Drawing projections survive unrelated document edits. Assembly
  dependencies retain conservative invalidation. Multi-sheet PDF export reuses
  source metadata within that export; annotation preparation avoids rebuilding
  the same Assembly scene twice.
- Symbol definitions use a bounded exact-source parsing cache. Geometry, text
  and variant evaluation still use current inputs.
- View no longer uploads an unused triangle index buffer. Twenty image hashes
  across rendering modes and transparency match the previous implementation.
- Import/CLI regression fixtures follow current explicit Relations regeneration,
  Part-based library templates and construction-geometry export rules.

Measurements, exact scope and retained candidates are recorded in the
[performance audit](../PERFORMANCE_AUDIT_20260930.md). Reported timings concern
individual operations, not a promised whole-application speedup. No native format
or template change is introduced by this release.

## Verification and limits

All four critical fingerprint, Sketch serialization, session and Drawing reuse
checks passed. The broader 37-check gate initially passed 35: an Assembly GUI
test collided with another test's working-directory lock, and the publication
fixture assumed exclusive ownership after creating a shared-history copy.
The GUI test passed independently; the fixture now separately verifies unshared
allocation retention and copied-history isolation. The final four-test recheck
passed, covering both corrections and the critical transaction/reuse paths.

The broader checks cover native persistence, Workspace publication, relocation,
family/Relations, import/export, PDF/DXF/images, Symbols, measurement, Sketcher,
localization, Fusion/fonts, templates, history deletion and refresh behavior.
There are no new user-visible strings; existing five-language coverage passed.
This is not a claim that the entire repository test suite passed.

Linux build, UI and packaging verification are explicitly deferred to Linux.
General renderer restructuring, nested Assembly dependency narrowing and a
cross-operation measurement index remain candidates requiring more evidence.
