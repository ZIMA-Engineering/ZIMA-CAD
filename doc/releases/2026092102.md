# ZIMA-CAD 2026092102 — Windows

## Changes

- Reference-only Skeleton components, filename-based Tree labels and native
  component file renaming with open-document and Drawing dependency updates.
- Component Properties combines relative source replacement and family variant
  selection. Variant labels avoid duplicated filename prefixes. Assembly mating
  offers visible result faces while retaining original persisted references.
- Faster Assembly reference preview evaluation, corrected plane-offset dimension
  presentation, and explicit Origin visibility during component placement.
- Materials belong to Parts; Assembly material editing is disabled and Assembly
  native data/start templates no longer contain Part material metadata.
- Active Part selection in Assemblies follows visible feature geometry and exact
  occurrence identity, including overlapping holes and threads.
- Large-model camera depth clipping and Sweep boundary seam display fixes.
- Drawing Ctrl multi-selection and Delete/context-menu removal of dimensions,
  axes, construction geometry, text, balloons, labels, traces and views. One Undo
  restores a batch. Captions and section ends snap to view helper rectangles.
- Drawing View Properties can crop normal and already calculated Section views
  with a circle, ellipse or closed spline drawn directly on the canvas. Boundaries
  support grip editing, Cancel, removal, native persistence and Undo. Screen,
  PDF, raster and DXF outputs honor the boundary.

Crop anchors are drawing placements, not associative topology attachments;
changes to a projection may require adjusting its crop. Cropping does not
calculate a new section depth. Dimensions and captions remain independent.

All new interface strings are localized in Czech, English, German, French and
Russian. User configuration and project files are excluded from release input;
tracked factory resources and native templates are included. Linux is not
rebuilt by this Windows release.
