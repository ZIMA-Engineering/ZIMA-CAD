# ZIMA-CAD 2026102004

This Windows candidate combines Drawing contacts, Sketcher editing and external
references, sheet-transition thickness inheritance, saveable incomplete Relations,
localized command guidance, factory-source update repairs and additional reviewed
native fastener models. It also corrects Unicode paths in the affected GUI verification helpers. Shared C++, Qt 6.11.0, OCCT 8.0.0 and the development
`zima-cad.bat` remain the common implementation and launch path.

## Changes

- The public README, roadmap and development TODO now distinguish implemented
  capabilities from queued work. Family Table, multibody Parts, Sketch editing,
  Sweeps, surfaces, sheet states and Undo/Redo are documented as existing tools.
  See [current project status](../PROJECT_STATUS.md).
- Native Part/Assembly temporary writes preserve Unicode paths; Drawing and
  native archives use the same internal Windows long-path I/O spelling when
  needed. Stored document bytes and source/reference identities retain their
  logical paths. See [Unicode I/O](../verification/20261020-native-unicode-io.md).
- Drawing dimensions can select the horizontal and vertical members of an
  end-on hole's axis cross. Angular, linear and chain dimensions retain the
  selected member through regeneration and persistence. Balloons can attach
  to an arbitrary point along a curve. See [axis dimensions](../DRAWING_AXIS_CROSS_DIMENSIONS.md)
  and [balloon contacts](../DRAWING_BALLOON_CURVE_CONTACTS.md).
- Midpoint-centered Sketch profiles and equal-circle layouts retain repeated
  dimension editing and dragging. See [midpoint profiles](../verification/20261020-midpoint-profile-editing.md)
  and [equal circles](../verification/20261020-equal-circle-dimension-edits.md).
- Exact external circular profiles retain native Circle/Arc geometry, corrections
  and Trim parameter identity. Missing or incompatible sources retain the last
  usable geometry and broken dependency, with repair of the same reference.
  See [analytic profiles](../verification/20261020-external-circular-profiles.md).
- External Circle, Arc, Ellipse and Elliptical Arc supports expose a selectable
  center cross. C binds center to center; = separately binds circular radii in
  either selection order. Drawing a circle can snap center and radius without
  creating a redundant rim contact. See [conic centers](../verification/20261020-external-conic-centers.md).
- Sketch Slot creation recovers centre H/V when an unusable segment-only
  inference would otherwise hide it, and displays its H/V marker. Existing
  manual centre H/V, automatic toggles, symmetry and native topology are verified.
  See [Slot alignment](../verification/20261020-slot-center-alignment.md).
- 3D angular dimensions use a horizontal landing behind the arrow with text
  above it, sharing the spatial linear dimension path. Planar Sketch/Drawing
  text retains its circular path. See [angular text](../verification/20261020-angular-text-landing.md).
- Sheet Transitions follow document sheet thickness unless Custom thickness is
  enabled. Existing Properties refresh their stylesheet on a live theme change.
  See [thickness verification](../verification/20261020-transition-thickness.md).
- Removing an Fx dimension no longer makes a document unsaveable because of a
  missing dN relation. Unavailable assignments and their dependent assignments
  are skipped while their authored source remains available to repair; independent
  mass relations still evaluate. See [Relations](../verification/20261020-missing-dimension-relations.md).
- Vladimír shows concise localized command guidance at the upper left, without a
  background. Global settings can disable it with YES/NO. It uses existing command
  status and validation information; it is not an AI assistant. See
  [guidance verification](../verification/20261020-vladimir-command-guidance.md).
- File Manager factory sources resolve against the running immutable version.
  Old settings gain missing factory source IDs while preserving custom paths,
  ordering and disabled states. The updater creates missing destination directories
  and retains rollback. See [source/update checks](../verification/20261020-factory-source-updates.md).
- Title blocks display enlargement ratios correctly, and Sketch editing retains
  preceding visible geometry in the active Body. See [title-block checks](../NATIVE_TITLE_BLOCK_FAMILY.md).
- Six pressed wing nuts M3-M10, thirteen symbolic steel insert lock nuts M3-M36,
  thirteen formed-nose washers M4-M27 and four additional compressed spherical
  washer sizes have native histories, mass, five-language pages, thumbnails and
  framed dimensioned reference Drawings. See [pressed wing nuts](../PRESSED_WING_NUT_LIBRARY.md),
  [insert lock nuts](../INSERT_LOCK_NUT_LIBRARY.md), [formed washers](../FORMED_NOSE_WASHER_LIBRARY.md)
  and [spherical washers](../verification/20261020-shaped-fasteners.md).

## Native data and finite verification

The approved Drawing contract identifies each axis-cross member separately.
Part external-profile blocks persist analytic kind and source parameter mapping;
external centers use a typed derived-point identity on the existing native
reference. Sheet Transition persists its explicit thickness override. All data
remain inside native documents. Six start templates were regenerated and verified
through actual new-document GUI workflows. The affected factory VentilationWindow
was calculated, saved and reopened with the changed implementation. No bulk custom
library or user-project rewrite is performed.

The linked records describe finite native equations, repeated edits/drags,
reference identity, independent geometry/mass checks, Undo/Redo, save/reopen and
actual GUI coverage. Conic centers include 880 enumerated native variants and
twelve mouse scenarios, including actual radius editing, constrained dragging
and reference deletion. Unsupported/redundant variants are checked for atomic
rejection. New UI text covers cs/en/de/fr/ru. Existing library source discrepancies
and manufacturing approximations remain explicit: in particular, the symbolic
insert uses steel density, and the two smallest spherical washer sections select
values within the original stated tolerances.

The user's rough remodeled pressed M10 nut remains private and is not silently
substituted for the accepted factory asset. Cast wing nuts and toothed/fan washers
remain unfinished; two-part locking nuts are excluded. Multiple Up To faces,
surface projection, FEM, mesh modeling, voice interaction and File Manager
directory prototypes remain follow-up work.
