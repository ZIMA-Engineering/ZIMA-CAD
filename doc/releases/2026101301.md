# ZIMA-CAD 2026101301 — calculation demand and File Manager

## Behavior

- Reuse valid calculated history prefixes and exact FORM copy operands. Parallel
  aggregate integration preserves OCCT 8.0.0 precision and ordered reduction.
- Defer expensive aggregate volume/centroid/inertia/total-area analysis during
  ordinary modeling. Explicit Regenerate and Body Properties demand the required
  exact analysis. Newly calculated cheap analytic results retain immediate properties. Unavailable
  derived quantities are marked pending, never reported as zero.
- Prepare sheet material sources only for actual active downstream Unbend/Refold
  consumers. Required authored cuts, FORM data and topology remain intact.
- Ordinary left click on a model face selects its owning feature and Tree row;
  double click opens dimension inspection. Radius dimensions follow this rule.
- Axis endpoint visibility follows axis visibility in Parts and Assemblies.
- File Manager starts in Files by default, keeps the selected view when opening a
  model, and sorts directories by disk names consistently with the Tree.
- Closing native tabs with browser/File Manager tabs remaining keeps a real
  selected utility page. Previews have a separate compact column, minimal margins,
  bounded PNG dimensions and a larger size slider.
- Symbol categories reuse SVG graphics for directory previews. The FORM category
  has a logo/preview and native-geometry thumbnails for both factory definitions.
- Part, Assembly and Skeleton use explicit mm/in start templates. System Setup
  configures all three and changes them together with unit presets. Removed factory
  settings select available unit variants while preserving existing custom files.

## Measurement and compatibility scope

On the unchanged private nine-operation `01.prtz`, two paired fresh-process runs
measure first full calculation at 9.520/9.502 seconds with eager analysis and
7.076/7.684 seconds with final-demand analysis: a 2.131-second (22.4%) reduction
of the paired mean. Repeated calculation remains 0.150–0.218 seconds. Geometry
and reference comparisons have zero differences across 1,220,874 numeric values
per pair. Intermediate analysis state is intentionally different. These are
fixture-specific results; see the [investigation](../performance/20261013-fillet-copy-history.md)
for previous measurements and methodology.

The newer eleven-operation user save was also measured on isolated copies:
14.280/14.412 seconds eager versus 10.795/10.652 seconds final-demand, saving
3.623 seconds (25.3%) on the paired means. Repeated calculation takes
0.176–0.182 seconds; 1,687,230 compared numeric values per pair have zero
geometric/reference differences. User source files were not modified.

Authored geometry, persistent side identity, oldest-face ancestry and protected
shared placement are unchanged. The optional native derived-cache representation
adds an explicit pending analysis state. Native document extensions and version
numbers remain unchanged; completed current caches remain valid. All 20 current repository-owned native factory assets were regenerated and
verified by calculation, save and reopen with the final implementation before
packaging. No legacy geometry fallback,
required sidecar or background worker feature is introduced.

New UI text is translated in cs/en/de/fr/ru. Linux uses the same C++ code but native
build, desktop and package acceptance remain on the Linux host. User projects,
private browser credentials and profile data remain outside the release input.
