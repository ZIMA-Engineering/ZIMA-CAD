# ZIMA-CAD 2026101905

Save and Save As complete physical analysis of existing calculated solids and
publish physical-dependent Relations, including evaluated Part/Assembly Family
rows. Source geometry, native references, Assembly cuts, mates, editing focus and
Undo/Redo remain under their existing ownership rules. Explicit Regenerate still
drives model dimensions and evaluates the full Relations program. Missing density
remains unavailable rather than becoming a verified zero mass.

Sketch Text opens in Part, Assembly and newly owned draft profiles. Each inserted
Sketch symbol has a real native solver point that can be dragged, dimensioned and
constrained. View and Tree menus offer **Explode symbol**, producing editable
native geometry and text as one reversible operation. Exact rational curves,
trimmed/offset results, arc handedness and readable text are preserved. Native
point dragging and angular correction also handle the verified free-degree and
reversed-selection cases. The factory title block and its five independent
language fixtures carry the required persisted insertion-point links. Custom
libraries and embedded user definitions are not rewritten.

Drawing symbol entry accepts continuous edge contacts while retaining original
edge/occurrence identity. Ordinary dimension entry keeps its characteristic-point
and line-selection policy. Verification details and finite GUI/native matrix
limits are in [Save analysis and Sketch symbols](../verification/20261019-save-properties-and-sketch-symbols.md).

This release also includes the reviewed changes prepared in the unpublished
1904 candidate: Assembly-contact Drawing silhouette correction, the regenerated
presentation demo and 942-model mass audit, and 30 native DIN 929/ISO 21670 weld
nuts with five-language pages, thumbnails and reference Drawings. See
[Drawing/library verification](../verification/20261019-drawing-contact-and-library-mass.md)
and [Weld-nut library](../WELD_NUT_LIBRARY.md).

The shared C++ implementation, Qt 6.11.0, OCCT 8.0.0 and the root development
launcher remain. Linux execution and the documented unfinished library families
are not claimed as completed.

Windows publication acceptance will be recorded after the committed-source
candidate, signing, packaged native/GUI checks and public-download checks pass.
