# ZIMA-CAD 2026112403 — Windows

This release repairs FEM condition placement during regeneration and simplifies
the FEM command panel. It also speeds up Body reordering across FEM and keeps
Assembly authoring focused on reference geometry for layouts and mechanisms.

## FEM

- Valid face references remain available when FEM placements are evaluated
  after the last material Body. The reported `50.prtz` now regenerates, meshes
  and solves on an isolated copy. An existing document with this stale invalid
  state needs explicit Regenerate once before generating its mesh.
- Constraint and Force placement accept the Part Origin or source Body Origin
  XY plane as the second reference. Replacement, Cancel, native persistence
  and Undo/Redo use the established placement contract.
- FEM Body properties appear immediately below Selection. Mesh settings,
  Generate mesh, Show mesh, analysis calculation and result display have direct
  buttons. Active display toggles are azure in both dark and light themes.
- Moving a Mirror Body across a FEM row reuses unchanged calculated geometry
  after dependency and fingerprint checks. The measured real-model mouse drag
  took 0.784 s with zero CAD calculations; the previous CLI operation took
  15.82 s. Other material-order changes retain full calculation.

## Assemblies

Point, Axis, Plane, Sketch, 3D Curve, Mirror and Pattern remain available for
reference geometry and future mechanisms. New material Extrusion/Revolution
and conversion of Assembly reference features into material cuts are rejected
in GUI and CLI. Material modeling remains available in Parts. Existing Assembly
cut definitions, editing, Undo/Redo and explicit regeneration are retained.
Assembly Render remains future work.

## Verification
