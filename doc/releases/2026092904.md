# Windows 2026092904

## Scope

- Smooth transition panel/bend junctions on both skins and coplanar panel
  junctions are hidden in normal View, preview and container highlighting,
  including the flat pattern. Original reference geometry remains available.
- Transition manufacturing options add rectangular, full-bend-width end
  notches, adjustable short bend-axis ends and individually selected reliefs
  at the rectangular end of half-round transitions. All options start disabled;
  the real solid and manufacturing DXF carry the resulting geometry.
- Sheet Profile is renamed Bend and accepts only a circular trajectory.
  Adjoining straight material belongs to a separate attached Flat with its own
  editable outline. Sheet from Body keeps separate Flat/Bend/Flat features.
- Czech, English, German, French and Russian labels are reviewed. Shared
  container placement and signed-zero endpoint sides are unchanged.

## Verification and limits

Transition geometry and marking contracts cover folded/developed solids,
volume, native persistence, invalid lengths, inclined ends, reference identity
and exported finite bend axes. Viewer checks cover smooth versus sharp edges.
Native transition GUI and new-document template checks pass; the final flat
pattern screenshot was inspected.

The focused Bend contract covers circular-only validation, angle/radius changes,
endpoint-side and corner behavior, reference attachment, persistence and Undo/Redo.
Sheet state tests cover unfolding/refolding and cuts across an attached Flat.
Sheet from Body backend and GUI tests and five-language translation coverage pass.
The focused Bend GUI check passes creation, all three Sketch editors, Cancel,
reopening, hem mode, inline dimensions, common hover/click attachment of a Flat,
Sketcher return and native save. Its attached-Flat screenshot was inspected.

Broader tests are not all green: the application-tools GUI still expects the
old Modeling Insert menu (previously recorded in BODY_DERIVATION.md); Bend and
sheet-state command suites encounter a stale format-43 box fixture; the Flat
suite reports an empty calculated cache on unchanged OK. These findings are
outside the changed trajectory behavior and remain unresolved. Focused checks
do not establish a full-repository regression pass.

The native transition payload now requires its manufacturing settings. Legacy
Part compatibility is not provided. Elliptical Bend trajectories are not included.
Linux runtime verification belongs on the Linux host.
