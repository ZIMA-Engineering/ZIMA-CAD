# ZIMA-CAD 2026101209 — File Manager and inspection

## Behavior

- File Open keeps the original chooser; File Manager remains a separate action.
- Combined file-name/check/thumbnail cells, movable/resizable columns and attached
  filters, directories first, selected-row group checks and larger footer clearance.
- Bounded 320 × 240 GUI-save PNGs, Files size slider and hover enlargement.
- Delete recycles checked files and folders, with no permanent-delete fallback.
- Clean adopts Parts archive rules, checks inherited protection and preview hashes,
  and moves confirmed archives to the OS recycle bin.
- Read-only STEP/IGES/DXF main tabs reuse the same path and do not create native
  source tabs. DXF stays an independent 2D tool; editing is deferred.
- Read-only working-directory row with the shared File-menu chooser icon (F12),
  directory/source context selection with application-wide updates, and
  Overview/tree edge alignment.
- Smaller Overview margins, tab icons, 34 factory directory metadata files with
  170 localized labels and eight SVG symbol-category logos.
- Ordinary choosers use shared directory labels. Part/Assembly width changes keep
  the model and common picking rays stationary without changing stored camera state.

- Part persistence includes default parameter mirrors before hashing and reads
  Sketches in the explicit persisted index order. This fixes Save Copy setup and
  mixed standalone/owned Sketch roundtrips without changing the native format.
- Packaging rejects private browser profiles, cookies and credential metadata in
  both committed source and runtime inventories, including accidentally tracked data.

- Independent inherited parameter protection and native library parameter support.
  Formats includes a five-language native Name example and explicit metadata mirrors.
- Title-block logos render from embedded SVG bytes in all five variants without
  external image files; redundant loose SVG and unwanted FR backups were recycled.

## Scope and verification

Native formats, geometry contracts, protected placement and OCCT 8.0.0 are unchanged.
All UI additions are reviewed in cs/en/de/fr/ru. Local Windows verification and
committed-source package acceptance are recorded below when completed.
Linux native build, desktop and packaging acceptance remain assigned to the Linux host.
DXF inspection explicitly reports unsupported entities; it is not a guarantee that
a file is manufacturable. Automatic cutting checks and editing remain future work.

## Local Windows verification

- File Manager, foreign-model preview and application integration GUI contracts pass.
  Integration covers the shared chooser action, multi-tab working-directory updates,
  localized native library editing, cache invalidation and saved-only metadata mirrors.
- Native Windows File Manager checks pass, including the real enlarged hover popup;
  Light/Dark/Light captures confirm the Overview/tree content boundaries.
- Five-language catalog coverage, ordinary chooser, native document, workspace,
  document operation, metadata and template command contracts pass.
- Save Copy passes its complete GUI scenario, including paired Part/Drawing copies,
  cancellation, Unicode paths, save/reopen and PDF/JPEG/DXF exports. STEP tab/save
  checks include an Assembly thumbnail and no hidden component tabs.
- All 31 packaging/publisher tests pass, with two Unix-only tests skipped on
  Windows. New cases reject accidentally tracked private browser data during
  source export and reject profile paths in runtime inventories and archives.

These are scoped regressions, not a complete repository test run. Native Linux
execution remains unverified here. Native formats and definition-hash validation
remain unchanged; no legacy compatibility path was added.
