# ZIMA-CAD 2026101504

## Changes

The engineering reference library has 459 logical references in five languages,
with original explanatory schematics before applicable tables and actual
localized previews. Logical references can scroll and print over multiple A4
sheets with repeated headings. Consolidation removes 1,350 artificial fragment
directories; wide tables use sections on the same page. No one-sheet limit is
used to determine navigation. Further grouping is scheduled for user review.

SI/unit, conversion and elementary geometry errors are corrected. Product grades
remain separate from property classes. Published ISO contexts, corrected editions,
withdrawals and unresolved historical numerical data are distinguished. Remaining
chapters include useful engineering fundamentals rather than guessed product
dimensions or material substitutions. Copied/unused image material is retired;
original source evidence remains in Git history and tracked input datasets.

The English [refresh record](../REFERENCE_TABLES_REFRESH.md) describes inventory,
technical scope and finite verification. The [review ledger](../REFERENCE_STANDARDS_REVIEW.md)
lists acquisition priorities, concrete source defects, incomplete numerical
contracts and seven empty categories. These are unofficial informative references,
not official standards or certified design tables. Language selects translation,
not a national standards system.

File Manager directory properties use one-line source fields and display their
copyable directory path above the tabs. Reference HTML follows live native
Light/Dark changes without reload. Ordinary source editing, scrolling, Cancel,
validation and metadata ownership are preserved by the native UI checks.

Shared C++, Qt 6.11.0, OCCT 8.0.0, native formats and protected modeling contracts
remain unchanged. User configuration, CAD models and independently authored
custom library edits are excluded. Native Linux execution is not verified here.

Standardized property-class identifiers retain their full stops in every language
(for example 8.8, never the localized decimal 8,8). The regression checks cover
the actual rendered class examples in both fastener chapters.

A legacy 727-page third-party handbook scan and unreferenced legacy media are
excluded from the distributed factory library. Private originals remain outside
Git and release packages. Existing public source tags are not rewritten.

## Verification and publication

All 38 independent reference-data checks and the native translation contract
pass. Native Windows File Manager verification covers ordinary behavior,
directory properties, three representative chapter overviews, five-language
Light/Dark/Light without reload and Qt reading of all 3,775 factory labels.
Rendering and printing evidence cover every localized logical reference;
all 2,295 localized references / 4,308 physical A4 sheets pass width, row-count,
contrast, missing-asset, selectable-text and printable-bounds checks.
Representative first/continuation pages are visually inspected. Package/publisher
suites pass 31 tests with two Windows platform skips.
