# ZIMA-CAD 2026101903

This build includes the changes and finite verification scope of
[2026101901](2026101901.md) and [2026101902](2026101902.md). Neither preceding
source tag was published as a Windows release.

Title-block generation now preserves authored parameter values, ordering,
localized labels and language-specific value tables. An explicit authoring input
can supply the original metadata while geometry is regenerated from the corrected
fixtures. It is not a runtime dependency. The factory definition retains its
shared Name and all five translations; native verification requires all six
and tests preservation of an additional custom parameter through save/reopen.
The five-language File Manager preflight passed with the repaired definition.

Opening copying is limited to Ctrl+C/Ctrl+V for Opening features. It retains
settings, creates independent identities and asks for new placement. Existing
complete-Origin Opening documents use corrected geometry after explicit
Regenerate; opening a saved document preserves its calculated snapshot. Existing
drawings retain their embedded title block until replaced from the corrected
factory definition.

No native-format change or shared placement-solver change is included. The
metadata repair introduces no product UI text. The five-language localization
review and finite GUI/native verification described in the linked notes apply.
Linux execution and the explicitly listed pending library authoring remain
unverified or unfinished. Windows publication acceptance is recorded only after
clean committed-source packaging and all final gates pass.
