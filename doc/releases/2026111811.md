# ZIMA-CAD 2026111811 Windows release

Status: Windows candidate preparation; publication acceptance is recorded below
only after the corresponding checks pass.

This Windows build incorporates the shared source published for Linux in
[2026111810](2026111810.md), based on upstream commit
`292536c1f`. It includes 3D Curve/Sweep editing and conversion, curve-route Point
placement, independent orientation references, whole-Origin placement, retained
input geometry during datum editing, constrained spline seam tangency, System
Setup corrections and the updated application artwork.

Windows uses Qt 6.11.0 and OCCT 8.0.1. The ordinary local development entry point
remains repository-root `zima-cad.bat`. Personal configuration, browser profiles,
projects and untracked working files are excluded from the release.

This release preparation changes only build identity and documentation. It adds
no application strings, native format changes or modeling algorithm changes.
The synchronized upstream changes include all five translation catalogs; Windows
acceptance will check their existing coverage and validation contracts.

Linux execution of this build is outside the Windows acceptance scope. The
previous Linux release has its own verification record. Finite regression checks
must not be interpreted as exhaustive coverage of every model and interaction.
