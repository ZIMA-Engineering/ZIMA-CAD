# ZIMA-CAD 2026101105

This Windows release includes the outward FORM candidates and native circular
contact editing described in [2026101104](2026101104.md), plus the subsequently
reported FORM-KOULE arc centre/end contact corrections. Build 2026101104 was
prepared and validated as a candidate but was not published before this fix;
its tag remains immutable.

Feasible arc centre/end contacts to an axis or Origin now fit the connected
native point graph, preferring entered radii. Both finite-arc circle/line
intersection branches are considered. Duplicate/impossible relations preserve
the document. R/D and three-point angle changes also fit shared ends without T;
points fixed by both axes reject dragging atomically. See
[the diagnosis and finite verification matrix](../SKETCH_ARC_AXIS_CONTACTS.md).

The focused native matrix covers 3280 cases and the GUI contract 48 scenarios.
Native tests include independent equations, driving/reference and locked/
unlocked R/D/position/angle dimensions, repeated drags, negative/wrapped angles,
immutable external references, native trimming, save/reopen and Undo/Redo.
GUI tests use actual common picking, both input orders, inline R/D edits,
mouse drags and persistence. Existing native contact, C+K, Sketcher, command,
serialization, FORM and five-language suites are dependent regressions.

No user-visible text or document format is changed by this additional fix.
The product still uses one shared Windows/Linux C++ implementation and pinned
OCCT 8.0.0. Native Linux verification remains assigned to the user's later
reboot in [the handoff](../LINUX_RELEASE_HANDOFF.md); Windows checks are not
Linux acceptance. Finite coverage gaps are recorded in the linked matrix.

The library keeps production-style `CornerGusset90.prtz` and
`VentilationWindow.prtz` as controls. Experimental finished/unrounded corners
and the outward Window remain candidates for the user's style decision.
Measured 1 mm kernel medians were 0.829244 s finished corner versus 1.115730 s
retained corner, and 1.348830 s outward Window versus 1.279560 s retained Window.
These are intentionally different styles, not equivalent-output speedups.

Windows publication follows the committed-source build, archive/dependency/CRC/
SHA-256 checks, production-trusted signing, fresh extraction and GUI verification,
remote asset digest acceptance and anonymous public download checks. Temporary
packaging copies may be removed after validation; accepted archives, user
configuration and projects are retained. The root development `zima-cad.bat`
continues launching the current local C++ build.
