# ZIMA-CAD 2026112206

Sketcher now accepts tangency to a source-driven native circle when the arc
endpoint already has a contact to that circle's external reference. The same
endpoint is retained, both contacts remain editable, and removing tangency keeps
the independent contacts.

Clockwise Polyline arcs attach their finishing contact to the clicked end.
The correction also preserves the intended endpoint for midpoint and alignment
constraints.

See the [finite verification matrix](../verification/20261122-arc-contact.md).
Native file formats and user settings are unchanged. Windows verification is
recorded separately from native Linux execution, which remains unverified.
