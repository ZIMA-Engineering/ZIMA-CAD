Status: candidate preparation; not signed or published.

This Linux x86_64 candidate receives the shared source through Windows
2026111703, including the current OCCT collection APIs, support-driven Fillet
and Chamfer repairs, circular Sketch inference and Mirror interaction fixes.
Its source baseline is `b4a4730b736430fa29159313bbec98eced8faae1`.
See the [upstream verification record](../verification/20261117-occt-current-api.md)

OCCT 8.0.1 SDK with the existing Gauss interval patch. The Qt version is the
existing Debian kit, rather than the Windows Qt 6.11.0 kit. No dependency pin,
modeling algorithm, native format or factory asset is changed for this release.
User settings, projects, browser data and custom libraries are excluded from
the committed-source build and preserved in the development checkout.

Packaging tests pass (15 tests, one skipped), and publisher tests pass (16).
Native regression, five-language catalog validation, packaged desktop smoke,
factory asset checks, signing and public download verification remain pending.

network access. Desktop and publication gates must run on the host; neither
offscreen execution nor a successful compilation replaces them.

The release preparation changes only the build identity and this record.
It adds no user-visible text or translation keys. Existing published archives,
including Windows 2026111703 and Linux 2026110404, remain immutable.
