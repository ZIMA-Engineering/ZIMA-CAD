# ZIMA-CAD 2026091901

## Changes

- Mirror and Pattern created inside an active Body are owned history features
  in that Body's Boolean chain. Part-level copies remain independent Bodies;
  Assembly copies remain components. Copies inherit their source operation,
  and overlapping Pattern operands are united before applying Add or Subtract.
- Mirror planes and Pattern directions come exclusively from their own placed
  Origin. Properties displays that Origin immediately. Double-clicking a copy
  exposes source editing dimensions without opening source Properties.
- Active Tree contexts have a green check in their context menu. Part,
  Assembly and Drawing navigation buttons show both an icon and text.
- Drawing Settings manages registered Part/Assembly sources with confirmation
  before removal, dependent-view cleanup and support for an empty source list.
  Source navigation follows the selected source/variant. Title blocks retain
  the source selected when they were inserted.
- Parameters and Family Table have distinct icons, Family Table follows
  Parameters in Tools, and Relations has an icon. Czech start-template
  parameter labels are lowercase without diacritics; standard title expressions
  match those labels. The unused splash resource was removed.
- Dimension expression fields preserve negative zero when confirming input.
  Geometry side identity is a permanent agent-level modeling contract. Bend
  endpoint dimensions preserve signed zero; Assembly plane orientation uses
  the persisted Flip choice independently of signed separation.
- Unchanged complete Body reference packets are retained when another Body
  moves, instead of unnecessarily repacking their reference triangles.

## Verification and limitations

Regression checks cover owned and independent copies, Add/Subtract, overlapping
patterns, native persistence, cold regeneration, later features, source edits,
rejection of invalid sources, Tree ownership and Undo/Redo. Side tests cover
projected dimensions, Bend endpoint zero offsets, Assembly plane orientation
and signed separation, persistence, regeneration and Undo/Redo. A GUI test
confirms negative-zero input survives focus transfer to OK and subsequent edits.

The pre-existing standard title-sketch regression cannot resize its shared
10 mm master dimension to 12 mm. It was reproduced with the unchanged template.
The broader workspace startup contract previously stopped at angular dimension
placement after two segments. These checks are not claimed as passing.
The reported first-open file-list delay has not been reproduced: isolated
first-process probes loaded the repository and Projects directories in under
one second. Its cause remains unresolved.

The broad native run passed 155 of 156 tests; the sole failure is the known
title-sketch case above. All twelve final GUI contracts passed, including the
signed-zero dimension-entry test after repairing focus-out. Archive
tests passed (nine cases, two Linux-only skips), as did all sixteen publisher
input-gate tests. Detailed local evidence is recorded in `SESSION_HANDOFF.md`.

The Windows package must pass committed-source provenance, native dependency,
archive path/collision, CRC/SHA-256, Part calculation, save/reopen, PDF/JPEG and
GUI startup gates before publication. Signed package acceptance is recorded
after those checks complete. No Linux runtime is included in this release.

Development continues through repository-root `zima-cad.bat`.
