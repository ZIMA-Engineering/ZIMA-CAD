# ZIMA-CAD 2026091504

## Windows portable release

This build introduces the signed native updater. Extract the complete ZIP into
a new directory and start `ZIMA-CAD.exe`. Keep this launcher path for future
updates. Existing development checkouts continue to use their root `zima-cad.bat`.
The package includes the native Windows runtime, matching source, documentation,
factory configuration and dependency notices. Python is not required.

## Updates

- Settings > Updates shows the installed, previous and available builds, release
  notes, download size and progress.
- Install and restart downloads and verifies the selected release, then restarts
  after confirming Settings. Save documents and finish model edits first.
- Cancel or closing Settings cancels the pending automatic restart. If a document
  changes during download, restart waits for a new explicit install action.
- Startup checks show a small status-bar link when a new compatible release is
  available. The check can be disabled in Settings; it never installs by itself.
- Successful updates retain current plus previous for rollback. Shared projects
  and user configuration remain outside the versioned runtime directories.
- Failed startup restores the previous selection. Active CAD processes are never
  forcibly terminated by the updater.

## Modeling fixes included

- Holes creates hydraulic drilling channels from Sketch segments with one common
  diameter, cylinder preview, editable diameter/offset annotations and drilling axes.
- Work-plane selection and offset display are consistent across Sketch, Holes,
  Protrusion, Revolve and construction Plane.
- Boolean operations preserve distinct identities for disconnected edge fragments,
  including cuts through shells and multiple solids used by Fillet and Chamfer.
- Fillet/Chamfer annotations retain selection while reaching and dragging purple
  grips; pending placement follows Properties OK/Cancel.
- View display modes have distinct icons; Regenerate leads the common View tools.

Regenerate existing calculated models once to rebuild drilling axes and repaired
edge-fragment references. Native document backward compatibility is not promised.

## Platform scope

This archive contains Windows x64 only. Linux runtime and desktop acceptance will
be completed on Linux. Windows and Linux releases may publish independently.

See [Application updates](../UPDATES.md) and
[Native distribution](../NATIVE_DISTRIBUTION.md) for the installation and publisher
contracts. Immutable published assets consist of the ZIP, `update-manifest.json`
and `update-manifest.sig`.
