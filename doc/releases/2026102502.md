# Windows 2026102502 — Sketch junctions, authored wires and library sources

This release repairs complete authored-wire selection when a modeled feature
also displays an internal construction axis. Axis points controls its passive
endpoints, including vertices shared with a hidden profile. Newly assigned
construction curves default to hidden outside Sketcher; explicit visibility and
existing saved choices remain. Revolution retains its calculated axis.

Symmetric Sketch junctions accept perpendicular legs and vertical native-point
pairs in either order. Repeated dimension edits and dragging use the established
bounded simultaneous fitter; numerical rank no longer invents an independent
constraint from redundant equal-length/symmetry rows.

File Manager's main sources reuse ordinary directory logos and localized
metadata, including custom sources. Home keeps its normal icon/label. Seven
factory roots include SVG icons and all five languages are covered.

Whole-Origin placement publishes the completed scene once while preserving
ordered reference solving. Bounded native-face classification reuse reduces
repeated edge-packet preparation. On the measured construction model, Default
Origin input decreases from 2.85 to 1.61 seconds and an edited feature's OK from
40.86 to 37.79 seconds. These finite timings are not universal speedup promises;
save/reopen remains a separate cost.

See the [verification matrix and measured limits](../verification/20261025-sketch-junction-selection-performance.md).
No native format conversion is introduced. Private project/library files are
excluded from the release. Shared C++, OCCT 8.0.1, Qt 6.11.0 and the normal
`zima-cad.bat` development entry point remain. Native Linux execution is not
verified by this Windows build.
