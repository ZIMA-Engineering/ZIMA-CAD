## Changes

- Repair Sketch Mirror source/axis handling and Escape cancellation.
- Create both persistent C+T contact pairs for common circle tangents atomically.
- Share exact circle tangent branch selection between preview and confirmation,
  including two-circle Segment inference near a quadrant snap.
- Keep double tangents editable after native or external circle changes, including
  free segment ends with persistent interior C contacts.
- Retain C when Tangent is added to an existing segment/circle, and verify
  contact-based trimming and subsequent radius edits.
- Solve successive FORM-EDGE arc radius/diameter, height and width edits and
  point dragging with symmetry and native/read-only external Axis contacts.

  in the limit plane; retain wrong-side crossing rejection.
- Remove automatic path-axis picking points when their Surface result is hidden.
- Close both sides of open Thin profiles in connected order, including zero
  offsets and all three thickness sides.
- Display cyan Surface/Thin/Solid previews on tilted Sketch planes up to Origin
  planes, preserving zero-length contacts and clipping thickness overhang.
- Include the earlier bidirectional Save Copy pairing of models and Drawings.

version changes. Windows and Linux share the same C++ implementation. Localization
reuses existing translations and is reviewed in all five supported languages.

  2D/3D Sweep and helical result modes (84.75 seconds).

  with native and external supports, Undo/Redo, R edit and native reopen, followed

  (69.51 seconds).
- The focused native matrix independently checks 4,608 quadrant/size/orientation
  tangent choices, 640 touching/overlap choices, 288 successive R/D edits/drags,
  and 64 dimensioned arc configurations with 768 edits, 240 actual free drags
  and 320 fully constrained rejected drags. Detailed scope and finite limits are
  in the linked matrix; these counts do not imply every possible Sketch is covered.

The earlier curved-limit test expected an automatic centerline endpoint at the
bounding primary axis's end. These are distinct references: the test now checks
all four actual origin/centroid Start/End descendants at their exact target.
The Surface revolution test counts the four marked surface endpoints separately
from generic automatic axis endpoints; hiding a Surface now removes its generic
axis path points as well.

No new user-visible text is introduced. Existing localized tool instructions and
errors are reused; source coverage, keys, non-empty translations, placeholders
and selected-language controls pass in all five catalogs.

Linux compilation, native tests and GUI acceptance must run on the Linux host;
no Linux verification is claimed. The repository-root development launcher
remains `zima-cad.bat`.
