# Windows 2026112801 - Shared visual documentation

Status: signed Windows release [published on GitHub](https://github.com/ZIMA-Engineering/ZIMA-CAD/releases/tag/ZIMA-CAD-2026112801)
at `2026-11-28T00:36:57Z` from immutable source `210adf731c2d6e4ea0891b24ce6cbb0bb2b5969b`.

The website and offline application now share 145 command guides and 11 overview
guides in Czech, English, German, French and Russian. The right-toolbar inventory
maps each supported command to its guide. Right-click a command and choose
**Show guide** to open the corresponding localized page in a new application
tab. Help and File Manager use the same content.

The responsive guide index supports search and workspace filters. Images offer
fit and actual-size views, keyboard scrolling and a persistent Close control.
The 955 real native images comprise 725 command-button captures, 175 dialog
captures (35 examples in each language) and 55 overview captures. Overview
annotations use the selected language. This does not imply that every command
has a full annotated dialog walkthrough.

The [public website](https://zima-cad.org/) retains the dark/cyan product design,
the project logo, screenshot/video gallery and the requested social links.
All 1,927 public file hashes match the accepted source-derived inventory over
HTTP. Deployment credentials are not part of the source or public artifacts.

Windows packaging now obtains factory configuration, resources and public web
content from a fresh committed-source export, preventing staging tests from
adding disposable profiles to the package. Normal development still uses the
root `zima-cad.bat`. The local GUI and CLI were rebuilt from the release source;
their modified-source flag reflects unrelated local changes. The portable
release was built from the clean tagged source and reports unmodified source.

## Boundaries

This is a Windows release; native Linux execution was not verified for this
build. Modeling algorithms, placement contracts and native formats are unchanged.
The [preceding release's documented modeling limits](2026112701.md) remain.
The tests are finite regression evidence, not exhaustive algorithm certification.

The user also agreed a [shared 3D controller design](../3D_CONTROLLER_INTEGRATION.md).
It is a separate follow-up: this release does not implement SpacePilot,
SpaceMouse or NaviGo camera/button support. USB enumeration of the connected
SpacePilot is not a navigation or button test.
