# Windows 2026112601 — Sketch and Drawing interactions

Status: signed Windows release published and independently verified. See the
[publication evidence](../verification/20261126-windows-2601-publication.json).

The interaction changes in this version are:

- Create a native Arc through start, end and through points, including major
  arcs. The through point retains the ordinary C contact and solver behavior.
- Show and snap the image insertion anchor, using the existing nine alignment
  positions and rotation. Insertion remains part of the active Sketch draft.
- Show the authored source Sketch while editing a Wrap and entering its targets.
- Display cylindrical placement angles from the selected plane, with the first
  witness in that plane. Preserve the canonical stored value and existing pose.
- Present whole/default Origin references in XY, XZ, YZ order in Parts and
  Assemblies, preserving the complete references and their geometric roles.
- Accept straight cylindrical silhouette edges for Drawing angular dimensions.
  Place consecutive linear dimensions directly with a click; OK ends the command.
- Offer Automatic Drawing dimensions with manual type override. Chain dimensions
  remain explicit. Dimension context actions now have the shared icons.
- Keep File Manager action buttons compact and give the thumbnail-size slider
  the extra width. New Folder precedes Copy, Move and Delete.

This release also includes the preceding committed Sketch outline manipulation
and CAM profile-milling work. Segment outlines translate or pivot according to
their constraints; Circle outlines change size under the ordinary solver.
Three-axis CAM supports native-profile pockets and inside/outside contours,
including islands, exact linear/circular paths and material simulation.
Controller-specific postprocessors, turning and rotary axes remain later work.

See the finite verification records for
[Sketch, Drawing and placement](../verification/20261126-sketch-drawing-placement.md),
[outline manipulation](../verification/20261126-sketch-contour-drag.md), and
[CAM profile milling](../verification/20261126-cam-profile-milling.md).
The shared implementation is C++; native Linux execution is unverified here.
This interaction batch does not change native document envelopes. The earlier
approved CAM work uses nested CAM schema 3. No user originals are overwritten.

The normal Windows development entry remains `zima-cad.bat`. Portable releases
carry their own native dependencies and installation-root launcher.
