# ZIMA-CAD 2026092902

Status: Windows release signed, published and verified.

## Changes

- Both sheet transitions display their second axis endpoint with the standard
  point color. Their end plane has a constant-screen-size border, an individual
  Tree entry and the persisted oriented normal used by reference selection.
- Normal View, Standard Views and Drawing insertion share standard view names
  and document-owned saved views. Normal View uses independent reference eyes
  and per-item remove buttons. Pending saved-view changes commit on OK and are
  discarded on Cancel. Drawings store the selected orientation in their own view.
- Model DXF separates cutting geometry (CUT), finite flat-pattern bend axes
  (BEND, cyan) and text contours for marking (MARK, green). Bend axes are clipped
  against actual flat material, including holes. Generic construction axes are
  omitted. Drawing DXF retains its independent configured-view export behavior.
- Packaged factory configuration uses `WorkingDirectory=~`, resolved to the
  current user's home on Windows or Linux. Shared user overrides take precedence;
  packaging does not rewrite the developer's working configuration.
- User-visible changes are localized in Czech, English, German, French and Russian.

See [model DXF](../MODEL_DXF.md), [saved views](../NAMED_VIEW_COMMANDS.md),
[transition references](../SHEET_TRANSITION_PREVIEW.md) and
[distribution settings](../NATIVE_DISTRIBUTION.md).

## Verification

Focused source checks passed for named-view commands and Part/Assembly GUI,
Drawing source/named-view selection and save/reopen, Drawing DXF, model DXF,
sheet exchange, transition commands and GUI, point-marker framebuffer colors,
viewer selection, portable settings and five-language coverage. The clipping
fixture independently checks that a 100 mm bend axis crossing a 30 mm slot
becomes two segments totaling 70 mm. Packaging unit tests passed eight cases,
with two Linux-only cases skipped on Windows.

The broader UI contract failed on retained hover/press state after a missed
Leave/release. The broader console GUI contract failed on Template changing
an active Drawing tool; its preceding named-view checks passed. These failures
remain unresolved; this release does not claim a passing full suite. Linux
runtime validation and publication remain work for the Linux host.

No native document format or shared container-placement contract is changed.
The development entry point remains `zima-cad.bat`.

Transition end-plane borders use the same base size and camera scaling as
container Origin planes. This changes display/picking only; persisted plane
positions, normals and reference identities remain unchanged.
