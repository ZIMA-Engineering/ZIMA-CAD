# Windows 2026102501 — Origin coordinates and Sketch interaction

This release aligns signed coordinate dimensions with the named axes of their
Feature Origin through View, Properties, CLI, Relations and Family Table while
preserving canonical geometry and authored reference choices. Sketch numeric
contract 36 requires explicitly converted native documents and libraries; no
older-format reader is added. All 1,185 factory assets and 36 affected regression
fixtures have been converted and verified with the changed native implementation.

H/V input and markers follow perpendicular Sketch views and remain available
while navigating obliquely. Native points and curves precede helper axes in
ordinary hover. Axis points also control construction-curve endpoint markers,
while their snapping and dragging remain available. Shared profile vertices
retain their normal markers.

Whole-feature selection and Mirror/Pattern use the complete authored preview.
Mirror completion restores Insert Here immediately after OK, Cancel and Undo.
Shell generated names no longer depend on face traversal order. Unchanged zero
coordinate Properties preserve the selected contact side.

See [the finite acceptance matrix](../verification/20261025-coordinate-sketch-selection.md)
and [the coordinate contract](../COORDINATE_FRAME_CORRECTION.md). Shared C++,
OCCT 8.0.1, Qt 6.11.0 and `zima-cad.bat` remain in use. Native Linux execution and
the previously documented broad baseline failures remain explicit gaps.
