# Windows 2026092905

## Scope

Fix Unbend of closely separated sheet material such as the reported `01.prtz`.
A coarse reconstruction that changes the solid count is retried with finer
precision, with at most three retries. Validity, material and connectivity
checks remain enforced. The document's precision settings are not changed.

## Verification and limits

Focused sheet-state geometry, transition commands, manufacturing marks and
arc-only Bend contracts pass. The new regression compares default Unbend with
an independent finer calculation at three Bend angles, then checks Bend Back
volume and references. Copies of the reported document pass Unbend, native
save/reopen and Bend Back with the original 0.05 mm setting.

Five-language translation coverage passes. No new user-visible strings or
native-format changes are introduced. Shared placement is not modified.
The broader pre-existing failures recorded in [2026092904](2026092904.md)
remain outside this fix; this is not a full-suite or Linux validation claim.
