# ZIMA-CAD 2026091606

## Changes

- Bend placement follows the selected straight outer edge and narrow attachment
  face. The start profile lies in that face, with material directed into it.
  This also supports attachment to the End face of another Bend.
- In the ordered Edge, containing Plane, Point sequence, the third point locates
  the origin along the edge by perpendicular projection. An intersecting plane
  can locate it instead. Point-first placement retains direct coincidence.
- Prepared Bend profiles have endpoint C constraints and editable origin or
  endpoint-difference dimensions. New GUI placement directs the start segment
  toward the other end of the selected edge, including from the opposite corner.
- Circular Bends with matching sections retain analytic cylinder surfaces. This
  fixes slow volume calculation for rotated 180-degree bends. Calculated Start/End
  rims and vertices provide persistent references for subsequent features.
- Container placement consistently preserves FRONT/TOP and uses the agreed
  0.01-degree threshold for nearly parallel directions. Returning from Sketcher
  no longer rotates the work plane or releases RY in Sketch, Holes, Flat or Bend.
- Clicking an already selected Body Origin in the Tree fills placement references,
  including in Flat properties.

The development entry point remains repository-root `zima-cad.bat`.
Portable installations start through their root `ZIMA-CAD.exe`.

## Compatibility and known limitations

- Native formats are unchanged from 2026091605 (Part INI 30 / JSON 54).
  Reference order and identities carry the new placement meaning.
- The previously documented conflict between an authored Bend trajectory endpoint
  and its moved end profile during Unbend remains unresolved. Use the end-profile
  endpoint for downstream attachment. See [Sheet Metal](../SHEET_METAL.md).
- The full repository suite was not run. The previously recorded obsolete native
  fixture and Drawing BOM assertion gaps are not claimed as repaired here.
- Linux packaging and acceptance remain assigned to the Linux host.
