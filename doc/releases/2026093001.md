# Linux 2026093001 — interactive drawing dimensions

This release prepares measurement candidates when a Drawing sheet is loaded,
regenerated or confirmed through View Properties. Unchanged views reuse their
prepared curves and spatial index. Picking preserves exact contacts, source
identities, visibility and candidate ordering without recalculating OCCT geometry.

Automatic two-point dimension creation accepts an exact second contact on a
straight edge after a point-like first reference. Moving above/below the point
rectangle selects horizontal distance; moving beside it selects vertical
distance; returning inside restores direct distance. Explicit Segment input and
existing saved dimensions retain their meaning.

Placement updates existing property controls rather than reconstructing the
form on every mouse movement. The user confirmed faster interaction and correct
horizontal/vertical placement in `Projects/11.drwz`.

## Source verification

Picking and dependent Drawing contracts passed, including dimensions, view
controls, breaks/details, balloons, symbols, threads and localization coverage.
The broader dimension-layout contract passed with an XCB/OpenGL context.
No user-visible strings, native document formats or shared container-placement
contracts changed.

This is focused verification, not a full-suite claim. Existing template and
sheet-state fixture limitations recorded for [2026092906](2026092906.md) are not
claimed resolved by these drawing changes.

The representative drawing benchmark compared every sampled ordered contact:
mean picking fell from approximately 5.6 ms to 0.5 ms, with 29.4 ms preparation
for four views. A separate offscreen single-view placement probe fell from
12.0–12.9 ms to 9.1–9.2 ms per mouse event including processing and painting.
These are picking and isolated placement measurements, not full-sheet GPU
frame timings. See [Drawing performance](../DRAWING_PERFORMANCE.md).

Packaging tests passed (nine passes, one platform skip); all sixteen publisher
input tests and all 23 isolated updater lifecycle tests passed.
