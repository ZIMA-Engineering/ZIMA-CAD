# ZIMA-CAD 2026112102

Adds the first FEM Constraint, Force and Pressure authoring commands, one shared
Properties editor, Point/Curve/Surface regions, ordinary container placement,
pickable symbols and labels, native persistence and Undo/Redo. FEM Bodies are
numbered automatically. Meshing and solving are not included in this checkpoint.

Projection uses the nearest selected face along either side of the Sketch normal
without separate direction controls. It gains its own icon, clearer reference
tables, white/dark source and result previews and complete azure hover. Sketch,
3D Curve and Projection line weight remains consistent after confirmation.

Verification includes inclined projection onto B-spline and multiple bounded
faces, dependent geometry operations, condition transactions, actual GUI picking,
five languages, two themes and three display scales. See the
[finite acceptance report](../verification/20261121-fem-conditions.md) for exact
coverage, native format verification and remaining FEM/Linux work.
