# Linux preview build 2026100908

This signed Linux x86-64 preview contains the shared C++ source from Windows
2026100906, built on Debian 13.6 with GCC 14.2, Qt 6.8.2 and the pinned OCCT
8.0.0 SDK. The native GUI, CLI, updater and complete committed source are included.
The release is a GitHub prerelease and is excluded from automatic stable updates.
It does not replace the latest stable Windows release.

Source tag `ZIMA-CAD-2026100908` identifies commit
`6767df8e32c14212bde1e4a8a1905d52b95978d4`. The only product-data change beyond
the build identity is refreshed calculated data in `VentilationWindow.prtz`.
The Linux native loader rejected its previously committed cache fingerprints.
An explicit native Regenerate produced the replacement; no fingerprint check,
modeling tolerance, topology identity, placement code or kernel pin was changed.
Independent comparison found valid old/new BReps, zero two-way surface difference
and the same 440 persisted owner/key/occurrence references. A cached external
point changed by approximately 7e-15 mm. This establishes this finite library
case, not general cross-platform floating-point equivalence. Windows verification
of the refreshed library data remains outstanding.

## Accepted checks

- Both local native compilation and committed-source portable compilation pass.
- Dependency closure, archive path/collision checks, CRC, SHA-256, fresh extraction,
  packaged GUI/CLI smoke, model regeneration and PDF/JPEG export pass.
- Independent Ed25519 verification against the existing trusted publisher key
  passes. The extracted production updater reports trusted build 2026100908.
- Package regressions: nine pass and one platform skip. Publisher regressions:
  16 pass. Isolated updater/desktop regressions: 23 pass.
- All five translation catalogs pass key/placeholder validation and the native
  translation coverage contract. No new user-visible text was introduced.
- After refreshing the shipped Form cache and preparing the required diagnostic
  directory, 61 of the 63 selected native suites pass. This includes failed-feature
  persistence, Form/Shell/Fillet/Thicken, the corner roundtrip and workspace copies,
  four thickness pairs and five tight-bend cases, ordinary copy batching,
  Sketch Mirror/tangent, Sweep and extrusion-limit coverage.
- Packaged KDE/Wayland GUI checks pass for templates, new-document options,
  owned-Sketch recovery, closed 2D Sweep, profile frames, Sketch return and external
  constraints, Save Copy, retained and derived copies, Pattern dimensions,
  Offset, Mirror, placed-Sketch references, endpoint priority, Slot, capsule
  dimension edits, System Setup and corner Form. These are finite scenario checks,
  not exhaustive Sketcher or desktop acceptance. GNOME was not tested.

## Remaining failures and acceptance limits

This preview has not passed the full Linux feature acceptance matrix:

- `zima_cpp_exact_spline_contract_tests`: curved Extrusion reports that its
  profile requires at least two curves. A fresh build of the previous Linux
  2026100602 source with the same SDK reproduces the failure.
- Boolean Form contract: expected fixed volume 18497.255434 mm3, Linux result
  18497.263466 mm3. Preceding validity, ancestry and independent property checks
  pass; the fixed golden-value assertion remains failing. Its tolerance was
  not relaxed.
- Ordinary Form GUI: replacing the support face retains the previous click
  position in the regression scenario. Shared placement code remains untouched.
- Form Sweep GUI: the dimension-edit test document's calculated-history cache
  is rejected. This fixture failure is separate from the repaired shipped library.
- Common Tangent GUI: the radius inline editor is missing in the test scenario.
- FORM-EDGE hover GUI: the scenario reports a missing created curve plane.
- Theme/font GUI: the theme assertion reports that it still follows the system.
  Earlier palette/style checks pass, but the complete theme matrix is not accepted.

No Windows or GNOME acceptance is claimed. Personal settings and projects were
preserved; they are excluded from the committed-source archive.
