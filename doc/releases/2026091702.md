# ZIMA-CAD 2026091702

## Changes

- Dimensions carry an explicit measurement direction, including zero-valued Bend
  dimensions and transformed Assembly occurrences. Ordinary zero dimensions keep
  their existing visibility policy. See [Sheet Metal](../SHEET_METAL.md).
- Assemblies persist native source references and their own operation results,
  rather than duplicate ordinary source geometry. Open unsaved source documents
  are authoritative. Missing sources can be located through **Source file…** in
  the component context menu. See [geometry sharing](../ASSEMBLY_GEOMETRY_SHARING.md).
- STEP/IGES Assembly import creates native Part/subassembly files directly in the
  working directory and leaves the current tab active without opening source tabs.
  See [import/export](../STEP_IMPORT_EXPORT.md).
- Assembly Origins follow the active occurrence and its immediate children,
  with explicit reference-selection visibility handled per occurrence.
- Concurrent application instances reserve unique numbers, working directories
  and open files. Closing documents releases reservations; abandoned process locks
  recover after a crash. See [multiple instances](../MULTIPLE_INSTANCES.md).
- Material, Parameters and Relations use numbered rows and first-cell actions.
  Family Table uses a header Open icon, first-cell actions and editable names.
  Renaming an open family instance updates its owner table and vice versa without
  renaming the native family file. See [Family Table](../FAMILY_TABLE.md).

The development launcher remains `zima-cad.bat`. Portable installations use their
root `ZIMA-CAD.exe`. User configuration and working files are excluded from release
source changes.

## Compatibility and verification

Part format is INI 31 / JSON 55; Assembly format is INI 25 / payload 37. Both
tracked start templates are updated. Legacy native documents are unsupported.
Native dependencies must accompany Assemblies when projects are moved or shared;
there are no required geometry sidecars.

Reference-only storage passed 33 focused console contracts, followed by component
properties and Assembly refresh GUI checks. Instance isolation passed real-process
tests and the two affected GUI contracts. The final table/rename verification
passed six distinct contracts: shared UI, entry tables, file rename, family core,
Family Table GUI and bidirectional family Rename GUI. Rendered tables were visually
inspected. Bend attachment, edge treatment and Sketch dimension entry GUI checks
also passed during the broader audit.

The earlier 190-test audit was not fully green. Four failures remain documented:
bounded construction Axis, a shared title-block dimension, Universal Dimension
two-segment interaction, and the comprehensive console GUI's invalid LENGTH family
fixture. This release does not claim those failures are repaired. The previously
documented Bend trajectory-endpoint/Unbend limitation also remains open.

Evidence is retained locally in `build/assembly-storage-*`,
`build/assembly-reference-*`, `build/instance-isolation-*` and
`build/document-table-layout-*`. Release acceptance is recorded separately after
the committed-source candidate and signed archive pass packaging gates.

Linux packaging is outside this Windows release; build 2026091701 retains its
separate Linux acceptance record.
