# ZIMA-CAD 2026091801

## Changes

- Sheet Profile and Sheet Revolution extend sheet bodies from persisted sheet
  boundaries. Their edge attachment derives the placement frame and material
  thickness from the parent sheet while ordinary free placement remains
  available. Sheet Profile also supports the tangent continuation segment.
- Sheet Cut supports the ordinary projected cut and a clearance mode that lets
  the entered profile pass through curved sheet material. Both modes provide
  lightweight cyan wire previews before confirmation. The configurable sheet
  calculation tolerance defaults to 0.05 mm.
- Unbend and Bend Back are independent history operations. They can process all
  eligible sheet features or a selected set, preserve original feature identity,
  keep later modeling operations in history order, and expose manufacturing bend
  axes in the unfolded state. The state operations themselves are presentation
  transparent so the original feature remains selectable and editable.
- Twisted Sheet creates a manufacturable transition with tangent end regions,
  inherited thickness on edge attachment, and an allowance correction used by
  its unfolded length. Sheet Cut, Unbend, and Bend Back understand the persisted
  twisted-sheet definition.
- Sheet edge attachment was repaired for Flat and Twisted Sheet. Reference rows,
  Origin placement, cyan previews, and edit rollback follow the shared container
  dialog contract without changing the common placement implementation.
- Family Table uses stable feature identities across sheet states and Drawing
  variants. Drawing sheets keep their own native or family variant selection;
  title blocks and balloons consume that sheet selection while inserted views
  remain independently configurable.
- Family Table is available from Part and Assembly root context menus and beside
  Parameters above the View. Sheet toolbar icons and separators were refreshed,
  and the unused Piping application entry was removed.
- Saving an unchanged native document performs no file write. Changed documents
  retain the existing version-backup behavior.

## Native formats and verification

Native formats are Part INI 40 / JSON 64, Assembly INI 33 / JSON 45, and Drawing
INI 18 / JSON 10. The tracked Part and Assembly start templates are updated.
Earlier native formats are unsupported; all required sheet definitions, topology,
references, and state data remain in the native documents.

The focused sheet-metal verification passed all 14 selected suites twice. It
covers sheet profile and revolution attachment, sheet cuts on flat and curved
material, independent Unbend/Bend Back history, bend axes, Family Table state,
Twisted Sheet persistence and attachment, container reference rows, cyan preview
frames, and the repaired start templates. The complete C++/OCCT contract set and
the native documentation/template checks also passed before release packaging.
The committed-source candidate and signed archive receive their own dependency,
path, collision, CRC, SHA-256, Part calculation, save/reopen, PDF/JPEG, and GUI
startup checks during the release pipeline.

Development continues through repository-root `zima-cad.bat`. The Windows
portable archive contains its own native dependencies and matching committed
source. Publisher signing uses the authenticated Ed25519 update protocol; Linux
remains a separate platform release.
