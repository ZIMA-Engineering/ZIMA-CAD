# ZIMA-CAD 2026112003 — Windows candidate

The reported rectangle/circle/slot Loft now supports Thin output and Shell.
When the ordinary offset algorithm fails, both operations share an exact
normal-offset surface fallback with native topology ancestry. Thin supports
both material sides and symmetric thickness. Shell supports closed cavities
and either or both opened planar ends on the verified mixed Loft.

The repair preserves successful existing calculation paths, the shared
placement contract, source Sketch definitions and the current native format.
It includes the General Surface reference/context, Twist attachment/axes and
sheet preview/dimension repairs from [2026112002](2026112002.md). Verification
helpers now preserve Unicode paths when loading localization and fixture data.

The [acceptance record](../verification/20261120-repair-acceptance-followup.md)
records signed thickness checks, independent wall volume, B-Rep validity and
self-interference, placed Shells, native save/reopen, cold regeneration,
Undo/Redo, no-op operation counts and dependent face/edge references. It also
separates the private reproducer from permanent independent fixtures.

This finite matrix does not establish arbitrary guide networks, non-planar
Loft caps, multiple Bezier patches per side or arbitrary side-wall openings.
The intermittent disappearance report remains unreproduced. Linux execution
remains a separate host gate; both platforms use the same C++ implementation
and OCCT 8.0.1 dependency pin. User projects and the normal `zima-cad.bat`
entry point remain unchanged.
