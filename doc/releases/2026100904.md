# Windows build 2026100904

## Scope

Adds exact IGES export to File > Export and the shared console/CLI command
`export.iges`, accepting `.igs` and `.iges`. Visible Part Bodies and current
Assembly results are exported in millimetres, with composed placements and
final Assembly cuts. Product structure/history are not preserved in IGES.
Export uses the existing captured snapshot and atomic publication mechanism;
it does not regenerate, change the model or create Undo history.

The English user manual and Form authoring guide explain planar pockets:
closed FORM_CUT replacement outline, continuous FORM wall/bottom, optional
empty FORM_FLAT and independent symbol. Existing planar/corner algorithms
remain in production. Test-only solid/surface experiments are documented with
their failures and limits; they are not enabled as product behavior.

All new UI strings are translated into cs/en/de/fr/ru. Six focused suites pass
in 106.14 s: export, import, localization, real IGES GUI, existing planar Form
and existing corner roundtrip/copy. The actual 20-FORM native CLI export and
IGES reimport also pass. The broad console GUI suite timed out; its repeat
passed the IGES section before a later overall timeout. The separate IGES
GUI suite passes. Arbitrary new pocket definitions are not accepted by these
checks. No native schema, template, protected placement or dependency changes.
Windows/Linux share C++ and OCCT 8.0.0; Linux verification remains separate.
