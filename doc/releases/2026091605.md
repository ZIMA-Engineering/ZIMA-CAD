# ZIMA-CAD 2026091605

## Changes

- Sheet Metal adds **Flat (Tabule)**: an owned closed Sketch extruded by the
  document or overridden thickness, on either side or symmetrically. Circular
  and elliptical openings publish their axes. Shared extrusion supports mixed
  elliptic loops and preserves inner loops when reversing direction.
- Bend owns three prepared Sketches: start profile, circular trajectory and end
  profile. Endpoint difference dimensions control width transitions. Radius can
  follow thickness; matching profiles support zero inner radius. Bend/Unbend is
  also accessible beside the feature's dimensions in the View. Unbend uses the
  effective K factor. All three Sketch buttons share the green style.
- Closing Sheet Metal Properties immediately restores the application selector,
  including switching back to Modeling.
- Container references accept native Sketch points/curves and finite original
  solid edges. Curves constrain position on the curve; point-plus-curve placement
  can orient FRONT to its tangent. A third straight reference controls remaining
  rotation. Tree reference diagnostics include Sketch geometry.
- Sketcher fixes anchored-arc angle/radius editing, circular-arc completion after
  reversing direction, and elliptic-arc direction switching. Auxiliary dashed
  lines and construction dash-dot lines retain their pattern on hover/selection.
  Offered points and endpoint Coincident snaps take precedence over curves and
  new-segment midpoint snaps.
- Dimension value clearance preserves the dimension line in Sketcher, model View
  and Drawings.

See [Sheet Metal](../SHEET_METAL.md), [Sketcher](../SKETCHER.md),
[curve placement](../SKETCH_CURVE_PLACEMENT_DESIGN.md) and
[Drawing dimensions](../DRAWING_DIMENSIONS_DESIGN.md).
The development entry point remains repository-root `zima-cad.bat`.

## Compatibility and known limitations

- Native Part INI format is **30**, with JSON payload **54**. Earlier Part formats
  are intentionally unsupported; the committed start Part template is updated.
- A Flat attached to both the Bend end profile and the authored trajectory's end
  point loses a consistent placement on Unbend. Use the end-profile endpoint for
  that attachment. This was reproduced in `Projects/03.prtz`; the original file
  was preserved. Trajectory-reference behavior is deferred to the next session.
- The monolithic `zima_cpp_contract_tests` stops on an obsolete format-26 fixture.
  A prior broad workspace-startup run also reported a Drawing BOM quantity
  assertion after completing its placement checks. These are recorded test gaps;
  this release does not claim that the entire repository suite passes.
- Linux runtime completion and acceptance remain assigned to the Linux host.
