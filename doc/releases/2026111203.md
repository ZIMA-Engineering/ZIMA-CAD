# Windows 2026111203 — Exact Fillet junction trimming

Status: signed Windows release published and accepted. Native Linux acceptance
remains a separate host gate.

This release corrects the common node where two selected Fillet routes end.
The previous implementation inserted a third synthetic connector at this node.
That connector could remain visible as a vertical tongue or chamfer even though
the user had selected only two routes. Two-route nodes now preserve the authored
material domains: separated routes keep their exact circular ends, and routes
whose actual cutter cylinders overlap are trimmed by their true simultaneous
Boolean intersection. No unselected third solid is invented. The established
three-route spherical connector remains unchanged.

The lightweight azure preview follows the same geometric decision for straight
plane/plane terminal routes. It analytically samples the two terminal cylinders,
clips the route rails at their common intersection and removes the internal end
arcs. When the cylinders do not overlap, both exact circular terminal arcs
remain visible. Curved-support previews retain the existing mesh-section path.
The preview remains calculation-free and does not invoke OCCT during interaction.

Focused verification covers separated two-route ends, true overlapping-cylinder
intersection, three-route behavior, direct batch treatment, solid-state support,
command/query contracts and all related GUI preview variants. An isolated copy
of the reported `RADIUS.prtz` recalculates all five boundaries without an error
and reads back exactly. `RADIUS2.prtz` was not present in the supplied project
directory during acceptance, so this release does not claim direct verification
of that second user document.

No user-visible text changes, so the Czech, English, German, French and Russian
catalogs require no new entries. The protected shared placement contract, native
document format, calculation tolerances, Qt 6.11.0 and OCCT 8.0.1 remain
unchanged. The implementation is shared C++; native Linux compilation and
execution were not run on the Windows host.
