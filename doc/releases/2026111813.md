# ZIMA-CAD 2026111813 Windows release

Status: withheld after additional user findings. The candidate and its signed
archive must not be published. Build 2026111901 incorporates the follow-up;
its publication acceptance is recorded separately.

The first picked Loft support now uses the same local XY work-plane preparation
as an ordinary Sketch feature. In an owned Loft Sketch, View-plane entry can
replace the automatically inherited parent-Origin attachment after a confirmed
plane or planar-face pick. Arming or cancelling entry preserves the attachment.

Whole 3D Curve references no longer falsely mark a valid Point red in the Part
Tree. Reference diagnostics use the existing route resolver and retain errors
for genuinely missing routes. In placement picking, a whole route is offered
immediately after its first segment, once per exact occurrence.

Double-clicking a Point on a route displays its stored distance/fraction beside
the Point; double-clicking that label edits the same parameter as Properties.
Double-clicking a 3D Curve exposes its owned Point placement dimensions, with
successive edits retaining the Curve inspector and dependent Point positions.

3D Curve/Sweep and Helical Curve/Sweep conversion retain whole-route Point
references in both directions. The Sweep axis offers its authored route for new
Point reference entry. Returning a Sweep to a standalone Curve also preserves the
construction order required for native reopening. See the
[inspection and conversion verification](../verification/20261118-route-point-inspection-conversion.md).

This version includes the symmetric Equal Length and configured working-directory
repairs from the withheld 1812 candidate. Shared Windows/Linux C++, Qt 6.11.0,
OCCT 8.0.1 and native formats are unchanged. No new UI text is introduced.
See the [finite follow-up verification](../verification/20261118-loft-plane-point-route.md).
