# ZIMA-CAD 2026092201 — Windows

## Changes

- Drawing views are protected from ordinary single/multiple-selection Delete.
  Tree selection highlights drawing entities and supports context actions and
  Ctrl selection. View captions use white 5 mm lettering.
- The view-break editor uses reference-style rows, interactive position entry
  and a default 2 mm gap.
- Thread drawings suppress stray axial strokes and offer control of lead-in
  chamfer visibility. Thread geometry can supply manual dimensions in hidden
  views and sections. Show/Erase restores projected source dimensions.
- A global setting selects inline or stacked upper/lower dimension tolerances
  in drawings and model views. Wide dimension text can remain between arrows;
  text width no longer overrides the user's chosen position.
- View cropping draws thin boundaries only over projected material. Per-section
  local hatch regions also draw their boundaries and leave ordinary edges intact.
- Insert Detail has its own icon and supports circular, elliptical and spline
  regions, names, scale and visibility controls. Source markers have yellow thin
  continuous boundaries/leaders/underlines and white 5 mm letters. Labels can be
  dragged independently, cancelled with Esc, undone/redone and saved.
- Title-block resources use uppercase English identifiers and the contact address
  `kontakt@zima-engineering.cz`.
- About now describes ZIMA-CAD as open-source parametric 3D CAD based on OCCT and
  written in C++, without the longer introductory paragraph. All five supported
  languages are updated; author, version and contact information remain.

Calculation-precision experiments are documented in
[the benchmark report](../benchmarks/CALCULATION_PRECISION_20260922.md).
They do not justify changing the default calculation precision; decimal display
formatting is separate from calculation precision.

## Verification and package status

Focused drawing, dimension, persistence, interaction and localization checks
passed during development. Local hatch boundaries were checked on screen and
for print, including material/view clipping and section ownership. Wide-label
placement passed dimension-layout and drawing interaction checks.

Windows package acceptance is pending. This record does not yet claim a signed
or published archive, a full repository-wide test pass, or Linux verification.
The development entry point remains repository-root `zima-cad.bat`.
