# ZIMA-CAD 2026091704

## Changes

- Flat can attach to a straight outer Bend boundary. Its placement and thickness
  follow the source Bend, with associative external endpoints available to the
  Sketcher. Ordinary free placement remains available.
- Sketcher endpoint, C (incidence), and M (midpoint) inference supports external
  points, including the inherited Flat attachment endpoints. Source identities,
  selection filters, and disabled inference settings are respected.
- Folded/unfolded sheet states preserve the box's cross-branch design references,
  Sketch identities, and constraints. Changing a source dimension still updates
  the dependent profiles.
- Earlier valid history edits commit even when a later external-reference
  constraint fails. The failed feature loses its geometry and is marked red with
  a diagnostic. Its definition and constraints remain repairable; restoring the
  upstream parameter restores the feature. Failed states persist through native
  save/reopen and Undo/Redo. Reusing compacted earlier history now restores its
  original reference data, without exposing references from later features.
- Bend Properties adds **Hem**, selecting 180 degrees and zero inner radius.
  The outer radius equals the material thickness. Disabling the preset restores
  the pending ordinary Bend values. The existing restriction to matching start
  and end widths for zero-radius bends remains.
- Double-clicking the localized Bend state annotation offers bent/unbent choices.
  Properties and Family Table use the same localized state names.

## Native formats and verification

Native formats are Part INI 35 / JSON 59, Assembly INI 29 / JSON 41, and Drawing
INI 18 / JSON 10. Part/Assembly start templates are updated. Earlier native
formats are unsupported; no required sidecar or geometry cache is introduced.

All thirteen selected native/GUI suites passed: nine in 67.63 seconds
(`build/release-1704-recovery-tests.log`) and five in 73.28 seconds
(`build/release-1704-final-check-tests.log`, including one repeated kernel suite).
Coverage includes native recovery, cached-prefix references, actual View angle
entry and red Tree state, Flat/Bend attachments, Sketcher C/M references,
Part/Assembly persistence, profile commands and history edits. Earlier failed
runs are retained as diagnostic evidence and are superseded by these passes.

Seven applicable archive/source tests passed (two Linux-only cases skipped),
and all sixteen publisher input-gate tests passed; see
`build/release-1704-package-tests.log` and
`build/release-1704-publisher-tests.log`.
This release does not claim a complete repository-wide test pass.
The unrelated title-block dimension, Universal Dimension two-segment interaction,
and comprehensive console GUI LENGTH-family fixture limitations from the previous
release remain outside this change. The older authored trajectory-endpoint issue
is distinct from the box cross-branch state regression fixed here.

Development continues through repository-root `zima-cad.bat`. The Windows portable
package contains its own dependencies and committed source. Signing means the
existing authenticated Ed25519 update protocol, not Authenticode signing of each
executable. Linux is a separate release.
