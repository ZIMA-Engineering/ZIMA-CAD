# ZIMA-CAD 2026101803

## Changes

- Studs use independent extrusion sides from their seating plane: first `e`,
  then opposite nominal length `l`. Overall length remains `e + l`. All 74
  factory variants retain their original document and authored element IDs;
  both thread supports and the stock relation follow the corrected sides.
- Fastener HTML omits approximate mass tables and rows while retaining native
  calculated mass and directory metadata. Stud length grids show explicit
  thread/length availability from the historical source, including fine-thread
  headings. M3 lists only 12, 14, 16, 18, 20, 22, 25 and 28 mm.
- ISO 4762 has a small revolved socket-mouth lead. Its authored radial size is
  `0.1P`; the socket floor is deepened accordingly to retain effective key depth
  and the tabulated minimum floor thickness. Original document/features remain.
- Cylindrical-head illustrations place `b` above the shaft alongside `t`.
  Socket end views include `e` across corners and `s` across flats. ISO identifiers
  are included in all localized cylindrical-head subdirectory labels.
- Seven new A2 button-head screws cover the existing M3–M12 topic. Heads use
  real constrained arc-profile revolutions, native underhead rounds, chamfers,
  threads and socket cuts. Native drawings, white horizontal thumbnails,
  metadata and five-language artwork accompany the models.
- Button dimensions follow ISO 7380-1:2022 Table 1; catalogue lengths are
  separately attributed to Bossard BN 1593 (2016). The page distinguishes
  catalogue entries from current stock and the full standard-length matrix.
  The wider normative scope includes M16, which is outside this source's
  verified A2 catalogue range. Historical source cells remain archived.

See [library authoring and verification](../STUD_AND_CAP_SCREW_LIBRARY.md).
No shared placement, Sketcher/modeling algorithm, native schema, Qt or OCCT
version changes are introduced. New visible text is supplied in cs/en/de/fr/ru.
