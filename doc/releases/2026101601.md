# ZIMA-CAD 2026101601

## Changes

Body activation preserves the current Tree expansion state. Sketch geometry and
its endpoints remain visible and selectable over Origin axes. Auxiliary geometry
uses blue-violet strokes without construction-axis extensions; ordinary
construction axes retain their established brown appearance. Native point
junctions, arc tangency/equal-radius contacts, axis-trim incidence, repeated
symmetric dimensions and read-only external-reference refresh are corrected in
the finite matrices linked below.

The factory FORM library adds Dimpled Hole and Bridge Lance, prepared from the
finished working examples with independent native identities and ordinary Body
ownership. Their spatial results, flat precuts and construction symbols survive
insertion, Unbend/Bend Back, Undo/Redo and native reopening. Exact toroidal seam,
rim vertex and thickened closing-wall ancestry fixes address failures exposed
by these authored shapes.

Extrusion Up to accepts a point from a preceding Sketch. Its current position
defines the perpendicular stop plane, including symmetric extrusion. Selecting
Up to automatically activates the target field. Bridge Lance uses this dependency
instead of an independently copied extrusion length.

File Manager retains its five fixed columns and takes custom column lists only
from metadata.ini and configured metadata includes. Native files supply current
values, units and localized labels without adding columns. Sixteen factory
directories explicitly preserve their previously displayed native columns.
