## Changes

- Equal Sketch corner radii can be driven by dragging a dependent corner.
  Collapsing one linked radius to zero collapses the linked corners consistently;
  successive edits, Undo/Redo and reopening retain the relationship.
- Sketch point/segment dimensions accept planar Face References and straight
  Intersection supports through the common picker, in either selection order.
  Unlocked line-distance dragging retains parallelism. The Sketch command label
  is simplified to **Intersection**, localized in all five languages.
- Positive Shell supports multiple disconnected solids in one operation.
  Selected openings identify the solids to hollow; untouched solids retain their
  source topology. An empty opening list hollows all solids.
- Mirrored closed Thin profiles calculate the same interior/exterior thickness
  side as the cyan preview. The supplied skeleton's final extrusion now builds
  both rounded rectangular regions consistently, including its plane limits.
- TOP puts X right/Y up; XZ Sketch entry puts X right/Z up. Vertical Sketch
  dimension text reads bottom to top. Surface transparency preserves correct
  depth-tested edge display in hidden-edge modes.
- Feature Pattern and Mirror retain the source feature's construction axes,
  centerlines and associated points, including successive feature copies.
  Ordinary visibility controls govern the transformed construction presentation.

private configuration and edited library assets are excluded from packaging.

requires the Linux host and is not claimed for this Windows release.

Use explicit **Regenerate** on existing models to rebuild corrected Thin geometry
and copied construction axes from their native definitions.
