# ZIMA-CAD 2026101108

This build adds the integrated [web browser](../WEB_BROWSER.md), extends ordinary
[Axis ends](../AXIS_EXTENTS.md) with None alongside Length and Up To, and fixes
imported STEP source documents appearing as tabs after closing their Assembly.

Browser tabs support multiple pages, bookmark folders and favicons, Home first
in the navigation bar, Working Directory downloads, configurable home/startup
preferences, cookies/cache controls and system-backed password storage. Browser
settings and bookmarks belong to shared installation-root configuration.
Windows uses one complete Qt 6.11.0 SDK, including WebEngine/WebChannel; native
OCCT remains pinned to 8.0.0. Linux consumes the same C++ implementation and data.

Imported STEP Parts and subassemblies stay in memory as background sources.
Closing the final visible Assembly releases its orphaned background documents
without opening their tabs. Explicitly opened source tabs remain ordinary tabs.
Saving an Assembly writes changed live native sources before publishing their
owner; dirty-source detection and stale save receipts preserve pending edits.
The retired Cylinder Axis feature was removed; cylinder-face placement remains.

English, German, French and Russian; source coverage and Qt placeholders passed.
