## Scope

Relations use a multiline text editor and plain source embedded in native
documents. Assignments, quoted Unicode text, text concatenation, mathematical
functions and conditional branches drive document parameters and supported
dimensions on explicit Regenerate. Existing physical-property relations also
wait for Regenerate. Part colour can be selected by conditional parameter rules.
The editor inserts View dimension identifiers at the text cursor, displays
their current values and identifies driven dimensions with `fx`.

Linear and circular Pattern dimensions expose spacing, angle and instance
counts in the View. Double-clicking a Pattern instance opens its own dimensions.
Part regeneration evaluates a draft; Assembly regeneration publishes a complete
staged result as one Undo step. See [Relations](../RELATIONS.md) for syntax,
supported targets, calculation order and format versions.

Deleting a Part history source previews its dependent objects in red. OK removes
the source and broken references while retaining the dependent history objects
for repair. Cancel restores the tree; Undo restores the source and references.
Incomplete Fillet, Chamfer and Pattern objects remain saveable and editable.
See [History deletion](../HISTORY_DELETION.md) for exact scope and persistence.

Library insertion options for variant parameter values are not included.
Assembly occurrence deletion and multiple-selection confirmation retain their
existing workflows.

## Verification and limits

The Windows GUI and CLI compile. The Relations implementation passed seventeen
focused checks covering parsing, dimensions, persistence, transactions,
metadata, editor interaction, View picking, Patterns, templates and localization.
After history deletion changes, nine core and GUI checks passed, including
Part transaction/publication contracts, engineering metadata, Pattern dimensions
and creation from native templates. Five-language translation validation passed.
The additional incomplete-feature Properties opening check also passed.

Deletion tests cover a valid Extrusion–Fillet–Chamfer chain, native round trip,
explicit regeneration, repair on a replacement edge, independent Body geometry,
Pattern source deletion and Undo/Redo. GUI checks cover the actual Tree context
menu, red preview, Cancel, OK, saving, reopening Properties and middle-button
confirmation over the View. The confirmation screenshot was inspected.

The complete CLI process suite still stops in drawing-template/DXF checks;
the complete derived-copy GUI suite exceeds its timeout after the focused
Pattern checks. These are not reported as fixed or full-suite passes. Native
Part and Assembly formats changed; legacy documents are unsupported under the
project's format policy. Shared container placement was not redesigned.
