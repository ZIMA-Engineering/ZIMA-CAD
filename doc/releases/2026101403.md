# ZIMA-CAD 2026101403

## Changes

Part Save writes the native temporary file once and checks the final stream
closure before replacing its destination. It no longer reopens the complete
model during ordinary saving. Full exact roundtrip verification runs in tests.
On the saved 853 MB `02.prtz`, the first measured sample drops from 78.830 to
44.072 seconds, a 44.1% time reduction. Opening is not claimed faster.

Circle creation on a native segment endpoint reuses its point identity.
Trimming retains the persisted contact at its surviving Arc endpoint and
avoids redundant incidence equations. The saved `03.prtz` rectangle/circle
profile accepts feasible repeated dimension edits and point manipulation.
The circular seed consumes shared native incidence, and manipulation of its
independent saved tangent contact preserves stored identities.

Shared C++, OCCT 8.0.0, native formats, container placement and precision remain
unchanged. No new or changed UI text is introduced; all five catalogs are
reviewed by the existing coverage check. Original user documents/settings and
custom libraries are excluded from the change and package.
