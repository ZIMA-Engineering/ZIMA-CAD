# Windows 2026110601 — independent sheet history and retained feature frames

Status: signed Windows release published and publicly verified at
`2026-11-06T07:15:17Z`.

[Download the signed Windows release](https://github.com/ZIMA-Engineering/ZIMA-CAD/releases/tag/ZIMA-CAD-2026110601).

This release makes generated sheet-metal Flats and Bends ordinary independent
history features. Removing one Bend retains unrelated sheet geometry and
invalidates only features that directly use its missing reference. Removing the
Sheet from Body divider restores the earlier solid without deleting the authored
sheet definitions. Lost ordinary references retain the feature's last numeric
frame and owned geometry so that the definition can be repaired; Fillet,
Chamfer and Shell retain their geometry-dependent failure behavior.

Sheet from Body now binds both ends of a complete joining outline segment to the
corresponding Bend endpoints. Meeting edges use the sheet thickness and actual
branch angle for the endpoint setback, including oblique branches. Imported STEP
sheet geometry keeps its existing authored clearances. Generated Flat ownership
remains distinguishable in the combined result, and Profile authors ordinary
Flat/Bend children that can be decomposed back into normal history features.

The same native-format refresh also removes the obsolete per-file revision and
archive command paths, retains current feature frames and exact references,
repairs the affected Sketch and modeling dialogs, and includes the approved
Profile, Transition, Helical Sweep and Sheet Form toolbar artwork. Factory
documents, symbols and Part/Skeleton templates are regenerated with the current
native implementation. User documents, local backups and investigation files
are not part of the release source.
