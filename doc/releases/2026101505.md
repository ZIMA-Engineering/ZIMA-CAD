# ZIMA-CAD 2026101505

## Changes

File Manager gains local and global name/wildcard exclusions. The Filters button
opens the local `0000-index/filters.ini` editor; Settings supplies global defaults.
The metadata-directory exclusion is configurable. Local Hide rules follow the
current ZIMA-Parts convention, without parent-directory inheritance. Obsolete
`files.ini` data is preserved. Type buttons retain fast in-memory filtering,
use lowercase names and native icons, and show the shared azure checked state.
Versions has an icon; the Type column remains available. Column filter editors
follow horizontal scrolling. Thumbnail size and file actions share one row.

Opening one `.matz` displays Material Properties with its parameter table, OK,
Cancel and Save As. Tools > Material Manager retains the directory tree, material
list and new-material/folder actions. Its tree omits internal metadata folders.
Both modes share validation, atomic saving, read-only/content protection and
external-change detection. Unchanged OK does not write. Save As creates a copy.
Library edits preserve units and descriptions in other languages and do not
modify materials already assigned to existing CAD documents. File Manager reads
material parameters and mirrors saved values into directory metadata. Folder
creation respects source/content locks; parameter protection alone permits it.

All ten current factory symbol files have native geometry-based thumbnails;
their source definitions are unchanged. Eighteen engineering category logo-text
icons follow the existing Symbols presentation. Reference tables consolidate
redundant nesting and related dimensional ranges, retaining 287 logical references
and 337 directories in all five languages. Scrollable tables keep headers and
identifying columns visible. Print panels repeat their identifying columns.
All original values, figures, evidence references and unresolved review status
are retained. Eighty additional original source files have hash-verified retained
copies and a path manifest. No complete numerical standards certification is
claimed; seven source categories still await evidence.

Selected model geometry uses azure without the extra projected thick-edge pass.
Native cache loading expands shared storage blocks once, retaining consistency
validation and independent decoded values. On the same 499,764,705-byte Part,
recorded complete-load samples decrease from 19.68 s to 15.06–16.86 s; this is a
local observation, not a universal startup guarantee. The separate consistency
experiment measured 0.33–0.36 s and the checks remain enabled by user decision.
See [measured cache work](../performance/20261015-native-cache-read.txt).

## Verification scope

New and changed UI text and material descriptions cover Czech, English, German,
French and Russian. The dedicated native translation contract also checks
Material Manager and individual Material Properties behavior. The library has
36 independent data/layout/source-evidence checks. All 1,435 localized pages
pass rendering, frozen-header, contrast and missing-asset checks; all 3,977
physical A4 sheets pass selectable-text and printable-bounds checks. Representative
screen and first/continuation print pages are visually reviewed. Packaging and
publisher suites have 31 cases, with two Unix-only skips on Windows.

Native Windows checks cover cache storage, materials, File Manager, workspace
opening and selection behavior. Exact final package identity, native smoke,
signatures and public acceptance are recorded after the release gates pass.

Shared C++, Qt 6.11.0, OCCT 8.0.0 and native file formats remain unchanged.
No protected placement contract is modified. Native Linux execution remains
unverified for this change. The repository-root `zima-cad.bat` continues to
launch the current local development build. Personal settings, working models
and independently edited symbols remain outside the committed-source release.
