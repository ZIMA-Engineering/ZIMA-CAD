# ZIMA-CAD 2026112001 — Windows

Sheet from Body now owns editable RIP Sketches and exposes ordinary Properties.
RIP curves form local source-face boundaries; conversion preserves the resulting
sheet regions. Empty confirmation creates a history boundary, and complete
release keeps the RIP inputs as ordinary Sketches. Failed definitions can be
saved for repair without losing the last valid material result.

Sketch Fillet has a radius field, two shared curve-reference fields and an
interactive preview. Cancel restores the original Sketch; OK commits once.
Deleting rounded supports or a complete selected chain is repaired. Assembly
Sketch dimensions retain radius/diameter picking after scene refresh.

Extrusion Up To now terminates on the exact cylindrical support surface.
The shared placement calculation no longer derives a large arbitrary twist
from floating-point residues at an orientation pole. Manual angles and
corrections retain their established behavior.

Known follow-up: the user reports a missing azure cylindrical Up To preview
in `26.prtz` / `Tažení 05`. The native calculation checks pass, but this
Properties preview issue remains for the next repair after this package.
The 3D Section Properties dialog also has a newly reported displaced Default
Origin button and missing origin preview; that GUI repair is subsequent work.
Body Measurement currently blocks a Body whose history contains an uncalculated
feature. Measuring the retained valid Body with an explicit state warning is
also scheduled for the subsequent repairs.

See the [verification matrix and explicit limits](../verification/20261120-owned-rip-and-sketch-fillet.md).
All five UI languages are updated. Two affected factory wheel-nut definitions
are re-expressed and verified to preserve their physical frames and material.
Windows and Linux continue to share one C++ implementation and the same pinned
OCCT dependency version.

Protected Toyota originals are untouched. Their older unsupported Part formats
still prevent complete project regeneration; copied Drawing readback succeeds.
Linux execution remains a separate host task. Projection and FEM remain future
design, not features delivered by this build.
