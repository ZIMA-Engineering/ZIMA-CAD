# Windows 2026101208 — directory overview and engineering names

## Changes

File Manager now has only Overview and Files. In the absence of active-language
or generic HTML in `0000-index`, Overview displays a native directory header and
large subdirectory cards with localized names above their previews, following
the ZIMA-Parts automatic directory index. One click opens a directory. Files
remain in Files. A project's number, title, description, customer and preview
appear in the same Overview; the existing context menu opens its editor.
Cards follow the live Qt palette, including Light/Dark/Light changes.

The engineering-table factory snapshot has reviewed English storage identifiers
and full labels in Czech, English, German, French and Russian for all 312
directories. Names use engineering terms rather than literal translations such
as pens for keys or fuses for retainers. The catalog is stored under
`tools/data/engineering-table-directories.json`. Original standard identifiers
and supported size ranges are retained. When source directory names disagree
with actual table ranges, labels follow the table contents.

The importer fixes an empty-INI-label parsing error, quotes comma-containing
labels for native QSettings scalar reading, and verifies the catalog
against the imported metadata. Reimporting preserves directory IDs, settings,
removal protection, all 279 HTML pages and the non-web reference assets. Web
navigation is rewritten to the reviewed paths. Two already-missing references
in an unused legacy page remain recorded; active Overview index links pass.

File Manager now reads and writes canonical QSettings hierarchy keys, matching
ZIMA-Parts INI data. This repairs the earlier mismatch that ignored imported
localized labels and parameter values. Previously authored CAD escaped-key
values remain readable; explicit edits write canonical keys. Both parameter
lists and comma-separated scalar definitions remain supported.

No native CAD document format, geometry, placement contract or kernel pin changed.

## Verification

Focused File Manager, integrated workspace and five-language contracts pass.
The native Windows harness verifies readable Overview text and live palette
changes. The importer passes its four regressions and the full factory-tree
verification, covering 312 stable directory IDs, 1,560 labels, retained settings
and identical non-web assets. The native Qt reader additionally verifies all
1,560 labels as nonempty scalar strings. Native Linux verification remains assigned to the
Linux host. Signed Windows acceptance will be recorded after publication.
