# Windows 2026101202 — shared Features and reference fixes

## Changes

Parts and Assemblies expose the same Feature command, property dialog and
Point, Axis, Plane, Sketch, Extrusion and Revolution editing definition.
Assembly material operations subtract from selected immediate editable Part
occurrences. They never add material or change a source Part's authored history.
The existing shared 3D Curve implementation remains available in both contexts.
Owned Sketch drafts return to the same Feature dialog; Cancel discards the draft.
Unchanged OK returns before dependency preparation, calculation or an Undo step.

The ordinary Feature Axis now has independent Length, Up to and None controls
for its two ends. None preserves the authored length, target and numeric locks.
Axis properties hide the inactive work-plane controls. A disabled end is stored
as `axis_enabled=false` in its native Feature parameters; enabled ends use the
default current-schema state. This fixes the ordinary Feature rather than only
the separate ConstructionObject extent controls added in 2026101108.

Imported STEP cylinder picks obtain their surface kind from the persisted
original-reference packet. Display triangles need not duplicate analytic
surface metadata. The lookup includes the occurrence path, owner and semantic
key, and is invalidated with the View's base packet revision. Both reference
entry and candidate filtering use this lookup, so cylinder-to-cylinder rows
select the existing axis coincidence equations instead of plane coincidence.

An inserted FORM's planar angle annotation uses its confirmed sheet-normal
frame. Double-click inspection consumes calculated native data and keeps both
angular witnesses in the support plane. The general container-placement solver
and its reference, offset and side contracts are unchanged.

The Assembly GUI delegates cutter calculation to the shared workspace
implementation. An unused GUI calculation wrapper and duplicated profile-target
reconstruction were removed. Required ConstructionObject and kernel operation
implementations remain because current curve, profile and native CLI consumers
still use them. No unrelated cleanup of working modeling algorithms is included.

`feature.get`, `feature.create` and `feature.set` expose the same native Feature
transactions to the CLI. Editing preserves the owned Sketch identity and numeric
locks. New user-facing text is translated in Czech, English, German, French and
Russian. The browser fixes accepted in 2026101201 remain included.
