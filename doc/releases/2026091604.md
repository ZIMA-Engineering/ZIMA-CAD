# ZIMA-CAD 2026091604

- Sketcher distances now display positive magnitudes consistently, including
  dimensions from the origin and the built-in axes. Positive input preserves
  the current side; negative input reverses it and displays a positive value
  again. The solver retains signed coordinates internally. Existing constraints
  must permit the change; rejected edits leave the Sketch unchanged.
- Dimension value fields accept arithmetic with `+`, `-`, `*`, `/`, parentheses
  and decimal commas. Invalid expressions remain available for correction.
- Selecting a dimension immediately after creating it no longer loses the
  selection during command cleanup, allowing normal double-click editing.
- Sketcher Coincident accepts both point-then-axis and axis-then-point selection.
- Sheet Metal includes the first sketch-based Bend/Unbend command, document
  thickness and K-factor defaults, and per-feature overrides. Default thickness
  is 1 mm and no longer requires a document-level enable checkbox.
- Drawing Text offers immediate cursor placement, an empty-text dash, multiline
  input and a symbol picker. Default text is green and 2.5 mm high. Dimension
  text clearance preserves the dimension line beneath the value.

See [Sketcher](../SKETCHER.md), [Sheet Metal](../SHEET_METAL.md), and
[Drawing Text](../DRAWING_TEXT.md). Development continues to start through the
repository-root `zima-cad.bat`.
