# Windows 2026100703

Status: source acceptance completed; distribution gates pending.

This build introduces the Sheet Metal FORM command with an independent native
Part definition. The four ordinary Body roles are FORM_CUT, FORM, FORM_FLAT and
FORM_SYMBOL. The supplied Ventilation Window has an intentionally empty flat
precut. Global Settings exposes the FORM library directory; insertion and
replacement accept only `.prtz` files.

FORM reads the calculated connected outer shell, grows thickness inward and
closes its rims. It represents manufacturing intent, rather than predicting
the exact forming process. The selected outer sheet side fixes the insertion
point and normal; the Properties window permits rotation in that plane and
atomic definition replacement. Ordinary placement mathematics and side choices
are preserved. Source changes invalidate calculated-surface reuse, and the
embedded native definition requires neither the library file nor a sidecar.

Unbend substitutes the optional FORM_FLAT cut; Bend Back restores the spatial
skin. Sheet Cut excludes symbolic forming skins. Drawing Show/Erase offers
FORM_SYMBOL through the ordinary symbol annotation contract. Repeated Assembly
occurrences retain distinct attachment paths. Replacement leaves absent
dependent geometry explicitly unresolved; Undo restores the previous source.

On the actual Ventilation Window, complete GUI confirmation, calculation,
commit and scene publication measured 1.93–1.95 seconds. Cold native insertion
measured approximately one second. These are Windows Release observations on
one fixture, not a universal timing guarantee. Rotation and inspection consume
persisted viewer data, and unchanged OK creates no calculation or transaction.

The same change adds Default beside Origin, retaining the nearest owning
container's complete-Origin entry; retains valid cuts that remove no material;
and keeps newly failed feature definitions editable in the red Tree state.
Thicken Surface consumes every patch of a connected sewn shell. Retired solid
axes disappear from passive surface Bodies, while preceding FORM_CUT Sketches
remain available as read-only context when editing FORM. A shared animated
activity indicator appears in the View center and beside OK during explicit
work. Calculation workers retain private pending geometry and commit on the
owning thread.

## Source acceptance

- Native FORM role validation, independent normal-offset equations on every
  surface patch, BRep validity, connected positive-volume solids, both sheet
  sides, successive thickness edits, rotations, flat restoration, replacement,
  dependent references, suppression, exact occurrences and save/reopen passed.
- Final FORM preparation resolves its native input frame before calculation,
  removing an unused second result preparation. Correctly rotated GUI insertion
  measured 1.183 seconds locally. The first packaged candidate reached 2.112
  seconds and was not published. The angle control now uses the actual free
  local-Y angle; native Rodrigues checks and preview/sample-to-result comparisons
  guard actual rotation, rather than only an unchanged support normal.
- The complete FORM GUI matrix passed in 76.72 seconds, including actual
  hover/LMB confirmation, reference replacement at a different insertion point,
  independent inspection, rollback, unchanged OK, replacement Cancel/OK,
  Undo/Redo, native reopening and ordinary whole-shell thickening.
- The final thirteen dependent native/GUI suites passed. The general native
  contract then passed separately in 6.29 seconds after obsolete coplanar
  expectations were aligned with the permanent oldest-face contract. Its
  unified edge still checks native ancestry from both sources and downstream
  Fillet/Chamfer behavior.
- Current CLI opening, context/Tree inspection, explicit regeneration and native
  saving of an isolated FORM copy passed. All seven native Part/Assembly start
  templates were regenerated and reopened; their bytes remained current.
  Actual new-document/template GUI checks confirmed active editing context and
  ordinary command availability.
- Five-language catalog coverage, placeholder validation and translated FORM
  Properties passed in Czech, English, German, French and Russian. The shared
  dialog layout matrix covers 370 language/dialog/size combinations. The
  combined console GUI passed in 168.34 seconds.

Documentation and the user manual are English. Shared C++ modeling and OCCT
8.0.0 remain aligned for Windows/Linux. Linux execution must be established
on its own host. This focused acceptance does not claim that the entire
repository-wide suite passes: inherited Extrusion Limit, hidden Surface Profile
and Boolean Assembly failures are recorded in the preceding release.

Insertion across a bend, recursive symbols inside FORM_SYMBOL, direct editing
of the embedded definition and configurable manufacturing DXF layers/tool
designation remain outside this first implementation. Unsupported offset
geometry retains its diagnostic and authored definition. Further GUI matrices
for every feature's failed-creation/repair path are not claimed.
