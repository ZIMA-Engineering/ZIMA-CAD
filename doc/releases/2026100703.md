# Windows 2026100703

Status: signed Windows release published and independently verified.

This build introduces the Sheet Metal FORM command with an independent native
Part definition. The four ordinary Body roles are FORM_CUT, FORM, FORM_FLAT and
FORM_SYMBOL. The supplied Ventilation Window has an intentionally empty flat
precut. Global Settings exposes the FORM library directory; insertion and
replacement accept only `.prtz` files.

FORM reads the calculated connected outer shell, grows thickness inward and
closes its rims. It represents manufacturing intent, rather than predicting
the exact forming process. The selected outer sheet side fixes the insertion
point and normal; the Properties window permits rotation in that plane and
atomic definition replacement. Ordinary placement mathematics and side choices
are preserved. Source changes invalidate calculated-surface reuse, and the
embedded native definition requires neither the library file nor a sidecar.

Unbend substitutes the optional FORM_FLAT cut; Bend Back restores the spatial
skin. Sheet Cut excludes symbolic forming skins. Drawing Show/Erase offers
FORM_SYMBOL through the ordinary symbol annotation contract. Repeated Assembly
occurrences retain distinct attachment paths. Replacement leaves absent
dependent geometry explicitly unresolved; Undo restores the previous source.

On the actual Ventilation Window, complete GUI confirmation, calculation,
commit and scene publication measured 1.183 seconds locally and 1.586 seconds in
the final signed package. The packaged first insertion prepared one kernel result,
with no unused settling calculation. Cold native insertion measured approximately
one second. These are Windows Release observations on
one fixture, not a universal timing guarantee. Rotation and inspection consume
persisted viewer data, and unchanged OK creates no calculation or transaction.

The same change adds Default beside Origin, retaining the nearest owning
container's complete-Origin entry; retains valid cuts that remove no material;
and keeps newly failed feature definitions editable in the red Tree state.
Thicken Surface consumes every patch of a connected sewn shell. Retired solid
axes disappear from passive surface Bodies, while preceding FORM_CUT Sketches
remain available as read-only context when editing FORM. A shared animated
activity indicator appears in the View center and beside OK during explicit
work. Calculation workers retain private pending geometry and commit on the
owning thread.
