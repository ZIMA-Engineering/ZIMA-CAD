# Windows build 2026092402

## Changes

- Parameters, Material and Family Table use their available dialog height for
  the table. In Relations the lower dimension catalog expands. Window defaults,
  editing behavior and confirmation remain unchanged.
- Sheet Transition has a persistent primary axis between the centres of its
  authored semicircular and half-rectangular profiles. Offset profiles and rigid
  placement are respected; the axis uses ordinary axis display and references.
- STEP/IGES Parts newly created by Assembly import inherit the complete ordered,
  localized parameter data and relations of the configured start Part and S235JR properties
  from the configured material library. Import into an existing Part preserves
  its metadata. Derived mass follows the imported geometry and assigned material.
  Geometry, imported identities and repeated instances are unchanged.
- Body Measurement offers a surface-area-weighted centroid when the measured
  geometry has no solid volume. The existing surface integration supplies the
  centroid during calculation; opening Measurement does not call OCCT. The UI
  identifies the surface result and does not invent mass or mass inertia.

The calculated native packet now stores `surface_centroid`; saved body-property
records store `surface_centroid_mm`. Part/Assembly extensions remain unchanged.
These are current-format fields, not a legacy compatibility layer. Start Part,
Skeleton and Assembly templates were resaved through the new native CLI. Their
empty calculated data produces byte-identical tracked templates. GUI creation
from the templates passed in all five supported languages.

Backlog additions: general spherical surface, a parameterized Straighten modeling
command, and completion of engineering symbols. These features are not implemented
by this release.

## Verification

All ten selected regression contracts passed: Assembly STEP/IGES/DXF import,
existing-Part import, surface profiles, analytical Body Measurement, Sheet
Transition calculation and GUI, shared UI, localization/catalog coverage,
new-document creation, and the Measurement inspector GUI. The surface result
dialog was instantiated and checked in all five languages.

The new surface test uses perpendicular faces of unequal area with an
independently calculated centroid, checks Body rotation/translation, Mirror,
Pattern, native measurement/cache persistence and the displayed analysis Origin.
Existing solid volume, mass, inertia, history and transaction checks still pass.
Transition verification covers persisted/regenerated axis references, normal
display, rigid placement, tilted profiles, Unbend/Bend Back and downstream sheet
operations. Import verification includes derived mass, metadata persistence,
shared occurrences, independent source relocation, Undo and atomic failure.

Updated old GUI test expectations for the current cylinder-axis dialog title
and reference column, and made Measurement assertions use the active language.
The relocation fixture now resaves its moved Assembly so relative child paths
remain valid. No application relocation or shared placement behavior changed.

Evidence: `build/release-2402-acceptance.log` (nine passing contracts), followed
by `build/release-2402-measure-final.log` (the corrected Measurement assertion
