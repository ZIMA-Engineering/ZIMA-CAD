# Windows build 2026101001

Keeps the complete calculated imported Body visible while editing its placement,
accelerates common face/container picking and placement over large imports,
removes discarded initial STEP result preparation, and reduces Extrusion opening
and cancellation costs without changing body calculations or reference contracts.

The [import interaction investigation](../performance/20261010-import-interaction-investigation.md)
records candidate-list equivalence, complete Body translation/rotation, Cancel,
unchanged/changed OK, native save/reopen and Undo/Redo. The common picker on the
captured G92H1 packet improves from 35.85 to 3.20 ms per query; actual warm GUI
placement queries including placement filtering average 21.78 ms.

The [STEP/Extrusion record](../performance/20261010-step-load-and-extrusion.md)
defines the measured scope: G92H1 source capture and history preparation improve
from 133.3 to 96.4 seconds with exact complete final packets. Median warm
Extrusion opening improves from 4.89 to 2.25 seconds; Cancel from 3.63 to 1.43
seconds, retaining complete context, camera and transaction state. These are
Windows observations of specific operations, not universal import timings.

GPU preparation remains byte-exact; changed source geometry invalidates reuse.
The native format, modeling precision, persistent identities/sides, shared
container placement and pinned Windows/Linux OCCT 8.0.0 are unchanged. No product
UI strings were added or changed; five-language localization is reviewed.
Concurrent Linux-preview source updates are retained. Explicit Windows Form
regeneration is required because Windows rejects the Linux preview's calculation
fingerprint; geometry and identity comparison pass, but cross-platform native
cache portability remains unresolved. See the
[Linux follow-up](../LINUX_RELEASE_HANDOFF.md#imported-model-performance-and-factory-cache-follow-up-2026-10-10).

The G92K1 kernel crash remains unresolved; the file has not been proven invalid.
Linux execution, complete large multi-component import, quantified rotation FPS
and the broader previously failing UI diagnostics are not accepted by the focused
Windows checks. The linked investigations state the individual coverage limits.
