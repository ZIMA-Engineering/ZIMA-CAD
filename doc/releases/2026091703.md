# ZIMA-CAD 2026091703

## Changes

- Flat and Bend persist sheet face roles, boundary classifications and endpoint
  ancestry. Ordinary modeling and sheet features can share the same Body.
- Selecting a straight sheet boundary edge automatically attaches Bend, derives
  its joining face and thickness, and binds both profile ends. Thickness edges
  are excluded. The start profile lies directly on the container Origin, without
  an additional plane offset. The selected edge starts the outer radius; angles
  remain 0–180 degrees. Choose the opposite boundary edge to change sides.
- Unequal endpoint offsets retain their physical ends across edge replacement,
  endpoint changes and reversed parameterization. Zero endpoint dimensions remain
  visible. See [Sheet Metal](../SHEET_METAL.md).
- New Bend properties inherit radius from thickness. **Custom radius** enables
  manual editing. The preview waits for references that determine orientation.
  Flat has a **Switch** button beside Direction. Confirming changed sheet defaults
  calculates dependent geometry immediately; unchanged Flat/Bend confirmation can
  refresh calculated geometry without adding an unnecessary Undo entry.
- User selection filters restrict the common hover, click and cycling candidate
  list, including container reference entry. **Edges/curves** and **Origins** join
  the existing filters. See [Viewer Selection](../VIEWER_SELECTION.md).
- **New > Drawing** requests a native Part or Assembly source before creating a
  tab. Canceling creates no Drawing. Creating a Drawing from a Part or Assembly
  uses its known source without prompting. **Insert View** directly starts the
  original placement/properties workflow and safely handles missing sources.
  See [Drawings](../DRAWINGS.md).

## Compatibility and verification

Native formats are Part INI 32 / JSON 56, Assembly INI 26 / JSON 38 and Drawing
INI 18 / JSON 10. The tracked Part and Assembly start templates are updated.
Legacy native documents are unsupported. All required topology and reference
metadata remain inside the native documents; no required sidecar is introduced.

Focused verification covers sheet geometry and ancestry, eight Flat boundary
edges and both endpoints, 0/90/180-degree bends, unequal 3/11 mm offsets, rotated
Bend-to-Bend attachment, native save/reopen, occurrence metadata, actual GUI edge
picking, all three owned Sketch editors, filters, settings Undo/Redo and the
main-window New Drawing / Insert View workflow. All sixteen final targeted native
and GUI contracts passed in 97.91 seconds (`build/release-1703-tests.log`). Seven
applicable archive/source tests passed (two Linux-only tests skipped), as did all
sixteen publisher input-gate tests (`build/release-1703-package-tests.log` and
`build/release-1703-publisher-tests.log`). Package acceptance is recorded below.

Known limitations from the previous release remain: bounded construction Axis,
shared title-block dimension solving, Universal Dimension two-segment interaction,
and the comprehensive console GUI's invalid LENGTH family fixture. The title-block
failure was observed again during this development cycle. The authored Bend
trajectory-endpoint/Unbend limitation also remains documented. This release does
not claim a complete repository-wide test pass or repairs to those unrelated cases.

The development entry point remains `zima-cad.bat`. The portable Windows package
uses its own `ZIMA-CAD.exe`, private native dependencies and committed source.
Publisher signing uses the authenticated Ed25519 update protocol, not Windows
Authenticode signatures on individual executables. Linux is a separate release.
