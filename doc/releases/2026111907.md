# ZIMA-CAD 2026111907 — Windows

Sheet from Body now uses the complete attachment boundary when symmetric or
two-sided Extrusion splits it at the Sketch plane. This repairs the half-height
Bend and long opening reported in `25.prtz`, while retaining original source
references and independent parallel sheet branches.

RIP Sketches can be selected in the Tree as well as the View. An owned Sketch
is selected by its exact child row; a standalone Sketch also accepts its
container row. Existing source ownership and history eligibility checks remain.

See the [finite verification record](../verification/20261119-sheet-rip-and-split-boundaries.md).
The native file format, factory assets and Windows/Linux dependency versions
are unchanged. Native Linux execution remains a separate host task.
