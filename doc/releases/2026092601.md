# Windows build 2026092601

## Changes

- Unified Feature creation, Point/Axis/Plane/Sketch/Extrusion shortcuts and
  operation-aware Tree rows include the work committed since 2026092402.
  Revolution presets both side operation modes; full rotations exclude an
  overlapping opposite rotation, while an opposite extrusion stays independent.
  New pending Features remain collapsed. Sketch/solid geometry is white;
  construction lines retain their brown appearance.
- Point/Text controls are available on meaningful placed Part modeling and
  sheet containers. Fillet, Chamfer, Shell and history-state operations do not
  expose them. Idle presentation is saved in the native document. Visibility-only
  edits retain calculated body data and support Undo/Redo.
- Every Feature type exposes its complete Origin during Properties. The first
  face picked in the View seeds placement at the hit position, honors numeric
  locks and retains coordinates beyond displayed decimal precision.
- Opening an owned profile Sketch from the Tree enters its parent operation's
  transaction. Finish returns to Properties; OK commits and Cancel restores it.
- Exact solid-face hover uses translucent green fill; confirmation and independent
  inspection use azure. Datum planes retain their frames. Cached viewer triangles
  supply the fill without a kernel calculation. H-Sweep placement offers the two
  endpoint caps, not its unsupported curved side.
- 2D/3D/H-Sweep have **Custom precision** controls, separate configuration defaults
  and native per-feature snapshots. The default is 0.001 mm for 2D/3D and 0.1 mm
  for H-Sweep. GUI and CLI share the behavior. A relaxed transported sweep that
  fails self-intersection validation retries surface construction once at
  0.001 mm; invalid results are still rejected.

The eight-turn benchmark improved from 261 s to 6.6 s at 0.1 mm, with all measured
BReps valid and a largest sampled surface difference below 0.0026 mm. 2D/3D gains
were small. The 0.5 mm follow-up exceeded two minutes without a result and was
interrupted, so it is not the factory default. These are synthetic fixtures,
not guarantees for all models. See [the method and raw measurements](../benchmarks/SWEEP_PRECISION_20260926.md).

The native format requires history origin-display flags and sweep precision
data. Extensions remain `.prtz`, `.asmz` and `.drwz`; no external model sidecars
or legacy compatibility branches were added. Start templates were refreshed;
their empty content remains byte-identical. New Part/Assembly GUI activation
from templates is included in verification.

## Verification status

All 20 focused contracts passed: portable settings, 2D/H-Sweep dialogs and kernel
contracts, common UI, sheet attachment, translations, numeric locks, sweep
commands and point references, Feature prototype and type UI, surface placement,
pending curve points, new-document options, Sheet Transition commands and UI,
Feature parameters and Holes UI. The Holes fixture now verifies the picked
source identities (including body-edge selection) and locates its owned Sketch
by identity; projected lines legitimately add two endpoint references.
Portable acceptance is pending; this record does not yet claim a signed or
published package.

An additional all-dialog layout audit found ten failures out of 300 combinations:
the two reference tables in Linear Pattern move vertically during resizing,
in each of the five languages at two window sizes. That dialog is not changed
by this work; the issue is recorded separately and is not claimed fixed.
