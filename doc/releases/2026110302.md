# Windows 2026110302 — durable routed edge treatments

This Windows release strengthens Fillet and Chamfer construction, reference
identity and editable perpendicular Sketch junctions. The product remains one
shared C++ implementation for Windows and Linux. Qt 6.11.0 and OCCT 8.0.1 stay
aligned across the native build recipes. This record establishes Windows
execution only; native Linux build and GUI acceptance remain separate host work.

## Routed Fillet and Chamfer construction

- Fillet and Chamfer Properties show Automatic, ZIMA and OCCT as three mutually
  exclusive check boxes. Every route segment is listed directly without an
  expandable parent row. Route rows stay in forward geometric order.
- Hover highlights only the exact candidate edge. Confirmed selection shows the
  complete accepted route as the ordinary cyan wire. A route continues only
  through one unique forward tangent edge; a tangent reversal or an ambiguous
  branch terminates it.
- The ZIMA Fillet builder uses the exact arc-and-two-lines profile. The ZIMA
  Chamfer builder uses its exact three-line profile. Neither builder adds an
  arbitrary 0.05 mm extension; all geometric comparisons use the configured
  modeling tolerance.
- A ZIMA Fillet can sweep an ordered mixture of straight and circular segments.
  It starts profile construction at the segment midpoint so open ends can be
  completed independently. The current ZIMA Chamfer boundary remains a straight
  route.
- A perpendicular terminal face stops the treatment exactly at the route end.
  One unique angled terminal face clips the treatment to that face. Automatic
  inference uses the same endpoint validity rule; unresolved complex ends may
  use the body envelope without extending through a known perpendicular cap.
- The first and last end-face fields remain independently replaceable and
  clearable. Explicit OCCT mode does not offer ZIMA end-face controls. An invalid
  face that does not contain its route endpoint is rejected before calculation.
- Current-result routes may contain valid line and arc descendants and are not
  discarded merely because a Boolean intersection classifier does not return
  them. Selecting an authored/original edge remains an explicit single-edge
  operation.
- Same-domain cleanup preserves non-seam boundaries and geometrically matching
  input seams. A selected route remains resolved while any persisted source
  fragment survives an upstream edit, and becomes unresolved only after every
  matching fragment disappears.

Variable-radius Fillets, spline routes, arbitrary free-form adjacent faces,
hole-intersection restoration and advanced multi-face termination remain future
extensions. Explicit ZIMA reports an unsupported case instead of silently
changing intent. Automatic may use OCCT outside the supported ZIMA boundary.

## History and failure durability

- Every history boundary now publishes the exact calculated reference packet
  belonging to that boundary. A failed producer publishes an empty exact view;
  it cannot substitute older recovery geometry and thereby rotate, mirror or
  reorder a later placed container.
- A structurally valid Fillet or Chamfer may be saved while its current geometry
  is unresolved. It remains visibly failed in history so the user can repair an
  upstream feature or its references. Malformed arguments and references are
  still rejected before insertion.
- Deleting or repairing a failed treatment restores calculation from persisted
  history. It does not mutate the placement or Sketch coordinate system of an
  earlier container.

## Perpendicular Sketch junctions

- Dragging the shared point of two perpendicular native lines now projects the
  requested movement onto the exact perpendicular-junction locus instead of
  leaving the point immobile or escaping the constraint.
- Editing an applicable length dimension seeds the solve from the analytic
  circle/locus intersection. Repeated drags and successive value edits retain
  the original shared point and the perpendicular equation.
- The regression matrix covers both line orientations and selection orders,
  driving/reference and locked/unlocked dimensions, native and read-only
  external supports, underconstrained and fully constrained states, applicable
  length and angle forms, rejection without document mutation, Undo/Redo and
  save/reopen. A real GUI test additionally drags the junction with the mouse
  and verifies Finish, Cancel, Undo/Redo and reopened geometry.

## Reference presentation

- The Reference icon is entirely brown. Reference Outline uses the same brown
  base with a white outline mark. Intersection and Intersection Outline follow
  the corresponding brown/white convention.
- Open reference edges continue to expose their endpoints as compact brown
  crosses. Their display stays distinguishable from an ordinary point during
  normal, hover and confirmed presentation.
