# Windows 2026110901 — Profile attachment and interaction corrections

Status: Unpublished Windows source tag, superseded by 2026110902.

This source tag was never published as a GitHub release. Final verification
found that the attached Sheet Profile used its own route-frame mapping and
still exposed endpoint-switch and manual-placement shortcuts. Those issues are
corrected by 2026110902, which is the only 20261109 build intended for public
distribution.

Sheet Profile can now attach directly to a valid straight sheet boundary. One
edge derives the joining face, endpoint, thickness and deterministic frame. A
new empty owned Sketch receives a 90-degree outer Bend arc followed by a tangent
Flat span, authored in positive local X/Y; the first generated Bend starts at
`R=T`. Attached thickness follows the source sheet. Profile Properties no longer
exposes material side, and provides the established endpoint switch and manual
placement transition.

3D Sweep Properties now installs its history rollback before the synchronous
initial preview, retaining the real preceding scene for display and picking.
Patterned Revolution copies regenerate their axis, while Pattern and Mirror copy
Origins expose their points, axes and planes to reference entry. This makes the
Origin workflow usable for 3D Sweep without introducing duplicate modeling data.

Sketch Trim retains applicable Parallel and Horizontal/Vertical intent when the
surviving geometry still satisfies it, including point constraints whose trimmed
endpoint stays on the required horizontal or vertical locus. Incompatible point
relations are not silently transferred. Projected Drawing view placement starts
from the prepared dimensioning frame and confirms directly without an additional
Properties step; the affected Insert View label is translated in all five
catalogs.

Interactive Drawing distinguishes thin strokes with the same continuous gray
family used for hidden geometry. The expensive on-screen line-weight preview
button is removed; precise weights remain an export/print responsibility. View
display reuses prepared depth geometry and avoids the former global slowdown.

The focused Windows Release matrix passes Profile calculation and UI, all five
localization catalogs, 3D Curve/Sweep, Bend/Flat, Fillet/Chamfer, Sheet Form,
Loft and solid-state rollback contracts. The reported `ZE-CUBE.prtz` model also
regenerates with a five-container history; its one closed 3D Sweep uses 21 unique
segments across 10 nodes without traversing a segment twice. That user model is
not a release asset.

No native file format, start template, factory asset, protected shared placement
solver, geometry-side meaning, calculation precision or dependency pin changed.
The Windows and Linux implementation remains shared and pinned to OCCT 8.0.1.
Native Linux build and execution remain a separate host gate.

See the [finite verification record](../verification/20261109-sheet-profile-and-properties-rollback.md).
