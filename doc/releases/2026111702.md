# ZIMA-CAD 2026111702

Status: native and interaction checks passed; signed Windows publication pending.

This build repairs the recreated stepped/oblique Fillet route and the closed
rib-to-cylinder transitions. Exact support boundaries, tighter swept-envelope
construction and correct closed-route termination prevent the tested residual
flaps and incomplete returning transition. General-route acceptance additionally
checks manifold edge incidence. Tangent contacts are retained through the main
transition; local terminal cuts need not be tangent everywhere.

Failed ZIMA Fillet and Chamfer construction now closes on OK or middle-button
double-click without inserting a feature or changing an existing definition.
Invalid command input still requires correction. The empty-selection prompt
remains green, and actual errors retain their warning color.

Sketcher offers H/V together with circle-to-circle C contacts. Rectangle creation
can combine a circular contact with axis symmetry. Both use actual circular
intersection geometry for preview and confirmation, including external circles.
New Mirror definitions select their own XY plane; existing definitions retain
their stored plane. Clicking Source preserves the current camera.

Verification includes the complete Sketcher contract, 16 GUI inference cases
with 576 dimension variants, repeated editing and dragging, seven saved Fillets,
five saved Chamfer variants, downstream model calculation, independent manifold
and tangent-contact checks, Mirror interaction, failed-command recovery,
save/reopen, Undo/Redo and five-language catalog validation. See the
[verification record](../verification/20261117-blend-circle-mirror-followup.md).

No native format, factory data, shared placement contract or dependency version
changes. Windows and Linux retain shared C++; Qt 6.11.0 and OCCT 8.0.1 remain
pinned. Native Linux verification requires the Linux host. The development
entry point remains `zima-cad.bat`.

Deprecated OCCT API modernization follows this release separately, with its own
verification and subsequent Windows build.
