# Windows 2026110403 — Sketcher mechanisms and responsive Drawings

This release candidate follows 2026110402 with a finite mechanism/profile
review, exact Drawing picking improvements and focused interaction repairs.
Publication is pending committed-source packaging and signed-runtime acceptance.

## Changes

- Coupled line/arc mechanisms reuse the existing simultaneous equation fitter
  when ordinary solving fails. Off-path dragging follows the handle's real
  one-dimensional motion, and rank checks retain locked and isolated positions.
- Trim retains real shared points and independent contacts; surviving native
  arc fragments share radius through a minimal EqualRadius relation set.
- Universal Arc dimension entry switches R/diameter on a repeated Arc click.
  Automatic angle sectors show positive magnitudes while explicit negative
  values retain their authored sign.
- Closed nested Assembly occurrences display their source Part Body and face
  appearance, occurrence overrides and current open unsaved source appearance.
- Drawing source-face and picking indexes remove repeated full-scene searches.
  Interactive projection avoids unused precise occlusion preparation; repeated
  Part annotation preparation is shared within one explicit operation.
- Exact cylinder generators and native rounded-shaft contours support associative
  linear, R and diameter dimensions. Native analytic adjacency data remains
  available after embedded Drawing save/reopen.
- Long Drawing preparation uses private worker inputs and the shared centered
  activity. Ordinary creation remains a lightweight frame until OK. Document
  closing paints activity before synchronous work and restores the remaining
  scene before retiring it.
- Manual dimension OK starts another dimension of the same kind. Middle
  double-click ends the command, with no transaction for an empty continuation.
- New projected views use four cardinal directions. Diagonal cursor movement
  chooses the dominant direction; click inserts directly and Escape cancels.
- Browser bookmark Properties resolves persistent bookmark identity after the
  nested context-menu event loop, avoiding a Tree-item lifetime crash.
- General ISO 21920 roughness has an Empty variant for Assembly title blocks.
  Factory and independently embedded definitions can select no mark or text,
  without changing the other variants or source library during instance editing.

## Verification and compatibility

The [review matrix](../verification/20261104-sketcher-drawing-review.md) records
native equations, repeated edits/drags, actual mouse interactions, Undo/Redo,
native reopening and representative protected-data observations. It includes
324 linkage variants, 432 tangent-slider variants, 1,440 U profiles, 180 Swivel
profiles, 96 Trim variants and 768 angular-sector variants. Exact candidate
hashes and three measured changed-view confirmations support the reported
performance improvements; they are not universal latency claims.

The supplied Assembly Drawing already has one first-level BOM row for its one
immediate subassembly and an upwards repeat region. Empty descriptive cells
reflect absent imported source parameters. The unavailable earlier draft is not
represented as a diagnosed or repaired BOM insertion defect.

Native document schemas, protected container placement, geometry precision,
side identity and OCCT 8.0.1/Qt 6.11.0 pins are unchanged. The general-roughness
definition and its embedded factory title-block copies are updated through the
native implementation; other factory assets are unchanged. All changed UI text is localized in Czech,
English, German, French and Russian. Windows and Linux share the C++ code;
native Linux compilation, execution and timing remain a separate host gate.
Private models, browser data, custom libraries and investigation artifacts are
excluded from committed source and release artifacts.
