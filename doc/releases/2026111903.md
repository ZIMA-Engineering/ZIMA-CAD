# ZIMA-CAD 2026111903 Windows release

Status: candidate built and validated, but publication is withheld. A subsequent
saved user case still fails when sheet branches touch. The mandatory independent
branch contract in `../SHEET_BRANCH_TEST_CONTRACT.md` must pass before release.

Flat, Bend and Profile can attach to straight sheet boundaries when touching
branches have merged their coplanar thickness faces. The material-side check
uses the exact selected edge's local face triangles. Flat accepts both sheet
skins; automatic Sheet from Body conversion retains its authored outer-skin
choice. Reference identity, side choice and the native document format are
unchanged.

In Sheet Metal, converted Flats and Bends precede their source Solid/Fillet in
ordinary selection. The source remains available by right-click cycling.
Profile Properties places Default plane below the placement status, keeps its
disabled plane controls beside the enabled Sketch action when attached, and
fits its height when the free-width controls disappear.

This release also includes the unpublished 1902 corrections for false red
sheet Tree entries, unchanged regeneration frames and the neutral Helical Curve
icon. The 1901 Loft correspondence, guide points, exact cut-edge and midpoint
attachment, and editing changes remain included.

See the [contact-edge verification record](../verification/20261119-sheet-contact-edges.md),
[1902 changes](2026111902.md), and [1901 validation limits](../verification/20261119-loft-correspondence.md).
The implementation remains shared C++; native Linux execution is separate.
