# ZIMA-CAD 2026112203

FEM now supports steady-state thermal analysis. Select it in FEM Body properties,
set ambient temperature and the exterior heat transfer coefficient, and use
**Heat source** to apply power to a Body face or a bounded planar/projected Sketch
area. The Part material supplies conductivity. Results show a temperature color
map, extrema and inspection values.

The separate **Measurement point** command stores a placed point with ordinary
references. Mechanical results report ΔX, ΔY, ΔZ and total displacement; thermal
results report temperature. Moving a point reuses the solution and does not
remesh. Values use T4/T10 interpolation rather than nearest-node snapping.

This release also includes real mesh/solver progress, deformation animation,
adjustable magnification, an optional transparent original, and result probes
from the preceding local development builds. Animation displays the static load
case; it is not a dynamic simulation.

See the [thermal and measurement workflow](../FEM_THERMAL_AND_MEASUREMENT.md),
[finite thermal verification](../verification/20261122-fem-thermal.md) and
[deformation inspection verification](../verification/20261122-fem-result-inspection.md).
The thermal scope is steady state with constant isotropic conductivity and
ambient convection. Transient heating, remote radiation and thermal expansion
are not included. Linux execution remains unverified in this Windows cycle.
