# ZIMA-CAD 2026101302 — Window menu, F10 and uniform file rows

## Behavior and cause

Opening Window with a browser, File Manager or foreign-model preview tab queried
that utility tab as a native document. The native save-state contract rejects an
unknown document with `Document is not open`, which escaped the menu callback.
Window now queries save state only for IDs actually present in Workspace. Every
tab retains its title, icon, active checkmark and ordinary switching behavior;
real native documents retain their unsaved marker.

F10 invokes the existing active-tab close action. F9 and the platform standard
Close shortcut (Ctrl+W on Windows/Linux) remain registered. Browser, File Manager
and foreign-preview tabs use their existing close handlers. Native Part, Assembly
and Drawing retain their Save/Discard/Cancel protection. The empty-CAD refresh
now reapplies the existing shared document-area visibility policy, preventing
Close from becoming disabled while a utility tab remains.

Files rows use one height from the thumbnail-size control, including directories,
files without previews, and landscape/portrait images. Changing the size updates
all rows together. Images keep their aspect ratio and minimal margins. Overview
and the directory Tree retain their existing sizing.

These changes use shared Windows/Linux C++ paths. They do not change the kernel,
geometry, placement, native formats, factory definitions or model calculations.
No new translatable UI text is introduced; existing Close and Window labels are
reviewed through all five catalogs. F10 is an invariant keyboard identifier.

## Local verification

- Before the fix, the added mixed native/File Manager menu fixture fails with
  `Document is not open` (2.96 seconds).
- Native Files GUI tests pass (3.08 seconds), including uniform heights at
  thumbnail settings of 48/72/144/192 pixels (rows add four pixels of margin),
  preview-free files, directories and differing image
  aspect ratios. Existing editing, filtering, hover and column checks remain.
- Extended workspace GUI tests pass (16.83 seconds): actual Window menu clicks,
  active checkmarks, unsaved markers and selection of every listed tab;
  native-only, mixed, utility-only and empty windows; F10 on native Part,
  Assembly, Drawing, browser, File Manager and DXF preview; Save, Discard and
  Cancel through the actual unsaved-change dialog.
- The test initially exposed the disabled Close action after the final CAD tab
  closed. The shared visibility-policy repair is included in the passing result.

Dependent Save Copy, STEP tabs, System Setup and five-language checks all pass
(4/4, 72.93 seconds). Save Copy retains its actual GUI save/reopen, cancellation
and export checks; System Setup retains all six mm/in templates. These are scoped
regressions, not a repository-wide test run.

Committed-source Windows packaging and signed publication are in progress;
their results will be recorded after final acceptance.
Linux build, desktop and package execution remain assigned to the Linux host.
