# Windows 2026101207 — editable directory metadata and removal protection

## Changes

Directory Properties now remains editable when a File Manager source is marked
read-only. This allows an administrator to maintain the five localized labels,
Overview behavior, SVG/PNG branding and parameter definitions without enabling
native parameter edits or destructive file operations in that source.

The dialog now exposes the existing metadata key
`Directory/PreventRemoval`. When enabled, File Manager blocks deletion and
moving of the directory's contents. It also rejects deleting or moving a
protected directory or an ancestor containing a protected descendant. Copying
out remains available. All 312 imported engineering-table directories already
carry this protection flag.

No native CAD document schema, geometry algorithm, container-placement contract
or OCCT version changed. The two new user-visible messages are translated in
Czech, English, German, French and Russian.

## Verification status

The standalone File Manager contract verifies localized metadata editing and
`PreventRemoval` persistence, disabled destructive controls in a protected
directory, and explicit Directory Properties editing for a read-only source.
It also retains the prior read-only native-parameter and no-write-on-browse
checks. The integrated application contract and five-language translation
contract pass with the same implementation.

Native Linux build and desktop verification remain assigned to the Linux host.
Packaged and signed Windows acceptance will be recorded below.
