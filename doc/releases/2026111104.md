# Windows 2026111104 — Properties layout and confirmation lifetime

Status: signed Windows release published and accepted. Native Linux acceptance
remains a separate host gate.

Sheet Profile Properties now follows the established Feature layout without
painting unused controls over the direction row. Its Sketch button is beside the
work-plane selector, thickness remains above both sides, and the dynamic extent
area scrolls when an Up To target table needs more height. Repeated expansion,
collapse and resizing retain the control order.

New Document reserves visible validation space from its initial layout. A
duplicate-file error therefore remains entirely visible above the action row,
and editing the filename clears the old message.

Shared middle-button double-click confirmation now invokes OK after the current
event dispatch finishes. A successful command may rebuild its View without
deleting the widget that is still dispatching the mouse event. Drawing Dimension
retains its existing creation-finish behavior through the deferred confirmation.

Nineteen distinct focused Windows suites pass. They include the 630-case
five-language/resizing Part-dialog matrix, repeated Sheet Profile Up To layout,
New Document duplicate validation, shared Properties confirmation, Drawing
Dimension, application tools and the adjacent Drawing contracts. A live Czech
Windows run also confirms the complete duplicate-file message is visible. See
the [verification record](../verification/20261111-properties-layout-and-confirmation.md).

No new or changed user-visible string was introduced. The five localization
catalogs pass their coverage contract. No native document format, modeling
algorithm, calculation tolerance, protected shared placement behavior,
geometry-side meaning, Qt 6.11.0 or OCCT 8.0.1 pin changed. A complete
repository-wide regression run and native Linux execution are not claimed.
