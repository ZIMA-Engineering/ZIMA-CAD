# ZIMA-CAD 2026111902 Windows release

Status: local native and hidden GUI verification and the Windows candidate
passed. This tag was not published as a release; its changes are included in
[2026111903](2026111903.md) with the subsequent contact-edge corrections.

Attached Flat, Bend and Sheet Profile validate their references against the
actual input history boundary. Consumed cut-edge segments and their midpoints
therefore no longer produce false red Tree entries. Genuinely missing references
remain invalid and repairable.

An unchanged explicit regeneration preserves a previously resolved placement
frame when the only difference is floating-point roundoff. Reuse requires
matching source and consumer fingerprints, preserving real source and parameter
edits. The change addresses the saved model 17 dependency chain.

Helical Curve now shares Helical Sweep's icon shape in the neutral foreground
color, including its command and Tree representation.

The existing 1901 Loft correspondence, guide points, exact trimmed-edge and
midpoint attachment, and Properties editing changes remain included. See the
[1901 release](2026111901.md) and the
[follow-up verification record](../verification/20261119-sheet-reference-status.md).
The implementation remains shared C++; native Linux verification is separate.
