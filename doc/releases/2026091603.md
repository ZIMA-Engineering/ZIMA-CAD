# ZIMA-CAD 2026091603

- Sheet Metal now offers Selection and Sheet Metal Properties in the right-hand
  command panel. The properties shortcut opens File Settings > Sheet Metal.
- Optional default material thickness and the material K factor are stored with
  the Part, support Undo/Redo and can also be edited through `document.settings`.
  Existing geometry is preserved when changing these defaults.
- The Part application dropdown switches Modeling/Sheet Metal and remembers the
  choice per open document. The contextual Insert menu shares toolbar actions.
- Extrusion/Revolution profile status reflects actual Sketch connectivity.
  Saving clears the dirty marker without resizing document tabs.
- Includes Surface Extrusion/Revolution, yellow surface display and visibility
  control, Drawing surface exclusion, and the Sketcher analysis-row Undo fix.
- Includes family variant insertion/replacement in Assemblies and Drawings,
  historical Body measurement with centroid inspection, and Drawing BOM balloons
  from the preceding development commits since release 2026091508.

The first Bend/Unbend command is specified but not implemented in this release.
See [Sheet Metal](../SHEET_METAL.md), [Application tools](../APPLICATION_TOOLS.md)
and [Surface profiles](../SURFACE_PROFILES.md).
