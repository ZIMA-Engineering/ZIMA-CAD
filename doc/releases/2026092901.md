# ZIMA-CAD 2026092901

Status: Windows release preparation; publication and signed-package acceptance pending.

## Changes

- Half-round sheet transitions prefer planar corner facets without additional
  diagonal bends when the checked construction is possible. Exact circular
  endpoint tangency may be relaxed; profile endpoints remain fixed. The existing
  triangulated construction remains available for unsupported facet arrangements.
- Half-round and rectangular L/U transitions show both material skins, thickness
  edges and finite-radius bends in the cyan preview. Construction closure and
  dashed envelope segments are omitted from this preview.
- Both transition types expose stable start/end axis points and an oriented end
  profile plane for Part references and Assembly mates. The Point checkbox shows
  both profile centres. Occurrence paths distinguish repeated components.
- Point Features on circles retain authored plane offsets when a referenced
  plane becomes parallel to the circle plane. The displayed distance is derived
  and read-only; tilting the plane restores the authored constraint.
- General-surface placement uses persisted viewer triangles, bounded geometric
  search and explicit solution validity, with the existing placement interaction.
- Boundary Surface editing retains input context and inspects stored boundaries.
  Cut boundary edges expose their original intersection endpoints for references.
- Sketch arc and spline snapping and document-tab close-button spacing are improved.
- Drawing surface-texture symbols require a selected entity and follow its
  orientation. ISO 21920 text spacing and upper-line length are adjusted;
  geometric-tolerance geometry is yellow with green text.
- Component occurrences can ignore Family detail variants in filename-based
  BOM grouping while retaining the actual variant in the Assembly Tree.
- Linear/angular dimension witness lines extend 1.5 mm beyond the dimension
  line at the arrow, including the 3D View and Drawings.
- Changed UI strings are covered in Czech, English, German, French and Russian.

## Modeling and compatibility limits

The new half-round transition construction changes calculation fingerprints.
The user explicitly requested new files instead of compatibility work for older
transition files. No migration or cache-validation bypass is included.
Rectangular L/U topology calculation is unchanged; its preview and datums change.
The end plane and points are reference geometry, not material or result-body
topology. Existing side identities and Assembly placement solving are preserved.

## Verification

Fourteen focused native/GUI contracts passed: translations, mesh-surface and
circle placement, Family Tables, surface-placement UI, new-document creation,
dimension layout, Boundary Surface calculation/UI, symbol Drawing/integration/UI,
and transition commands/UI. Transition checks include both L/U and half-round
endpoints, Assembly point/plane mates with both zero-offset plane sides,
material preview coverage, dependent Bend operations, Undo/Redo and native
save/reopen/regeneration. Start templates were regenerated and remained unchanged;
the new-document GUI check passed afterward. Packaging/publisher unit checks
passed 23 cases, with two platform-specific cases skipped.

Signed-package acceptance and publication remain pending. This release targets
Windows; it makes no Linux or full-suite claim.
The standard development launcher remains `zima-cad.bat`.
