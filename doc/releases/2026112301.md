# ZIMA-CAD 2026112301

## Render and retained images

- A Render Body combines calculated Part Bodies in one scene with cameras,
  point lights and sun lighting, shared placement and the current View background.
- Rendering runs from a private snapshot while Modeling remains available.
  Results appear in a separate Render tab with compact controls and a gallery.
  Closing the tab leaves the job running; Stop cancels it.
- Explicitly keep multiple images inside the Part, rename/delete with Undo/Redo,
  and export JPEG or PNG through the ordinary Export action. Earlier snapshots
  remain usable after source edits. No required image sidecar is introduced.

See [Render usage and limits](../RENDER.md) and the
[finite acceptance record](../verification/20261123-render-and-hole-properties.md).
The first renderer handles calculated solid Bodies in Parts; Assembly scenes,
textures, glass refraction, animation, depth of field and denoising are later work.

## Modeling repairs

- Hole Properties retains the real last valid input geometry when a preceding
  operation has failed, including the reported threaded Hole case.
- Holes places Sketch beside In View and exposes both authored drilling-axis
  endpoints for ordinary reference selection.
- A circle accepts tangency to exact circular offsets, retaining the dependent
  source and an existing C contact. Repeated dimensions and dragging retain the
  tangent equations. Three-circle/arc contact uses the same native constraints.
- Virtual rounding accepts two arcs and explicitly anchored offset/arc endpoint
  junctions without merging or moving their authored points.

The [Sketcher acceptance matrix](../SKETCHER_OFFSET_FOLLOWUP_20261123.md) records
tested variants and limitations. The [CAM design](../CAM_BODY_DESIGN.md) records
the agreed future setup, stock, tool, path and simulation workflow; CAM is not
implemented by this release.
