# ZIMA-CAD 2026092604 — Windows

This maintenance release fixes Drawing views that could appear blank or as a
white block and makes Sketch entry buttons consistently azure.

## Changes

- The Drawing sheet surface inherits the active OpenGL context format instead
  of forcing a legacy OpenGL 2 context alongside the application's core-profile
  3D canvas. This prevents incompatible shared Qt shader programs from hiding
  otherwise calculated view geometry. Model geometry, depth ordering and vector
  export preparation are unchanged.
- Enabled Sketch entry buttons use the same azure background in the main
  Modeling controls and the affected feature properties, including Sweep,
  Helical Sweep, Sheet Transition and Section properties. Disabled controls keep
  their native disabled appearance.
- Preparatory Straighten/Restore shape icons and the confirmed specification
  are included in the source. The solid straightening commands are not yet
  implemented or exposed in this release.

No native document format change or new runtime UI text is introduced. The normal
development launcher remains `zima-cad.bat`.

## Verification scope

During implementation, the translation, Drawing UI, view controls, breaks,
details and source-picker contracts passed. The source-picker regression checks
actual OpenGL framebuffer content and captured Drawing output, including a
negative check for the previous white-block failure. The main Drawing workspace
check and tests using copies of two user projects also passed; the originals were
not modified. Sketch-button shared UI, feature-type and five-language checks
passed.

An extended Section fixture still reports `Drawing sheet/view has no Rename
action`; the identical failure was reproduced with the unchanged published
2026092603 executable. This release does not claim to fix that separate issue.

Package acceptance and publication are recorded below only after validation.
This is a Windows-only build; no fresh Windows OS or Linux acceptance is claimed.
