# ZIMA-CAD 2026092802

Status: Signed Windows release, published and verified.

## Changes

- Straight-extrusion Features have a signed draft angle for each side. Every
  supported wall receives the same angle relative to the extrusion direction.
  Positive draft reduces material away from the Sketch plane; holes expand.
  Revolution retains its existing behavior.
- Analytical previews use native Sketch geometry without a solid calculation.
  Calculation rejects profile collapse, self-intersection and intersecting
  expanding profile regions. Original Sketch topology ancestry is preserved.
- Drafted planar and conical faces remain usable by downstream Up To operations.
  Revolution Up To retains its existing axis-containing-plane restriction.
- Corrected mixed polygon/circle profile orientation at the inactive reverse
  endpoint, including zero-draft Features.
- Model leaders retain their model-space length while orbiting and scale with
  zoom. Edge leaders point vertically on screen.
- Sketch, Add and Subtract controls have matching rounded styling. Add and
  Subtract have equal height and retain their existing toggle and color behavior.
- Labels and validation messages are translated into all five UI languages.

Nonzero draft currently supports lines, circular arcs and circles, including
solid profiles with holes, closed Surface profiles and open or closed Thin
profiles. Ellipses, splines and open Surface profiles report explicit limitations.
Zero-draft behavior remains covered by regression checks. See
[Feature types](../UNIFIED_FEATURE_TYPES.md) for the user-facing contract.

## Source verification

Eighteen focused native and GUI contracts passed, covering analytical dimensions
and volumes, both extrusion directions and symmetry, profile topology identity,
downstream targets and regeneration, persistence, failure atomicity, Undo/Redo,
numeric locks, translations, Feature interaction, model symbols and compact
windows. The final multi-region intersection check passed separately.
This is targeted Windows verification, not a full-suite or Linux claim.

Start templates were regenerated with the changed code and remained byte-identical.
Template and real New Document GUI checks passed. Packaging/signing unit checks
passed with 23 passed and 2 skipped.

The Feature GUI fixture previously expected a black selected Add icon, although
the accepted product code already retained its green icon. Only that obsolete
test expectation was corrected; the button interaction was not changed.
