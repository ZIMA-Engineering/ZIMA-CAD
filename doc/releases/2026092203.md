# ZIMA-CAD 2026092203 — Windows

## Changes

- Native `.symz` definitions contain coplanar Sketches, text fields and named
  variants. Inserted symbols are independent embedded copies and do not become
  solid profiles. Projection symbols follow their owning Drawing sheet.
- Factory title blocks in all five languages contain general surface texture
  and edge symbols. Their values are directly editable without an override
  checkbox. General texture has its own library asset, separate from local
  surface texture. All texture strokes are yellow; general text is white and
  local text green. The green edge heading includes `ISO 13715`.
- Title-block symbol strokes and text share an editing identity; double-click
  and Properties edit only the selected occurrence. Library changes do not
  silently modify existing drawings. Reinsert a factory title block to adopt
  its updated layout and headings.
- Template text in PDF respects its configured pen width. Adjusted text is
  vector outlines, not searchable text. DXF retains native text entities.
- The interface ISO font is slightly heavier. Drawing and model annotation
  fonts retain their normal weight independently of the interface.
- Assembly activation and exit retain the camera. The top Assembly tree menu
  offers Activate with the same behavior as returning from a component.
- A fixed-height status row prevents the progress indicator from changing the
  View size during saving or double-click inspection; its horizontal space is
  retained while hidden. Previously its removal
  changed the canvas height by eight pixels in the regression fixture.
- Entering a Sketch in Assembly context retains zoom and pan during normal
  alignment; standalone Part profile fitting retains its existing behavior.
- Includes the preceding committed fixes for Assembly Drawing thread lead-ins,
  unwanted basis axes and boundary visibility, configurable document-name
  normalization and frame trimming marks.

## Scope and verification

See [symbol design and limitations](../SYMBOLS_DESIGN.md) for implemented
annotation support. Fixed-size model attachments, a full symbol authoring GUI
and the explicit list-of-exceptions roughness composition remain future work.
The library is not a claim of exhaustive standards coverage.

Focused verification covers symbol embedding, variant values, Cancel,
Undo/Redo, native persistence, extrusion-profile isolation, five-language UI,
template rendering, Drawing text pens and unchanged output under a heavier UI
font. Assembly regression coverage checks nested Body/Assembly Sketch editing,
camera and canvas stability, saving and returning through the root context menu.

All eleven selected native contracts passed, including the corrected export
test, which now invokes Export rather than the obsolete Save As route. A
read-only GUI check of `ze0001-0000-0000.asmz` also passed: Skeleton activation,
Body double-click and exit preserved the camera and the 1594 × 743 canvas.
The test releases its Tree iterator before triggering a Tree rebuild. Original
Assembly and Part files were not saved. Evidence: `build/assembly-final-ctest.log`,
`build/assembly-view-verified.log` and `build/assembly-real-file-verified.log`.

This record does not claim a complete repository-wide test pass or Linux
verification. Windows packaging and publication acceptance will be recorded
after the committed-source candidate and signed-archive checks complete.
