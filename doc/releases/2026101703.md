# ZIMA-CAD 2026101703

Factory locking holes in the 24 small-head bolt models and their two reference
Parts now use the current Default modeling operation, subtracting Through All
independently on both sides. Editing opens the current Properties panel. Native
document, Sketch and feature identities are retained; the two affected reference
Drawings have verified hole-center attachments.

Ordinary console modeling uses `feature.*`, including atomic Sketch editing.
The retired ordinary `extrusion.*` and `revolution.*` commands are removed without
aliases. Sheet Cut and Sheet Revolution retain their shared geometry backend and
expose the separate `sheet_cut.*` and `sheet_revolution.*` command families.
Default reference assignment/removal uses the existing profile transactions in
Parts and Assemblies, as explicitly approved. Placement solving, orientation,
offset and persistence rules are unchanged.

Opening another document in an already running application preserves the working
directory. The first shell-opened document still selects its directory. Setting
the working directory from Engineering Tables retains the current source,
chapter and page. Save and Save As keep their established behavior.

Engineering reference tables highlight a clicked data row in azure. The highlight
works in Light and Dark themes and does not alter printing or embedded controls.
The counterbore overview places the original illustration's lower half to the
right at the existing display height. The screws overview omits redundant child
navigation. All generated pages retain five-language content and neutral fallbacks.

Seven proven uncalled helpers were removed. Live sheet geometry and registered
hole commands remain; two protected placement helpers await separate discussion.
The command audit records the evidence and remaining dependencies.

An editable fitted-bolt starting model was prepared separately in the user's
Projects directory as `HFB-CSN021111-M10x050.prtz`: M10 thread blank, 11 mm fitted
shaft, 50 mm length, 16 mm across flats and 7 mm head height. It is an unfinished
model for the user to complete, not a certified factory product or release asset.

## Verification and limits

The native Part/Assembly profile, reference, history, cursor, activation, work-plane,
value-lock, sheet-state, Bend and disconnected-fragment matrices pass. They cover
successive edits, atomic rejection, Undo/Redo and native persistence as applicable.
All 200 factory bolt models pass independent geometric/property checks. A freshly
authored locking-hole bolt passes three successive length changes, Undo/Redo and
reopening. Its actual GUI verifies both Through All sides, Cancel, unchanged OK,
editing and native reopening. Startup/working-directory and File Manager checks
pass. The CLI process contract passes native files, Unicode paths, projections,
scripts/stdin, errors and explicit calculation.
The complete console GUI contract also passes, including current Properties,
Shell/Fillet/Chamfer edits, Assembly cuts, references, history and persistence.
Its downstream fixtures use one current Default side where their independent
equations require a complete wall or full-length edge; independent End/Start
geometry remains covered by the profile matrices.
Actual bolt Sketch double-click editing, three successive angle values, supported
point drags, Undo/Redo and persistence pass. The two final public API consumers
also pass their GUI scenarios: repeated-occurrence refresh without unnecessary
rebuilds, and nested component reference/activation/source-opening interactions.

All 1,405 generated localized reference pages pass browser layout, Light/Dark,
row-selection and print checks. Sixteen table/layout tests, five-language catalog
checks and packaging/publisher tests pass (platform-specific skips are recorded
in their logs). There is no native file-format or kernel-version change.

The broad UI color suite stops at the existing assertion that confirmed wire
pixels must exceed hover pixels by 20%; the production wire-width code is
unchanged from 2026101702. Targeted point-marker and translation checks pass.
This is an explicit verification gap, not a passing broad UI suite. Checks are
finite and do not certify every geometry, Sketcher interaction or manufacturing
tolerance. Linux execution remains unverified on this Windows host.

Windows package acceptance and publication are recorded after their gates pass.
