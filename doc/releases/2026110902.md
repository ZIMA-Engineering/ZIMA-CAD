# Windows 2026110902 — Bend-aligned Profile attachment

Status: Signed Windows release candidate pending publication acceptance.

Sheet Profile now uses the exact attachment reference and trajectory frame used
by Bend. Selecting a straight sheet boundary chooses the same real native edge
endpoint as Bend, inherits the joining face and sheet thickness, and places the
owned route at that endpoint with Bend's tangent, material-inward axis and plane
normal. The same calculation is verified at both endpoints and after reversing
the edge representation.

Profile Properties no longer exposes **Other edge endpoint** or **Manual
placement references**. The ordinary workflow is therefore one edge selection,
with no separate attachment mode or Profile-only frame path. Flat and other
commands retain their own controls. The protected shared container-placement
implementation is unchanged; Profile consumes the existing Bend contract.

This release also contains the preceding 2026110901 source batch: 3D Sweep
Properties retains the real rollback/input scene; Patterned Revolution copies
regenerate their axis; Pattern and Mirror expose copied Origins; Sketch Trim
retains compatible Parallel and Horizontal/Vertical relations; projected
Drawing views place directly from their prepared frame; and interactive Drawing
distinguishes thin gray strokes without the expensive line-weight preview.

The focused Release checks pass for Bend attachment, Sheet Profile geometry and
GUI behavior, and all five localization catalogs. The native Profile test
compares Profile and Bend origins and axes independently, covers both native
edge endpoints, reversed edge order, generated children, Undo/Redo, save/reopen
and cold OCCT calculation. No new or changed user-visible text required catalog
updates because the removed labels remain in use by other commands.

The broader shared UI contract still reports an unrelated existing automatic
work-plane expectation. It is recorded as a finite verification gap and was not
mixed into this conservative Profile correction.

No native file format, start template, factory asset, protected shared placement
solver, geometry-side meaning, calculation precision or dependency pin changed.
Windows and Linux keep one shared C++ implementation pinned to OCCT 8.0.1.
Native Linux build and execution remain a separate host gate.
