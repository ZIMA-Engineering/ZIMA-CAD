# Windows build 2026101101

This follow-up carries the verified STEP, rigid-Body, calculated-model parity
and angular-dimension changes from [source candidate 2026101003](2026101003.md)
into the next Windows release. The immutable 1003 source tag and unsigned
candidate remain intact; that candidate was not published as an official release.

Large-import scene refresh prepares the complete construction/parameter
reference source only when an existing consumer needs it. Exact reference-copy
capacity is reserved before retaining all accepted faces. A bounded viewer cache
reuses silhouette connectivity only after complete equality checks of current
rounded coordinate classes, triangles, face-key runs and topological segments.
Current positions, normals and publication order are still calculated from the
actual mesh. Geometry changes invalidate reuse; no precision, identity, side
choice or supported geometry is dropped.

On the proper 308,270-triangle G92H1-T fixture, two ordinary candidate preview
samples reused adjacency in 137.830 and 145.594 ms. Other placements required
full rebuilds in 712.380–834.212 ms; this additional work is retained for correct
classification. Complete offset previews measured 3,604.78/2,590.85/2,630.74/
2,007.72 ms, with Cancel 2,694.45 ms. The serial preceding-build samples were
2,635.55/2,640.13/2,908.43/4,299.69 ms, with Cancel 2,709.87 ms. These noisy,
finite samples show a useful reuse path and remaining cold overhead, not a
universal command-speed ratio. The requested 0.5-second GUI target remains unmet.
The earlier native confirmation measurements of about 0.52–0.69 seconds exclude
GUI publication and saving. Full measurements and limitations are in the
[investigation](../performance/20261010-step-gauss-shared-source.md).

The eighteen selected dependent contracts have passed, including actual
SurfaceIntersection, surface trimming, General/Boundary Surface, both Sweep
commands, feature and Pattern dimensions, imported Body/Extrusion interaction,
measurement, curved placement, Section editing and factory document creation.
The Section test's obsolete caption order and removed `boxAction` lookup were
corrected to the existing product contracts; Drawing behavior is unchanged.
The complete Section lifecycle passed in 20.58 seconds. All five localization
catalogs pass; this follow-up adds no user-visible product text.

The permanent seventeen-case connectivity contract checks complete cached versus
forced-fresh GPU bytes, frames, reuse and invalidation. The earlier full product
move/save/Undo/Redo/reopen acceptance remains recorded in 1003. The final grouped
candidate matches all 200 synthetic frame/hash records and thirteen complete
G92H1-T images against the clean preceding renderer. Six actual Body poses also
pass independent vertex/triangle, complete cached-versus-fresh GPU and camera
checks. Extrusion opening measured 2,291.07/2,288.82/2,234.40 ms and Cancel
1,427.08/1,754.05/1,450.42 ms across three trials. Every transition published
one scene with zero unchanged geometry uploads, preserving the complete native
packet, camera, document and Undo state. Packaged acceptance remains pending.

OCCT 8.0.0 patch. Native Linux verification remains pending the user's reboot
and is recorded in [the handoff](../LINUX_RELEASE_HANDOFF.md). The existing
spatial-Sweep nonconvergence and G92K1 physical-integration discrepancy remain
explicit verification gaps; neither tolerances nor convergence checks are relaxed.

Official publication still requires the committed/tagged-source pipeline,
dependency closure, archive checks, native smoke, publisher trust, packaged GUI
acceptance and independent public-download hashes. No signed release is claimed
before those gates succeed. User configuration and projects remain preserved;
the root `zima-cad.bat` continues to launch the current local native build.
