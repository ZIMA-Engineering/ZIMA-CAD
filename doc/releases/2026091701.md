# ZIMA-CAD 2026091701 — Linux candidate

## Status

This is an **unsigned candidate**, prepared for Debian 13 (trixie) x86_64 and
KDE/Wayland. Public signed release and production updater bootstrap acceptance
remain pending the existing publisher's private key. Do not describe this
candidate as an authenticated official update.

The candidate source is commit `48465a3fe34c5db3c2dc14cbf80a736b7b474fb1`.
It follows Windows 2026091607 and contains the same modeling functionality,
plus the native Linux build and distribution work below. Windows is not included.

## Changes

- Native Qt 6.8.2, OCCT 7.9.3, OpenSSL and transitive libraries replace the former
  Conda development/runtime dependency. Debian 13.6, GCC 14.2.0 and glibc 2.41
  supplied this build. Per-library Debian versions and licenses are in the bundle.
- The repository now provides a pinned OCCT SDK builder and a committed-source
  Linux candidate builder. Exact source, factory resources and version-local
  libraries accompany the binaries; user configuration and projects stay separate.
- Fixed Debian Qt private-header discovery, GCC dependent-type declarations in
  GUI verification, OCCT STL export on POSIX and transitive SDK library loading.
- Linux archive extraction preserves executable permissions. Launcher recovery
  preserves the CLI's output protocol. Candidate and signing input gates verify
  the Linux launcher, and finalization can smoke the signed Linux archive.

## Candidate acceptance

Passed:

- Eight packaging tests (one Windows-only test skipped), fourteen publisher
  input-gate tests and all twenty-three isolated Linux updater lifecycle tests.
- Five native suites: portable settings, STEP models, AI command contract,
  actual CLI processes and STEP/STL exports, including accented paths and volume.
- Actual Updates GUI checks on KDE/Wayland: install approval, cancellation,
  retry, rollback presentation and unsaved-document restart protection.
- Committed-source candidate build, dependency closure, safe paths/collisions,
  CRC, SHA-256 and extraction into a directory with spaces and Unicode.
- Extracted root launcher and CLI pipes, 6000 mm3 Box save/reopen, PDF/JPEG,
  rendered GUI startup, unchanged packaged files and preserved user settings.
  The exported 3D view was visually inspected.

Known test limitations:

- The broad shared-dialog suite stops at its fixed 360-pixel Axis Properties
  width assertion with this KDE font configuration, also with Fusion style.
  Remaining assertions in that suite were not completed.
- Qt's offscreen backend cannot render this OpenGL widget and crashes that GUI
  suite. Actual desktop verification used Wayland instead.
- This is focused Linux acceptance, not a complete repository-wide regression
  pass. Existing modeling limitations from 2026091607 still apply, including
  the authored Bend trajectory-endpoint reference conflict during Unbend.
- Production signing, final signed-archive smoke and public update discovery
  remain pending. Test-only signatures establish lifecycle behavior only.
