# Windows 2026112503 — first-stage CAM

This release follows the CAD fixes in [2026112502](2026112502.md) and completes
the agreed initial three-axis CAM workflow.

- Edit tools, machines, ordered Facing/manual operations and clamping references
  within the CAM setup. Import explicit tool and machine parameters from native
  library files; edit exact cutting/shank profiles around their common origin.
- Calculate generic NC paths and exact remaining material explicitly. Cancel
  retains the document; current results and unchanged settings avoid recalculation.
- Inspect and step NC lines with yellow cutting paths, dashed red rapids and a
  moving tool. Export the generic program as text. Controller postprocessing is
  a separate, unimplemented step.
- Check fixture/contact-exclusion collisions, cutting below jaw tops and lost
  contact area. Reports select their corresponding NC motion. Colliding stock
  cannot feed the next setup.

The approved nested CAM schema is version 2. Ordinary Part storage remains
format 79. Start templates were regenerated and verified; factory assets have
no CAM definitions requiring conversion. Earlier unfinished CAM schema is not
migrated. All text is localized in Czech, English, German, French and Russian.

See the [acceptance matrix](../verification/20261125-cam-authoring-and-clamping.md)
for native/GUI checks, precise semantics and finite coverage. Arbitrary modeled
tool conversion, workholding-library placement/import, pocket/contour machining,
turning, rotary axes and controller-specific export are outside this first stage.
Native Linux execution remains unverified. Protected user originals are unchanged;
their previously unsupported legacy-format files remain unsupported.
