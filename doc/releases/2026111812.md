# ZIMA-CAD 2026111812 Windows release

Status: Windows candidate preparation; publication requires the package checks
and public acceptance recorded below.

This follow-up fixes Equal Length on a rectangle symmetric about both Sketch
axes, starts Loft placement reference entry automatically, and displays the
selected work plane while editing a Loft-owned Sketch. Manual XY/XZ/YZ choices
reuse the existing resolved Sketch frame. XY remains the default; the new
Sketch's prefilled references intentionally attach it to its owning Loft Origin.

The repository development BAT keeps the repository process directory while
honoring the configured application project directory. Explicit
`--working-directory` still takes precedence.

The implementation is shared C++ on Windows and Linux, with unchanged Qt 6.11.0,
OCCT 8.0.1, native document formats, reference identities and placement solver.
No application text was introduced or changed. See the
[finite regression matrix](../verification/20261118-symmetric-equal-loft-launcher.md)
for checked behavior and remaining platform/coverage limits.
