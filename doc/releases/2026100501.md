# Windows 2026100501

Status: release preparation; publication acceptance is recorded after validation.

## Behavior

- General Surface owns ordinary Sketch features with their complete local
  Properties and Sketcher, and 3D Curves inheriting the surface frame. All owned
  definitions remain available as passive context during nested editing.
  Boundary removal can empty the list; committed definitions are hidden and
  independently selectable/editable in the Tree.
- Trim hides a consumed Intersection wire, including its points. Manual wire
  Show/Hide is persisted in the native Part and supports Undo/Redo. Properties
  temporarily restores the needed input without changing ordinary visibility.
- Hidden geometry has only gray Tree names. Hidden Body construction wires and
  points disappear together with its solid. Hidden subassembly descendants retain
  their suppression state; repeated occurrences remain independent. Extrusion
  and Revolution result rows no longer offer ineffective source-Sketch Hide.
- Sewing Properties keeps two visible rows with fixed heights, compact controls
  and a scrolling reference list. Upper fields keep their spacing on resize/move,
  and new input scrolls into view.
- Automatic axis points lie at the actual axial ends of geometry, independently
  of display overhangs. Profile/centroid axes and points remain visible through
  Body history cursor changes and Straighten/Restore chains. Open construction
  axes and curves have presentation overhangs; Sweep tails use exact tangents.
  Idle axis points use their axis color.
- Polyline start tangency survives compatible endpoint snapping. Arc junction
  tangency and dimension solving use the native endpoint equations. Circular and
  elliptical Arc entry offers its own K points through the common picker.
- Through All Sheet Cut restores the dashed final cyan preview. Passive boundary
  points follow their geometry color. Intersection View selection uses the
  common candidate list. Fill Surface omits its unrelated Origin action.
- Drawing File Rename renames its primary Part or Assembly in the same staged
  transaction and updates open-document paths, repeated/nested occurrences,
  tab titles and historical metadata. It targets the displayed Drawing even
  while its source is the writable model context. Drawing sheet/view Rename
  remains a separate undoable name edit available in the Tree menu.

All changed UI text is localized in Czech, English, German, French and Russian.
Documentation is English. Part and Skeleton templates include native wire
visibility data. Existing geometry-side, identity and shared placement contracts
are retained. Old calculated files need explicit Regenerate for newly calculated
automatic-axis endpoints and exact Sweep curves; opening does not calculate.

Grid editing and G3 remain deferred. The existing Trim edge-tool calculation
does not accept standalone authored 3D Curves directly. These limits are unchanged.
