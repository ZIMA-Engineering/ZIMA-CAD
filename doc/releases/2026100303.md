# Windows 2026100303

Status: signed Windows release published and verified on 2026-10-03.

## Behavior

- Modeling Twist uses the shared Feature editor, filled-profile centroid axis,
  linear/smooth transition and native solid history. One owned Sketch supports
  one connected filled profile with holes; disconnected regions and separate
  Sketch stations are unsupported.
- Straighten preserves the directed start/end behavior of combined Features
  with Extrusion and Revolution sides. Explicit calculation rebuilds the valid
  original Feature prefix rather than reusing stale state geometry.
- Ordinary View selection of a straightened result resolves to the original
  feature. Double-click shows its complete authored blue wire and dimensions
  at the original location. Body and active occurrence transforms apply once;
  Tree synchronization preserves the exact occurrence path.
- Unbend calculates a separate circular Sheet Cut axis at the current planar
  material carrier. The folded axis disappears from display and picking. Bend
  Back and repeated Unbend retain the authored axis and Origin. A curved cut
  footprint after unrolling has no single straight cylinder axis.
- Imperial drawing tolerances use decimal-point alignment, omitted leading
  zero and preserved signed zero. This is a presentation correction, not a
  claim of comprehensive ASME compliance.

Existing cached sheet calculations need explicit Regenerate once to receive
the corrected axis. Document opening and parameter inspection never invoke
OCCT. The protected shared placement solver is unchanged. User-model checks
save test copies only; no source project is overwritten.

## Verification

The focused native matrix compares independent expected straight solids,
endpoint direction, volume, area, source identity and restoration. GUI checks
exercise real View clicks/double-clicks, authored wire/dimensions, rotated Body,
active Assembly occurrence, Sweep variants, rollback, Cancel, unchanged OK,
Undo/Redo and native reopening. Optional checks on `03.prtz` and `11.prtz`
cover every profile feature in those models and hidden source-axis picking.

Native axis checks cover Unbend, Bend Back, repeated Unbend, unchanged source
axes and save/reopen. Start templates were rewritten by the current serializer
and GUI creation was verified. Localization covers all five supported catalogs;
the axis and selection corrections introduce no new UI text.

The eleven focused native/GUI/localization tests passed, followed by six
state/GUI tests against the final implementation. The native user-axis check
also passed. Six packaged GUI scenarios passed: solid states with both user
models, sheet states, Sweep states, symbols in five languages, New Document
templates and Feature axes. Package tooling passed ten tests with two
environment skips; all sixteen publisher tests passed.
