# Windows 2026102403 — Loft and numeric parameter inspection

This release adds the standalone Loft command (`Přechod` in Czech) on OCCT 8.0.1.
It owns planar 2D profile and guide Sketches, with profiles above guides, a common
Sketch editor, parent-Origin placement and the shared container placement UI.
Profile-only and exact guided networks support Solid, Surface and Thin results.
[Calculation limits](../LOFT.md#calculation-and-limits) remain explicit.

Owned placements are persisted in Loft-local coordinates and retain their last
valid frame when an anchor is missing. Native Sketch dimensions and nonzero
placement/offset annotations appear during editing and double-click inspection.
Zero parameter slots also have persistent identifiers for Relations and Family
Table; locks and reference dimensions retain their read-only behavior.

Output type/Thin settings precede Add/Subtract in Loft, 2D Sweep and 3D Sweep.
Numeric helper labels identify direction (+1/-1), pattern values, helix pitch and
Up To corrections without dimension lines. Action names are aligned to Extrude /
Tažení, Loft / Přechod, Twist / Krut and Drill Point / Špička in all five languages.
The public Feature CLI operation is `extrude`; old `extrusion` input is rejected.
Native enum identities and user-authored names are unchanged.

See [Loft acceptance](../verification/20261024-loft.md),
[parent placement/parameter acceptance](../verification/20261024-loft-parent-origin.md)
and [the OCCT upgrade matrix](../verification/20261024-occt-801-upgrade.md).
The known broad baseline failures are not claimed as fixed. Linux uses the same
implementation and pinned kernel, but native Linux execution is unverified.

The immutable Windows 2401 release remains available; the development launcher
remains `zima-cad.bat`.

Candidate 2402 was held before publication when the extra Helical Sweep GUI
check found that default geometric dimension layout could move its new pitch
value label over the start marker. Helper values now carry no measured witness
direction, matching the existing scalar annotation contract. The start marker
and numeric pitch presentation are checked together. Tag 2402 is retained as
an unpublished candidate; it is not a public Windows release.
