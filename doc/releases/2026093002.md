# Windows 2026093002

## Scope

Sheet Transition Properties restores full outer and inner bend boundary lines
in the transient material preview. Rectangular-end relief is one operation for
both complete corners, including the planar facets between bends. It replaces
individual bend selection and avoids leaving the former inter-bend tongues.
Depth is measured perpendicular to the rectangular rim. Broad walls retain
their rims, forming stepped joins. Separate rectangular-end notches are not
stacked onto relieved corners; circular-end notches and short axes remain
independent. Facet-count changes retain the collective relief.

File shortcuts are F3 Import, F4 Export, F6 Save, F7 Save As, F8 Rename,
F9 Close and F12 Set Working Directory. Close follows Rename in the File menu.
F1 New, F2 Open, F5 Regenerate and standard Ctrl shortcuts are retained.

This Windows build also includes the Drawing measurement picking and
point-pair placement improvements already documented for
[2026093001](2026093001.md).

## Verification and limits

Six focused transition checks passed: half-surface geometry, manufacturing
marks/relief, finite-thickness sheet geometry, native transition commands,
transition GUI and five-language translations. These cover full preview
segments, both relieved corners, unchanged broad walls, valid single solids,
Unbend/Bend Back, creation/editing, Cancel, Undo/Redo, save/reopen and cold
regeneration. The manufacturing preview screenshot was inspected.

Drawing measurement picking, geometry and GUI checks also passed after the
GitHub update. Shortcut changes compile and have no duplicate assigned F keys;
the existing translation coverage/catalog check passed after the final F9/F12
change. Existing action implementations and command availability are reused.

The broader startup check failed at its Unicode Save As model/Drawing-copy
assertion. This does not establish that Unicode encoding caused the failure.
The application-tools GUI check failed at its initial Modeling Insert-menu
assertion. These failures are recorded, not reported as fixed or full-suite
passes. No physical cutting trial or machine-specific minimum feature size
is certified. Native file formats and shared container placement are unchanged.
