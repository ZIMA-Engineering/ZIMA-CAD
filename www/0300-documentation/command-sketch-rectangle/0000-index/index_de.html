Skizze

Rechteck

Erstellen Sie ein Rechteckprofil aus zwei gegenüberliegenden Ecken.

Befehl in der Anwendung

Vorbereitung

Öffnen Sie eine bearbeitbare Skizze und schließen Sie andere Eigenschaftenfenster. Arbeiten Sie in ihrer aktiven Ebene.

Vorgehensweise

  1. Starten Sie Rechteck.
  2. Bestätigen Sie die erste Ecke links.
  3. Prüfen Sie die Vorschau und bestätigen Sie die gegenüberliegende Ecke.

Ergebnis

Die verbundenen Seiten können bemaßt und mit umgebender Geometrie verknüpft werden.

Grenzen und Abbrechen

Escape verwirft die unfertige Konstruktion. Prüfen Sie fertige Geometrie mit Maßen und Ziehen; das Profil muss zur folgenden Operation passen.
