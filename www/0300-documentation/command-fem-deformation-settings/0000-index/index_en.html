FEM

Deformation player

Set visual deformation magnification and playback.

Command in the app

Before you begin

Activate an FEM Body with a valid mechanical result; a purely thermal result without expansion is insufficient.

Workflow

  1. Open Deformation player.
  2. Adjust magnification and speed, move the phase or start playback, and inspect the preview.
  3. Confirm OK to retain display settings.

Result

The prepared result is displayed with the selected magnification and playback.

Limits and cancellation

Cancel restores the previous display and camera. Playback visualizes a static result; it does not perform dynamic analysis or change measured values.
