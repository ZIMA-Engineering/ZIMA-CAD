Blechteile

Linienbiegung

Biegen Sie Blechmaterial um eine endliche Skizzenlinie.

Befehl in der Anwendung

Vorbereitung

Bereiten Sie berechnetes Blechmaterial in einem bearbeitbaren Körper vor.

Vorgehensweise

  1. Platzieren Sie die Skizzenebene und zeichnen Sie genau ein gerades Segment bis zu realen Blechgrenzen.
  2. Wählen Sie die feste Seite und setzen Sie Innenradius, Winkel sowie gegebenenfalls Dicke und K-Faktor.
  3. Stellen Sie die Skizze fertig, prüfen Sie die Biegevorschau und bestätigen Sie OK.

Ergebnis

Die Linie definiert die entwickelte Biegemitte, während die feste Seite stehen bleibt.

Grenzen und Abbrechen

Die Skizzenebene bestimmt die Richtung; Linienenden innerhalb durchgehenden Materials werden abgewiesen.
