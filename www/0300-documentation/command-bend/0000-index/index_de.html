Blechteile

Biegung

Erstellen Sie eine kreisbogenförmige Blechbiegung mit bearbeitbaren Endbreiten.

Befehl in der Anwendung

Vorbereitung

Aktivieren Sie einen bearbeitbaren Körper mit gültiger Platzierung oder Blechgrenze.

Vorgehensweise

  1. Wählen Sie eine geeignete gerade Grenze oder definieren Sie manuelle Platzierung.
  2. Setzen Sie Innenradius und Winkel; bearbeiten Sie bei Bedarf vorbereitete Start-, Bogen- und Endskizzen.
  3. Prüfen Sie Dicke, K-Faktor und Endkorrekturen und bestätigen Sie OK.

Ergebnis

Die Biegung folgt ihrer Kreisbahn und der beibehaltenen Materialseite.

Grenzen und Abbrechen

Gerade Fortsetzungen gehören in ein angebundenes Flachblech; die Bahn akzeptiert einen Kreisbogen, keine Ellipse. Bei Biegungen aus Blech aus Körper können Sie beide Endpunkte der ersten und zweiten Skizze korrigieren. Doppelklicken Sie auf die Biegung und dann auf das entsprechende Maß. Die Korrektur der ersten Skizze bezieht sich auf den Endpunkt der Quellkante und bleibt beim Neuberechnen erhalten.
