Render

Sun

Adds directional sunlight to the render scene.

Command in the app

Before you begin

Activate a Render Body and close other Properties.

Workflow

  1. Start Sun and enter its name.
  2. Set orientation using shared references or numeric values.
  3. Enable the light and adjust color, illuminance in lx and angular radius in degrees.
  4. Confirm with OK and compare a newly rendered image.

Result

The saved sun illuminates the scene's source Bodies from the specified direction.

Limits and cancellation

Marker visibility and illumination enablement are independent. Cancel discards pending settings; changing a light does not recalculate an existing image.
