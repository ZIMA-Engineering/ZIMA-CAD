Modeling

Wrap relief

Create raised or recessed material from wrapped closed contours.

Command in the app

Before you begin

Prepare supported analytic target faces and a filled Sketch.

Workflow

  1. Anchor the feature Origin and edit the input contours.
  2. Select the target supports in continuation order.
  3. Enter signed normal Correction and confirm OK.

Result

Positive correction raises relief; negative correction cuts inward.

Limits and cancellation

An embedded image alone is not an engineering contour or a relief definition; Cancel discards the draft.
