3D-контроллеры

Настройте 3D-контроллер для перемещения камеры и запуска существующих команд САПР.

Команда в приложении

Перед началом

Подключите совместимый контроллер. Оригинальный USB SpacePilot проверен в Windows. Проверка в нативной системе Linux и на реальном устройстве NaviGo ещё предстоит.

Порядок работы

  1. Откройте Инструменты > 3D-контроллеры или нажмите значок контроллера рядом с настройками системы.
  2. Выберите устройство и профиль Моделирование, Эскиз или Чертёж. Для NaviGo выберите его конкретный последовательный порт на вкладке Подключение; соединение начнётся после OK.
  3. На вкладке Камера настройте чувствительность перемещения, вращения и масштаба. Мёртвая зона подавляет небольшие движения в нейтральном положении; Инвертировать меняет направление оси. Потяните рукоятку 3Dconnexion к себе для приближения. Индикаторы показывают входные оси, пока навигация камеры приостановлена.
  4. На вкладке Кнопки нажмите кнопку устройства, чтобы выделить её строку, затем выберите команду. Не назначено отключает привязку. Выполняются только доступные в данный момент команды САПР.
  5. Подтвердите OK, вернитесь в активный вид модели или чертежа и проверьте контроллер. Для уточнения профиля снова откройте настройки. Отмена отбрасывает несохранённые изменения.

Результат

Сохранённые профили устройства доступны после перезапуска. Движение меняет только камеру, не пересчитывая геометрию и не создавая записей отмены.

Ограничения и отмена

В эскизе вращение по умолчанию отключено; в чертеже используются только перемещение и масштаб. Ввод текста и открытые диалоги блокируют команды. NaviGo использует 115200 8N1 и настраиваемый диапазон входа; его текущий протокол из шести значений не содержит событий назначаемых кнопок. Дисплеи устройств и радиальные меню драйвера не реализованы.
