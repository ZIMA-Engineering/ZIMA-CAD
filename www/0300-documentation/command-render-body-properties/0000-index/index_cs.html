Render

Vlastnosti Render tělesa

Upravuje zdroje a parametry existující renderovací scény.

Příkaz v aplikaci

Než začnete

Aktivujte požadované renderovací těleso; jeho zdroje musí být platná dostupná vypočtená tělesa.

Postup

  1. Otevřete Vlastnosti Render tělesa.
  2. Zvolte viditelná tělesa nebo upravte explicitní seznam zdrojů.
  3. Vyberte aktivní kameru a nastavte rozlišení, vzorky, odrazy a expozici.
  4. Zvolte převzetí povrchu z modelu nebo společnou drsnost a kovovost; potvrďte OK.

Výsledek

Scéna uloží změněné nastavení pro příští render.

Omezení a zrušení

Existující obrázky se automaticky nepřepočítávají. Zrušit zachová původní nastavení; geometrie a vzhled zdrojových těles zůstávají ve vlastnictví modelu.
