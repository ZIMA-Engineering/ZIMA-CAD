Shared commands

Mirror

Creates a referenced mirrored copy of a source solid, Body or component.

Command in the app

Before you begin

Inside a Body, the source solid must precede insertion; in an Assembly use an immediate owned component.

Workflow

  1. Start Mirror and select the Source in the Tree or view.
  2. Position the mirror's own Origin using the shared references.
  3. Choose its XY, YZ or XZ plane and inspect the preview.
  4. Confirm with OK.

Result

The copy retains its source reference and the source's additive or subtractive meaning.

Limits and cancellation

Foreign Origins and planar faces cannot define the mirror plane. Cancel preserves the original state; Sketches and Fillets are not independent source solids.
