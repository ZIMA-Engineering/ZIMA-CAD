Extrusion, Revolution and Thin

Before you start

Activate an editable Body in a Part. New material features belong to Parts, including a Part activated inside an Assembly.

Steps

  1. Choose Extrude or Revolve. Set the placement references, base plane and any plane offset in Properties.
  2. Open Sketch and draw the profile. For Revolution, define a green construction centreline as the axis. The selected axis is retained; otherwise the first eligible centreline is used.
  3. Finish the Sketch. Set the extrusion length or revolution angle and inspect the direction shown by the preview.
  4. Choose Add or Subtract. For walls, choose Thin feature, enter the thickness and select its side or symmetric distribution.
  5. Confirm OK to calculate and commit. Use Cancel to discard the pending definition.

What to check

A closed profile can create a solid; an open profile uses a supported thin-wall or surface result. Up to… requires a valid target reached by the operation. Through all is available for subtraction. Check the selected material side.

Reopen Properties to edit. The View temporarily shows the input before the feature. A single click selects; double-click exposes parameter dimensions.
