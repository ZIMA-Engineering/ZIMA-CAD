Mechanische Elemente

Einstich

Erstellen Sie einen umlaufenden Einstich auf einer Welle oder in einer Nabe mit rechteckigem oder kreisförmigem Profil.

Befehl in der Anwendung

Vorbereitung

Aktivieren Sie einen bearbeitbaren Bauteilkörper und die Anwendung Mechanik.

Vorgehensweise

  1. Starten Sie Einstich. Wählen Sie eine zylindrische Materialfläche: Sie wird als Achse eingetragen und bestimmt die Außen- oder Innenseite.
  2. Wählen Sie eine ebene Fläche oder Ursprungsebene als Fläche und stellen Sie den axialen Versatz ein. Beide Referenzreihenfolgen sind möglich; eine Drehung ist nicht erforderlich.
  3. Wählen Sie ein rechteckiges oder kreisförmiges Profil. Geben Sie für einen benutzerdefinierten Einstich Breite und Tiefe beziehungsweise den Kreisprofilradius ein.
  4. Alternativ wählen Sie eine Katalogreihe DIN 471/472 oder DIN 9925/9926. Der Stützdurchmesser bestimmt die Größe; bei rechteckigen Einstichen ist die Breite im angezeigten Bereich wählbar.
  5. Prüfen Sie die Drahtvorschau und bestätigen Sie mit OK. Spätere Änderungen erfolgen in den Eigenschaften desselben Elements.

Ergebnis

Ein subtraktives Element folgt dem gewählten Zylinder und der axialen Platzierung. Maße und Referenzen werden im Bauteil gespeichert.

Grenzen und Abbrechen

Die Kreisprofilbreite wird aus Tiefe und Radius abgeleitet. Ein nicht verfügbarer Katalogdurchmesser oder eine unpassende Seite muss korrigiert werden. Das erste fehlgeschlagene OK behält den privaten Entwurf; ein zweites unverändertes OK speichert ein ungelöstes Element, Abbrechen verwirft die Änderungen.
