Ориентиры в приложении

Эскиз

Перед началом

Активируйте редактируемое тело. Откройте Эскиз из окна Свойства содержащего его элемента, предварительно задав размещение и рабочую плоскость.

Порядок действий

  1. Выберите инструмент построения, например Прямоугольник, Окружность или Ломаная. Подтверждайте определяющие точки левой кнопкой мыши.
  2. Используйте существующие точки и предлагаемые ограничения для точных соединений. Назначайте вспомогательной геометрии режим построения, чтобы она не входила в состав профиля.
  3. Добавьте размеры. После размещения нового управляющего размера введите его значение и нажмите Enter. Справочные и заблокированные размеры доступны только для чтения.
  4. Выберите и перетащите точку, чтобы проверить оставшиеся степени свободы. Ещё раз измените размер и убедитесь, что профиль ведёт себя ожидаемым образом.
  5. Нажмите OK, чтобы вернуться в свойства элемента, затем снова OK, чтобы подтвердить элемент. Отмена отбрасывает изменения текущего сеанса редактирования эскиза.

Что проверить

Профиль должен соответствовать использующей его команде: для твёрдого тела обычно нужна замкнутая область, а поддерживаемые тонкостенные операции могут использовать разомкнутую цепочку. Внешние ссылки доступны только для чтения. Противоречащие ограничения или размеры отклоняются; полностью определённая геометрия не может свободно перемещаться.
