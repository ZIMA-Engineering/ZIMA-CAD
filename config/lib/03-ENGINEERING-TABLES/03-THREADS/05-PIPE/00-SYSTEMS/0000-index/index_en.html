ISO pipe threads
SymbolMeaning
R / Rp / RcISO 7-1 distinguishes R (external taper), Rp (internal parallel) and Rc (internal taper), with thread-joint sealing. ISO 228-1 uses G for parallel threads sealed outside the thread. These systems are not automatically interchangeable.
GISO 7-1 distinguishes R (external taper), Rp (internal parallel) and Rc (internal taper), with thread-joint sealing. ISO 228-1 uses G for parallel threads sealed outside the thread. These systems are not automatically interchangeable.
