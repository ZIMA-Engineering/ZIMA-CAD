Filetages de tuyauterie ISO
SymboleSignification
R / Rp / RcISO 7-1 distingue R (extérieur conique), Rp (intérieur cylindrique) et Rc (intérieur conique), étanches dans le filetage. ISO 228-1 utilise G pour les filetages cylindriques avec étanchéité hors filetage. Ils ne sont pas automatiquement interchangeables.
GISO 7-1 distingue R (extérieur conique), Rp (intérieur cylindrique) et Rc (intérieur conique), étanches dans le filetage. ISO 228-1 utilise G pour les filetages cylindriques avec étanchéité hors filetage. Ils ne sont pas automatiquement interchangeables.
Filetages de tuyauterie ISO
SymboleSignification
PPas P [mm]
D, dDiamètre [mm]
  • Filetages de tuyauterie ISO 7 pour joints étanches dans le filetage
  • Filetages de tuyauterie ISO 228 pour joints sans étanchéité dans le filetage

D désigne le filetage intérieur, d l’extérieur. P est le pas; l’avance d’un filetage multiple est Ph = nP. Les nombres ne sont pas automatiquement les dimensions limites d’un produit.

Sources: ISO 7-1:1994 + Cor 1:2007 · ISO 228-1:2000
