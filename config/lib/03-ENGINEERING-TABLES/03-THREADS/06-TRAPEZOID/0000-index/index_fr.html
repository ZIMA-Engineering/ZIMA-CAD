Tr a un profil à 30°. L’avance multiple est Ph = nP; ne pas confondre Tr et Acme à 29°. Dimensions du profil et classes de tolérance relèvent de différentes parties ISO 2901 à ISO 2904.

D désigne le filetage intérieur, d l’extérieur. P est le pas; l’avance d’un filetage multiple est Ph = nP. Les nombres ne sont pas automatiquement les dimensions limites d’un produit.

Sources: ISO 2901:2016, ISO 2902:2016, ISO 2903:2016, ISO 2903-2:2025, ISO 2904:2020
