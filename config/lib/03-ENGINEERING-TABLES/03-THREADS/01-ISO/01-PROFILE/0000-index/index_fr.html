Relations du profil de base du filetage
SymboleRelation
H√3·P/2
D2 = d2d − 3H/4
D1 = d1d − 5H/4
Phn·P

D désigne le filetage intérieur, d l’extérieur. P est le pas; l’avance d’un filetage multiple est Ph = nP. Les nombres ne sont pas automatiquement les dimensions limites d’un produit.

Diamètres de référence calculés pour le profil 60°, arrondis à 0,001 mm. D1 = d − 5H/4; d2 = d − 3H/4; d3 de référence = d − 17H/12; H = √3·P/2. Limites réelles, fond de filet et tolérances sont spécifiés séparément.

Sources: ISO 68-1:2023
