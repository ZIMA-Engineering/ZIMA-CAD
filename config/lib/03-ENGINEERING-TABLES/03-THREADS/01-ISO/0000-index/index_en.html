Uppercase D denotes internal threads, lowercase d external threads. P is pitch; multiple-start lead is Ph = nP. Numeric entries are not automatically the limits of an actual product.

Diameters are calculated 60° profile reference values, rounded to 0.001 mm. D1 = d − 5H/4; d2 = d − 3H/4; reference d3 = d − 17H/12; H = √3·P/2. Actual limits, root contour and tolerances are specified separately.
